# RDD - 2026-05-21-1358
**Project Name:** StreaMu AAC Direct Public Repo Removal

## 1. 機能一覧
- FR-1: 公開リポジトリから AAC Direct 再生機能を削除する。
- FR-2: 公開リポジトリから Helix AAC decoder 同梱コードを削除する。
- FR-3: 既定の音声経路を Opus Direct に変更する。
- FR-4: 既存設定に `aac_direct` が残っている場合は、安全な音声経路へ移行する。
- FR-5: 設定画面の Audio Path から AAC Direct 選択肢を削除する。
- FR-6: サーバー側の AAC Direct 用 API / transmux 実装を公開機能から削除する。
- FR-7: ドキュメントと third-party 表記から、公開版に AAC decoder が含まれる前提の記述を削除または更新する。
- NFR-1: 公開配布される 3DS バイナリに AAC decoder 実装がリンクされないこと。
- NFR-2: 既存ユーザーの設定ファイルに古い `aac_direct` 値があっても起動・再生不能にならないこと。
- NFR-3: Opus Direct と MP3 Proxy の既存再生・seek 挙動を壊さないこと。
- NFR-4: 削除後のコードベースで AAC Direct の残骸がビルド対象・UI・通常ドキュメントに残らないこと。

## 2. 詳細仕様

### FR-1: AAC Direct 再生機能の削除
- 入力: ユーザーが検索結果・プレイリスト・履歴などから楽曲再生を開始する。
- 処理: アプリは AAC Direct 経路を選択しない。使用可能な経路は Opus Direct と MP3 Proxy に限定する。
- 出力: 再生 URL 生成、プレイヤー状態、再生中表示は AAC Direct を前提にしない。

### FR-2: Helix AAC decoder 同梱コードの削除
- 入力: 公開リポジトリの通常ビルド。
- 処理: Helix AAC decoder ソースはリポジトリおよびビルド対象に存在しない。
- 出力: 生成される `.3dsx` / `.cia` に AAC decoder がリンクされない。

### FR-3: Opus Direct の既定化
- 入力: 設定ファイルが存在しない初回起動、または audio path 設定が未指定の設定ファイル。
- 処理: 既定の音声経路として Opus Direct を採用する。
- 出力: アプリは Opus Direct を使って再生を開始する。Opus Direct が利用不能な場合は既存の fallback 方針に従う。

### FR-4: 古い `aac_direct` 設定値の移行
- 入力: `config.json` に `"audio_path": "aac_direct"` が保存されている。
- 処理: 読み込み時に AAC Direct ではなく、公開版で利用可能な音声経路へ変換する。
- 出力: アプリはクラッシュせず、設定保存時には AAC Direct 以外の値が保存される。

### FR-5: Audio Path UI の整理
- 入力: ユーザーが Settings の Audio Path 項目を操作する。
- 処理: 選択肢は Opus Direct と MP3 Proxy のみを巡回する。
- 出力: UI に AAC Direct は表示されない。

### FR-6: サーバー側 AAC Direct API の削除
- 入力: 公開版サーバーの起動。
- 処理: AAC Direct 用の `/stream_aac_adts`、`/api/aac-info`、AAC transmux / probe の公開機能を削除する。
- 出力: サーバーは Opus Direct と既存 fallback 用 API を提供する。AAC Direct 用 API は通常導線に存在しない。

### FR-7: ドキュメント更新
- 入力: 公開リポジトリ内の README、third-party license、PoC/LEGAL ドキュメント。
- 処理: AAC decoder を含む公開配布を前提にした記述を削除または過去 PoC として明確化する。
- 出力: 公開版の利用者・配布者が、公開版に AAC decoder が含まれると誤解しない。

## 3. UI/UX考慮事項

Settings の Audio Path は次の 2 択にする。

```text
Audio Path: Opus Direct
Audio Path: MP3 Proxy
```

- 操作方法は既存の Audio Path 操作と同じにする。
- 既存設定が AAC Direct のユーザーにもエラー表示は出さず、自動移行で自然に継続利用できるようにする。
- AAC Direct 削除によって、通常の検索・再生・pause・seek 操作の表示文言が不自然にならないようにする。

## 4. 追加設計情報

- 変更対象は 3DS クライアント、Makefile、サーバー、ドキュメントにまたがる。
- 3DS クライアントでは `AudioPathConfig`、設定読み書き、Settings UI、再生開始・更新処理から AAC Direct 依存を取り除く必要がある。
- `third_party/helix-aac/` は公開リポジトリから削除対象とする。
- サーバー側は AAC decoder を含まないが、AAC Direct 機能としての公開導線を閉じるため削除対象に含める。
- Opus Direct の性能計測ログは今後の regression 比較に使うため維持する。
- HANDOFF の現在状態では Opus Direct が seek-capable かつ高速化済みであるため、公開版の主経路として扱う。
