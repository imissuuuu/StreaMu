# 要件定義書 - Vorbis Decoder PoC
**作成日:** 2026-05-18

## 1. 目的
AAC decoder 同梱の特許リスクを避ける代替候補として、Ogg Vorbis を 3DS 側で直接 decode できるかを小さく確認する。

## 2. 機能要件
- FR-1: 既存の `StreamDecodeResult` 抽象に沿った Vorbis stream decoder を追加する。
- FR-2: devkitPro の `3ds-libvorbisidec` / `libogg` をリンクしてビルドできる状態にする。
- FR-3: 既存の MP3 Proxy と AAC Direct の挙動は変更しない。
- FR-4: PoC の判断材料として、Vorbis 導入候補と依存関係を文書に残す。

## 3. 非機能要件
- NFR-1: GPL の `ctrmus` コードはコピーせず、API 利用方法の参考に留める。
- NFR-2: hot loop 内の不要な heap allocation を避ける。
- NFR-3: decode 入力が不足している場合は消費バイトを返し、再生ループが次の受信データを待てるようにする。
- NFR-4: 既存ビルドが失敗する環境では、依存不足が分かるエラーにする。

## 4. 対象外
- YouTube 音源を Ogg Vorbis として供給するサーバー側変換の実装。
- Settings の Audio Path 追加。
- AAC Direct の削除または無効化。
- 実機での音質・長時間再生チューニング。

## 5. 参考情報
- `C:/dev/research/3ds-audio-refs/ctrmus`: `3ds-libvorbisidec` を使う3DS音楽プレイヤー実装。
- `C:/dev/research/3ds-audio-refs/pomegranate`: Opus/Symphonia 系の別実装候補。
- Xiph Vorbis: patent-and-royalty-free と説明される音声形式。

## 6. 受け入れ条件
- `make clean` と `make` が通る。
- 新規 Vorbis decoder が `source/audio` に追加され、既存 decoder 抽象と同じ戻り値形式を使う。
- 依存関係と今後の導入判断が docs に記録される。
