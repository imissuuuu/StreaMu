# システム設計書 - StreaMu AAC Direct Public Repo Removal
**RDD:** `RDD-2026-05-21-1358.md`
**作成日:** 2026-05-21

## 1. 全体方針
- AAC Direct は compile-time option 化ではなく、公開リポジトリから実装を削除する。
- 公開版の音声経路 enum は `MP3_PROXY` と `OPUS_DIRECT` の 2 値に縮小する。
- 既存設定の `"aac_direct"` は読み込み時に `OPUS_DIRECT` へ移行する。
- 3DS バイナリから AAC decoder を確実に外すため、`third_party/helix-aac/` と AAC player/decoder ソースを削除し、Makefile の探索対象からも外す。
- サーバー側の AAC Direct API はクライアントから使われなくなるため、公開機能として削除する。
- 過去の RDD/DESIGN 履歴は履歴資料として残す。現在の README、third-party notice、LEGAL/POC の通常参照文書は公開版の実態に合わせる。

## 2. 新規ファイル
新規ファイルは作成しない。

## 5. 状態設計（新規フラグ・状態変数がある場合）
新規フラグ・状態変数は追加しない。

削除後の状態不変条件:

| 変数 | 型 | 初期値 | セット条件 | クリア条件 | 残留リスク |
|------|----|--------|-----------|-----------|-----------|
| `AppConfig::audio_path` | `AudioPathConfig` | `OPUS_DIRECT` | 設定読み込み・Settings変更 | なし | 旧 `aac_direct` を移行しないと存在しない enum 値を参照する危険があるため、読み込み時に `OPUS_DIRECT` へ倒す |
| `AppContext::active_audio_path` | `AudioPathConfig` | `OPUS_DIRECT` | 再生開始・fallback・設定適用 | 再生停止時は `ctx.config.audio_path` に戻す | 停止処理に AAC 分岐が残ると削除済み player を参照するため、`AacPocPlayer` 参照を全削除する |
| `MP3Player::is_playing` | `bool` | 既存通り | MP3 Proxy 再生・Opus fallback | stop/error/track end | Opus fallback の移行先として使う。AAC auto-next 用の代替にもする |
| `OpusPocPlayer::is_playing` | `bool` | 既存通り | Opus Direct 再生 | stop/error/track end/fallback | AAC 削除後の主経路。既存の `opus_pending_decode_start` と perf log の責務は維持する |

## 6. 実装順序
1. `theme.h`、`app_context.h`、`config_manager.h`、Settings UI、YouTube API の enum/設定/URL 生成から AAC Direct を削除する。
2. `main.cpp` から AAC player の include、global、init/stop/update、状態分岐を削除する。
3. `source/audio/aac_*` と `third_party/helix-aac/` を削除し、Makefile を更新する。
4. `server/proxy.py` から AAC API と cache/helper を削除し、`server/aac_probe.py` と `server/aac_transmux.py` を削除する。
5. README / THIRD_PARTY / LEGAL / POC docs を公開版の Opus Direct 方針へ更新する。
6. Build checkpoint: `make clean && make`。
7. Static checks:
   - `rg "AAC_DIRECT|AacPocPlayer|aac_player|aac_adts|helix-aac" source include Makefile server`
   - `python -m py_compile server/proxy.py server/opus_probe.py server/webm_opus_remux.py`
8. 実機テスト:
   - 初回起動相当で Audio Path が Opus Direct になる。
   - 旧 `config.json` の `"audio_path": "aac_direct"` で起動し、Settings 表示が Opus Direct になる。
   - Opus Direct 通常再生。
   - Opus Direct seek。
   - Opus 取得失敗時の MP3 Proxy fallback。
   - MP3 Proxy 通常再生と seek。
