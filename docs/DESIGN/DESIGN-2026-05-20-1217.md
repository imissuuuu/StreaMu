# システム設計書 - Opus Direct PoC
**RDD:** `RDD-2026-05-20-1157.md`
**作成日:** 2026-05-20

## 1. 全体方針
- Opus decoding は `3ds-libopus` / `3ds-opusfile` / `3ds-libogg` を使う。実パッケージの BSD license 確認済み。
- WebM 処理は外部 demux/remux ライブラリを追加せず、server 側に PoC 用の自前最小 WebM Opus -> Ogg Opus remuxer を実装する。ただし実装前半に feasibility gate を置き、YouTube audio-only WebM が narrow subset に収まらない場合は 3DS 側実装へ進まない。
- 3DS 側は WebM を扱わず、Ogg Opus `.opus` buffer を `opusfile` で decode する。
- 今回は Settings の正式 Audio Path を増やさない。サーバー API と hidden/local PoC playback で成立性を確認する。
- AAC Direct / MP3 Proxy / Vorbis PoC の既存経路は変更しない。

## 2. 新規ファイル

### `server/opus_probe.py`
責務: `yt-dlp` から native Opus/WebM format 情報を抽出し、server API 用の構造化データにする。

```python
from __future__ import annotations

from dataclasses import asdict, dataclass
from typing import Any

OPUS_FORMAT_SELECTOR = (
    "bestaudio[acodec*=opus][ext=webm]/"
    "bestaudio[acodec*=opus]"
)

    direct_url: str

    ext: str
    acodec: str
    container: str

    duration: float | None

    def to_json_dict(self) -> dict[str, Any]:

        data["fragments"] = len(self.fragments)
        data["http_headers"] = sorted(self.http_headers.keys())
        return data

def extract_opus_format(video_id: str) -> OpusFormatInfo | None:
    ...
```

契約:
- 入力: YouTube video ID raw string。呼び出し元で ID validation 済み。
- 出力: Opus/WebM が選択できた場合のみ `OpusFormatInfo`。
- エラー: 抽出失敗、Opus 不在、URL/fragments 不在、`acodec` が `opus` を含まない場合は `None`。
- 副作用: `yt_dlp.YoutubeDL.extract_info(..., download=False)` のネットワーク I/O。

### `server/webm_opus_remux.py`
責務: audio-only WebM Opus bytes を Ogg Opus bytes に再エンコードなしで変換する。

```python
from __future__ import annotations

from dataclasses import dataclass

@dataclass(frozen=True)
class WebmOpusPacket:
    data: bytes
    timecode_ms: int

@dataclass(frozen=True)
class WebmOpusTrack:
    codec_private: bytes
    channels: int
    sample_rate: float
    packets: list[WebmOpusPacket]

class WebmOpusRemuxError(ValueError):
    pass

def opus_packet_duration_samples(packet: bytes) -> int:
    ...

def extract_webm_opus(data: bytes) -> WebmOpusTrack:
    ...

def build_ogg_opus(track: WebmOpusTrack,
                   vendor: bytes = b"StreaMu") -> bytes:
    ...

def remux_webm_opus_to_ogg(data: bytes) -> bytes:
    return build_ogg_opus(extract_webm_opus(data))
```

契約:
- 入力: 完全取得済みの audio-only WebM bytes。
- 出力: Ogg Opus bytes。先頭は `OggS`、Opus ID header は `OpusHead`、comment header は `OpusTags`。
- エラー: EBML parse 不能、Opus track 不在、`CodecPrivate` 不在、packet 不在、lacing 使用時は `WebmOpusRemuxError`。
- 副作用: なし。pure logic として unit test 対象。

PoC 制限:
- YouTube の audio-only `webm_dash` を対象にする。
- `SimpleBlock` の no lacing を優先実装する。
- `BlockGroup` / Xiph lacing / EBML lacing / fixed-size lacing は検出したら明示エラーにする。
- granule position は Opus packet duration の累積で作る。固定 20ms 前提にはしない。
- `opus_packet_duration_samples()` は Opus TOC byte と frame count code から 48 kHz sample 数を返す pure function とし、不正 packet は `WebmOpusRemuxError`。
- `CodecDelay`, `SeekPreRoll`, `DiscardPadding` は parse して記録する。PoC 初期で正しく反映できない場合は remux 成功扱いにせず、feasibility gate で止める。

Feasibility gate:
- corpus: `dQw4w9WgXcQ`, `jNQXAC9IVRw`, `9bZkp7q19f0` の Opus WebM を対象にする。
- PASS 条件:
  - single `A_OPUS` audio track。
  - `CodecPrivate` が存在し、`OpusHead` で始まる。
  - packet は `SimpleBlock` no-lacing、または実装済みの `BlockGroup` subset のみ。
  - remux output が `OggS` / `OpusHead` / `OpusTags` を含む。
  - host-side validation で `opusfile` が開ける。
- FAIL 条件:
  - lacing が常用される。
  - `BlockGroup` / `DiscardPadding` 対応が必須で PoC 範囲を超える。
  - granule position の作成が安定せず、PC 側でも正常 decode できない。
- gate FAIL の場合、`source/audio/opus_*` と `source/main.cpp` の 3DS 側実装へ進まない。

### `source/audio/opus_memory_decoder.h`
責務: 完全な Ogg Opus memory buffer を `opusfile` で開き、PCM16 stereo 48 kHz を取り出す。

```cpp
#ifndef OPUS_MEMORY_DECODER_H
#define OPUS_MEMORY_DECODER_H

#include <stddef.h>
#include <stdint.h>
#include <opusfile.h>

struct OpusDecodeResult {
  bool ok;
  bool eof;
  int samples_per_channel;
  int sample_rate;
  int channels;
};

class OpusMemoryDecoder {
public:
  OpusMemoryDecoder();
  ~OpusMemoryDecoder();
  bool open(const uint8_t *data, size_t size);
  OpusDecodeResult decode(int16_t *pcm_out,
                          size_t pcm_capacity_samples);
  void reset();
  bool is_open() const;
  bool is_eof() const;

private:
  OggOpusFile *file_;
  bool eof_;
};

#endif
```

契約:
- `open(data, size)`: `data` は `reset()` まで生存する完全 Ogg Opus buffer。成功時のみ `file_ != NULL`。
- `decode(...)`: `op_read_stereo()` で stereo PCM を返す。`sample_rate=48000`, `channels=2` 固定。
- エラー: `open()` 失敗は `false`。decode error は `{false, false, 0, 48000, 2}` とし、呼び出し側が stop する。
- 副作用: `opusfile` decoder state のみ。NDSP には触らない。

- 成功時 media type は `audio/ogg`。
- PoC safety limit として入力 WebM が `64 MiB` を超える場合は `413`。
- remux error は `501`。
- 再エンコード、FFmpeg subprocess、外部 demux library は使わない。

## 4. 各機能の詳細設計

### FR-1/FR-2: Opus format 抽出
```text
[GET /api/opus-info]
  -> validate video id
  -> _get_cached_or_extract_opus_info()
  -> yt-dlp selector bestaudio[acodec*=opus]
  -> OpusFormatInfo.to_json_dict()
```

返却例:
```json
{
  "video_id": "dQw4w9WgXcQ",
  "format_id": "251",
  "ext": "webm",
  "acodec": "opus",
  "container": "webm_dash",
  "sample_rate": 48000,
  "channels": 2,
  "direct_url": true,
  "fragments": 0
}
```

### FR-3: Opus stream API
`/stream_opus` は現物 WebM 確認用。3DS decode 対象ではない。

`/stream_opus_ogg` は feasibility gate PASS 後の PoC playback 対象:
```text
yt-dlp OpusFormatInfo
  -> direct_url bytes fetch
  -> size <= 64 MiB
  -> extract_webm_opus()
  -> build_ogg_opus()
  -> audio/ogg Response
```

### FR-4: 3DS Opus playback
この節は server remux feasibility gate PASS 後に実装する。

```text
server /stream_opus_ogg output
  -> user saves as sdmc:/3ds/StreaMu/opus_poc.opus
  -> HOME L+R+X
  -> load file into g_stream_buffer_ptr
  -> OpusPocPlayer opens memory buffer with op_open_memory()
  -> op_read_stereo() fills NDSP buffers
```

`OpusPocPlayer` は `read_offset_` を持たない。`opusfile` が内部 cursor を持つため、finish 判定は `decoder_.is_eof()` と wave buffer 状態で行う。

### FR-5: 既存経路保持
- `AudioPathConfig` enum は変更しない。
- `YouTubeAPI::get_audio_stream_url()` は変更しない。
- Settings 表示は `AAC Direct` / `MP3 Proxy` のまま。
- `/stream` と `/stream_aac_adts` は変更しない。

### FR-6: PoC doc
`docs/POC/opus-direct-poc.md` に記録:
- `yt-dlp` format 確認結果。
- `/api/opus-info` 結果。
- `/stream_opus` first bytes / response media type。
- `/stream_opus_ogg` first bytes `OggS` と `OpusHead` 確認。
- WebM remux feasibility gate の PASS/FAIL。

- ライセンス確認結果: `3ds-libopus`, `3ds-opusfile`, `3ds-libogg` は BSD 確認済み。WebM remux は自前実装。

## 5. 状態設計

| 変数 | 型 | 初期値 | セット条件 | クリア条件 | 残留リスク |
|------|----|--------|-----------|-----------|-----------|
| `OpusPocPlayer::is_playing` | `bool` | `false` | local `.opus` load 成功後 | `stop()`, track finish, normal playback start, cleanup | true 残留で通常再生 update が止まる |
| `decoder_opened_` | `bool` | `false` | `open_decoder_if_needed()` 成功後 | `stop()` | true 残留で別 buffer を古い decoder state で読む |
| `decode_failed_` | `bool` | `false` | `op_read_stereo()` error | `stop()` | true 残留で次回 PoC playback が即終了 |
| `m_is_downloading` | `bool` | `false` | interface parity only | `stop()` | PoC local playback が finished 判定しない |

エラーパス:

| エラー | 最終状態 | 表示 |
|--------|----------|------|
| Opus player init 失敗 | `is_playing=false` | `Opus init failed` |
| file missing | `is_playing=false` | `Opus PoC file missing` |
| file too large | `is_playing=false` | `Opus PoC file too large` |
| `op_open_memory` 失敗 | `is_playing=false` | `Opus decode failed` |
| decode error | `decode_failed_=true`, finish扱い | `Opus decode failed` |

## 6. 実装順序
1. `server/opus_probe.py` を追加し、`/api/opus-info` を `proxy.py` に追加。
2. `server/webm_opus_remux.py` に EBML/WebM inspector と `opus_packet_duration_samples()` を pure logic として追加。

9. `source/audio/opus_poc_player.*` を追加。
10. `source/main.cpp` に init/stop/update/hidden trigger を配線。
11. `make clean`。
12. `make`。
