# システム設計書 - Vorbis Playback PoC
**RDD:** `RDD-2026-05-20-1049.md`
**作成日:** 2026-05-20

## 1. 全体方針
- 既存の `VorbisStreamDecoder` を NDSP queue へ接続する専用 player を追加する。
- 正式な Settings Audio Path は増やさない。
- PoC 入力は `sdmc:/3ds/StreaMu/vorbis_poc.ogg` の完全読み込み buffer とする。
- 起動中の明示操作でローカル PoC file を読み込み、既存 `g_stream_buffer_ptr` に格納して Vorbis player を開始する。
- AAC Direct / MP3 Proxy の URL 生成、server API、Settings 保存形式は変更しない。

## 2. 新規ファイル

### `source/audio/vorbis_poc_player.h`
```cpp
#ifndef VORBIS_POC_PLAYER_H
#define VORBIS_POC_PLAYER_H

#include <3ds.h>
#include <stdint.h>

#include "vorbis_stream_decoder.h"

class VorbisPocPlayer {
public:
  VorbisPocPlayer();
  ~VorbisPocPlayer();
  bool init();
  void update();
  void stop();
  bool is_track_finished() const;
  bool has_started_playing() const;
  void set_downloading_status(bool downloading);

  static bool is_playing;

private:
  VorbisStreamDecoder decoder_;
  ndspWaveBuf waveBuf[8];
  int16_t *audioBuffer;
  bool m_is_downloading = false;
  size_t read_offset_ = 0;
};

#endif
```

### `source/audio/vorbis_poc_player.cpp`
- `AacPocPlayer` と同じ ownership pattern を使う。
- PCM capacity は `8192` samples、wave buffer count は `8`。
- `init()`:
  - `decoder_.reset()`
  - `linearAlloc(VORBIS_PCM_CAPACITY_SAMPLES * VORBIS_WAVE_BUF_COUNT * sizeof(int16_t))`
  - alloc 失敗時は `false`
  - `ndspChnReset(0)` 後、各 `waveBuf[i].data_vaddr` と `status` を初期化
- `update()`:
  - `stream_lock` で `g_stream_buffer_ptr->size()` を読む
  - `is_playing == false` または `audioBuffer == NULL` なら return
  - downloading 中で未読 byte が小さい場合は待機
  - FREE/DONE buffer ごとに `VorbisStreamDecoder::decode()` を呼ぶ
  - `decoded.ok` の場合、`ndspChnSetFormat` / `ndspChnSetRate` / `DSP_FlushDataCache` / `ndspChnWaveBufAdd`
  - `decoded.bytes_consumed` を `read_offset_` に反映
- `stop()`:
  - `is_playing = false`
  - `m_is_downloading = false`
  - `ndspChnReset(0)` と `ndspChnWaveBufClear(0)`
  - buffer 状態を初期化し、`DSP_FlushDataCache`
  - `decoder_.reset()` と `read_offset_ = 0`
- `is_track_finished()` と `has_started_playing()` は AAC player と同じ判定にする。

## 3. 既存ファイルの変更

### `source/main.cpp`
#### include / global
Before:
```cpp
#include "audio/aac_poc_player.h"
#include "audio/mp3_player.h"
```
After:
```cpp
#include "audio/aac_poc_player.h"
#include "audio/mp3_player.h"

```

Before:
```cpp
std::unique_ptr<AacPocPlayer> g_aac_player_ptr;

```
After:
```cpp
std::unique_ptr<AacPocPlayer> g_aac_player_ptr;
#define aac_player (*g_aac_player_ptr)
std::unique_ptr<VorbisPocPlayer> g_vorbis_player_ptr;
#define vorbis_player (*g_vorbis_player_ptr)
```

#### local helper
Add near other file/helper functions:
```cpp
static constexpr const char *VORBIS_POC_PATH =
    "sdmc:/3ds/StreaMu/vorbis_poc.ogg";

static bool load_file_to_stream_buffer(const char *path);
```

Implementation:
- `FILE *f = fopen(path, "rb")`
- `fseek` / `ftell` で size を取得し、0 以下や大きすぎる値は失敗
- temporary `std::vector<uint8_t> data`
- `fread` が size と一致する場合のみ `stream_lock` 下で `g_stream_buffer_ptr->swap(data)`
- 失敗時は file close して `false`
- max size は PoC 用に `16 * 1024 * 1024` bytes

#### startup / cleanup
Before:
```cpp
g_player_ptr = std::make_unique<MP3Player>();
g_aac_player_ptr = std::make_unique<AacPocPlayer>();
```
After:
```cpp
g_player_ptr = std::make_unique<MP3Player>();
g_aac_player_ptr = std::make_unique<AacPocPlayer>();
g_vorbis_player_ptr = std::make_unique<VorbisPocPlayer>();
```

After `aac_player.init()`:
```cpp
bool vorbis_ready = vorbis_player.init();
```
If false, keep app booting and set a transient status only when PoC is requested.

Cleanup:
```cpp
vorbis_player.stop();
g_vorbis_player_ptr.reset();
```

#### stop existing playback
In `start_playback()`:
```cpp
player.stop();
aac_player.stop();
vorbis_player.stop();
```

When setting normal playback flags:
```cpp
VorbisPocPlayer::is_playing = false;
```

On stream error / auto-next stop paths, set `VorbisPocPlayer::is_playing = false` with the existing MP3/AAC flags.

#### PoC trigger
Add a hidden development key chord:
- `STATE_HOME`
- `KEY_L | KEY_R | KEY_Y` all down/held in the same frame

Action:
```cpp
bool started = start_vorbis_poc_playback();
ctx.g_status_msg = started ? "Vorbis PoC" : "Vorbis PoC file missing";
```

`start_vorbis_poc_playback()`:
- cancel current download and wait for `ctx.is_downloading == false`, same as `start_playback`
- stop `player`, `aac_player`, `vorbis_player`
- load `VORBIS_POC_PATH` into `g_stream_buffer_ptr`
- set:
  - `ctx.is_paused = false`
  - `ctx.is_buffering = false`
  - `ctx.playback_start_time = osGetTime()`
  - `ctx.playing_id = "vorbis_poc"`
  - `ctx.playing_title = "Vorbis PoC"`
  - `ctx.playing_duration = "?"`
  - `ctx.playing_meta = VORBIS_POC_PATH`
  - `MP3Player::is_playing = false`
  - `AacPocPlayer::is_playing = false`
  - `VorbisPocPlayer::is_playing = true`
- return `true` only when file load succeeds and `vorbis_ready == true`

#### main loop update / finish
Add:
```cpp
vorbis_player.update();
```
near existing `player.update()` / `aac_player.update()`.

Active player finish detection:
- Treat Vorbis PoC as active when `VorbisPocPlayer::is_playing` is true.
- If Vorbis finishes, clear `playing_id`, `g_status_msg`, and all `is_playing` flags.
- Do not auto-advance playlist for Vorbis PoC.

## 4. 各機能の詳細設計

### FR-1: Vorbis PCM to NDSP
- `VorbisPocPlayer::update()` mirrors `AacPocPlayer::update()`.
- `decoded.channels == 2` uses `NDSP_FORMAT_STEREO_PCM16`; otherwise mono.
- Flush length is `decoded.samples_per_channel * decoded.channels * sizeof(int16_t)`.
- `waveBuf[i].nsamples = decoded.samples_per_channel`.

### FR-2: Complete `.ogg` buffer input
- Local file is fully read before playback starts.
- `VorbisStreamDecoder` sees stable memory from `g_stream_buffer_ptr` for the life of playback.
- Streaming/server Ogg is not introduced in this task.

### FR-3: Player lifecycle
- `VorbisPocPlayer::stop()` resets NDSP channel state and decoder state.
- `is_track_finished()` returns true only when not downloading, unread bytes are below trailing threshold, and all 8 buffers are FREE/DONE.
- All normal playback starts stop Vorbis first.

### FR-4: Existing path preservation
- `AudioPath`, `AudioPathConfig`, Settings strings, config serialization, and server endpoints are unchanged.
- `YouTubeAPI::get_audio_stream_url()` remains untouched.

### FR-5: Documentation
- New PoC doc records how to place the sample and what manual tests to run.
- The doc states this is not the final Vorbis delivery path.

## 5. 状態設計

| State | Owner | Meaning |
|-------|-------|---------|
| `VorbisPocPlayer::is_playing` | Vorbis PoC player | Hidden local sample playback is active |
| `read_offset_` | Vorbis PoC player | Consumed bytes in `g_stream_buffer_ptr` |
| `m_is_downloading` | Vorbis PoC player | Kept for player interface parity; false for local PoC |
| `ctx.playing_id == "vorbis_poc"` | app context | Current visible now-playing source is local Vorbis PoC |
