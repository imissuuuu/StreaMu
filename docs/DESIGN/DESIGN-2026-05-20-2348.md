# システム設計書 - Opus Playback Parity
**RDD:** `RDD-2026-05-20-2348.md`  
**作成日:** 2026-05-20

## 1. 全体方針
- Opus seek は 3DS 側でコンテナ解析せず、既存と同じ `seek_seconds` を `/stream_opus_ogg` に渡す。
- サーバー側は WebM Opus を seek 秒付近から Ogg Opus stream として再生成する。Ogg stream は毎回 OpusHead / OpusTags から始める。
- 開始時間短縮は「全量remux禁止」を維持し、YouTubeのfragment情報がある場合は seek対象以前のmedia fragmentを読まない。
- MP3 fallback は開発中の退避として残すが、Opus parity の成功条件にはしない。

    if opus_track is None:

## 4. 各機能の詳細設計
### FR-1: Opus Direct seek
データフロー:
```text
seek bar -> ctx.seek_target_seconds -> YouTubeAPI.get_audio_stream_url(...)
  -> /stream_opus_ogg?i=<id>&t=<seconds>
  -> proxy.py fragment selection
  -> webm_opus_remux.py Ogg stream regeneration
  -> g_stream_buffer_ptr -> OpusPocPlayer
```

3DS側は seek 秒を捨てない。`playback_start_time` は既存コード通り seek秒を反映する。

### FR-2: 再生開始時間
`server/proxy.py` は fragment情報がある場合、対象秒より前のmedia fragmentを読まない。fragment情報がない direct URL の場合は `filesize` / `duration` からbyte位置を推定し、先頭512KBのWebM header prefix + seek位置付近のCluster以降を remuxer に渡す。Range推定に失敗した場合のみ従来通り先頭からstreamする。

ログ:
```python
add_log(
    f"Opus Ogg stream started: {v_id} ({info.ext}/{info.acodec}) "
    f"seek={seek_seconds}s fragments={len(info.fragments)}"
)
```

### FR-3 / FR-4: release前提
この設計では ffmpeg を追加しない。`/stream_opus_ogg` は Python remuxer のまま維持する。release判断は実装後の実機test結果で行う。

### FR-5: 回帰防止
AAC Direct / MP3 Proxy のURL生成分岐には触れない。hidden Opus PoC はローカルbufferからの再生なので、`seek_start_ms` 追加の影響を受けない。

## 5. 状態設計

既存状態の変更:

| 変数 | 型 | 初期値 | セット条件 | クリア条件 | 残留リスク |
|------|----|--------|-----------|-----------|-----------|
| `ctx.seek_target_seconds` | `int` | `-1` | seek bar操作 | `start_playback` 冒頭 | Opusでも破棄しないため、server側seek失敗時はfallback/Stream Errorに委ねる |
| `ctx.opus_pending_decode_start` | `bool` | `false` | Opus Direct再生開始 | Opus decoder開始/失敗/停止 | fragment skipで初回pageが遅い場合はBufferingが続く |
| `g_stream_download_complete` | `bool` | `true` | download thread完了 | streaming開始 | direct URL deep seek fallbackでは完了まで時間がかかる |

## 6. 実装順序
1. `source/main.cpp` で Opus seek 秒破棄と unsupported表示を削除。
2. `source/network/youtube_api.cpp` で Opus URL に `t` を付ける。
3. `server/webm_opus_remux.py` に `seek_start_ms` packet dropを追加。
4. `server/proxy.py` の `/stream_opus_ogg` に `t` と fragment開始選択を追加。
5. `python -m py_compile server/proxy.py server/webm_opus_remux.py server/opus_probe.py`。
6. `make clean && make`。
7. 実機test:
   - Opus Direct 通常再生の開始時間。
   - Opus Direct seek 30秒/中盤/終盤。
   - seek後の再生バー。
   - AAC Direct / MP3 Proxy 通常再生とseek。
   - hidden `L+R+X` Opus PoC。
