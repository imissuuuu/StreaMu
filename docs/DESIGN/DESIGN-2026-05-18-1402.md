# システム設計書 - Vorbis Decoder PoC
**RDD:** `RDD-2026-05-18-1402.md`
**作成日:** 2026-05-18

## 1. 全体方針
- `ctrmus` のコードはコピーせず、devkitPro portlibs の `vorbisidec` API を直接使う。
- 既存の `StreamDecoder` 抽象に `VorbisStreamDecoder` を追加する。
- 既存の AAC/MP3 playback 選択や UI は変更しない。
- 今回はローカル/完全受信済み Ogg buffer の decode PoC とし、YouTube 供給経路は後続タスクに残す。

## 2. 新規ファイル

### `source/audio/vorbis_stream_decoder.h`
```cpp
class VorbisStreamDecoder : public StreamDecoder {
public:
    VorbisStreamDecoder();
    ~VorbisStreamDecoder() override;
    void reset() override;
    StreamDecodeResult decode(const uint8_t* data, size_t size,
                              int16_t* pcm_out,
                              size_t pcm_capacity_samples) override;

private:
    struct MemoryStream;
    bool open_if_needed(const uint8_t* data, size_t size);
    void close();

    OggVorbis_File file_;
    MemoryStream stream_;
    bool opened_;
};
```

### `source/audio/vorbis_stream_decoder.cpp`
- `ov_open_callbacks` を使い、呼び出し元から渡された memory buffer を Ogg input として扱う。
- `ov_read` で PCM16 を取り出し、`StreamDecodeResult` に sample rate / channels / samples_per_channel を詰める。

## 4. 各機能の詳細設計

### FR-1: Vorbis decoder 追加
- `decode()` の入力が不正なら `{false, 0, 0, 0, 0}` を返す。
- 初回 `decode()` で Ogg stream を開く。
- open 失敗時は 1 byte 消費して caller が同期点探索できる余地を残す。
- `ov_read()` が正の byte count を返したら `ok=true` とし、消費位置は callback stream の現在位置から計算する。
- `ov_read()` が 0 以下なら `ok=false` とし、進める位置があれば `bytes_consumed` を返す。

### FR-2: build dependency
- devkitPro portlibs に `vorbisidec` / `ogg` が無い場合、link step で不足が分かる。
- 追加ライブラリは依存される `ogg` を後ろに置く。

### FR-3: 既存経路維持
- `AacPocPlayer`, `MP3Player`, settings, server は触らない。
- 新 decoder は未使用のままビルド対象にだけ入る。

### FR-4: 文書化
- `docs/POC/vorbis-decoder-poc.md` に `ctrmus` から得た確認事項を記録する。
- GPL 由来コードをコピーしていないことを明記する。

## 5. 状態設計

### `VorbisStreamDecoder::MemoryStream`
| フィールド | 型 | 内容 |
|------------|----|------|
| `data` | `const uint8_t*` | 入力 buffer |
| `size` | `size_t` | 入力 byte 数 |
| `offset` | `size_t` | callback が読み終えた byte 位置 |

### `VorbisStreamDecoder`
| フィールド | 型 | 初期値 | 内容 |
|------------|----|--------|------|
| `file_` | `OggVorbis_File` | zero init | Tremor/Vorbis file state |
| `stream_` | `MemoryStream` | zero init | memory callback state |
| `opened_` | `bool` | `false` | `ov_clear` が必要かどうか |
