# システム設計書 - AAC Direct Promotion
**RDD:** `RDD-2026-05-18-1247.md`
**作成日:** 2026-05-18

## 1. 全体方針
- 既存の AAC ADTS 実装をそのまま正式経路へ昇格し、再生・seek の処理内容は変更しない。
- `PoC` は UI 表示、設定保存値、公開 enum 名から外す。既存設定値 `aac_poc` は互換読み込みのみ残す。
- MP3 Proxy は削除せず、明示的な fallback/debug 経路として残す。
- `source/ui/theme.h` の `AppConfig` 既定値を変更するため、実装後は `make clean && make` を必須にする。

## 4. 各機能の詳細設計

### FR-1: AAC Direct 既定化
```text
ConfigManager::load()
  -> AppConfig{} で audio_path=AAC_DIRECT
  -> audio_path 欠落時は "aac_direct"
  -> "mp3" のみ MP3_PROXY
  -> それ以外は AAC_DIRECT
```

### FR-2: UI 表示の正式化
```text
SettingsScreen::get_item_value(ITEM_AUDIO_PATH)
  AAC_DIRECT -> "AAC Direct"
  MP3_PROXY  -> "MP3 Proxy"

SettingsScreen::get_item_description(ITEM_AUDIO_PATH)
  AAC Direct default / MP3 Proxy fallback を短く表示
```

### FR-3: 既存設定互換
```text
audio_path == "aac_poc"      -> AAC_DIRECT
audio_path == "aac_direct"   -> AAC_DIRECT
audio_path missing/unknown   -> AAC_DIRECT
audio_path == "mp3"          -> MP3_PROXY
```

保存時は `aac_direct` / `mp3` のみを書き出す。

### FR-4: MP3 Proxy fallback 維持
Settings の切替処理は 2 択のまま維持する。
```cpp
editing_config_.audio_path =
    editing_config_.audio_path == AudioPathConfig::MP3_PROXY
        ? AudioPathConfig::AAC_DIRECT
        : AudioPathConfig::MP3_PROXY;
```

### FR-5: AAC 初期化失敗時の退避
起動時の既存 fallback 判定を新 enum 名へ置換する。
```cpp
if (!aac_player.init() && ctx.config.audio_path == AudioPathConfig::AAC_DIRECT) {
  ctx.config.audio_path = AudioPathConfig::MP3_PROXY;
}
```

## 6. 実装順序
1. `source/ui/theme.h` の enum と既定値を `AAC_DIRECT` へ変更する。
2. `include/network/youtube_api.h` と `source/network/youtube_api.cpp` の `AudioPath` 名を `AacDirect` へ変更する。
3. `source/config_manager.h` の読み書きを `aac_direct` 既定・旧 `aac_poc` 互換に変更する。
4. `source/ui/screens/settings_screen.cpp` の表示名、説明、切替 enum 名を変更する。
5. `source/main.cpp` の enum 参照を変更する。
6. `rg "AAC_ADTS_POC|AacAdtsPoc|AAC PoC|aac_poc"` で残存箇所を確認し、過去 RDD/DESIGN/POC 以外の残りを判断する。
7. ヘッダ変更があるため `make clean && make` を実行する。
8. `git diff --check` を実行する。
