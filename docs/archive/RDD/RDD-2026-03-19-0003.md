# RDD - 2026-03-19-0003
**Project Name:** Phase 6-B: PlayBar シャッフル/ループ切替 + PL再生モード選択

## 1. 機能一覧

### 機能要件
- **FR-1**: PlayBar に シャッフル/ループ切替タッチゾーンを追加（5ゾーン化）
- **FR-2**: PlaylistDetailScreen のトラックリスト先頭に SHUFFLE | ORDER ボタン行を追加
- **FR-3**: 再生モード状態管理（shuffle_mode, loop_mode）を RenderContext に追加

### 非機能要件
- **NFR-1**: 状態は AppConfig に保存しない（揮発性）。起動時デフォルト: shuffle=false, loop=OFF
- **NFR-2**: 既存の PlayingScreen・SearchScreen の再生動作に影響を与えない（SearchScreen は単曲再生のため無関係）

## 2. 詳細仕様

### FR-1: PlayBar 5ゾーン化

**入力**: タッチタップ（各ゾーン内）
**処理**:
- ゾーン0（LOOP）タップ → loop_mode を OFF→ALL→ONE→OFF… とサイクル
- ゾーン1（PREV）タップ → 既存の prev_track（キュー空なら無効）
- ゾーン2（PLAY/PAUSE）タップ → 既存の toggle_pause
- ゾーン3（NEXT）タップ → 既存の next_track（キュー空なら無効）
- ゾーン4（SHUF）タップ → shuffle_mode をトグル。ON時にキューを再シャッフル、OFF時にキューを元の順番に戻す
**出力**: アクション文字列（"toggle_loop", "prev_track", "toggle_pause", "next_track", "toggle_shuffle"）

**レイアウト（320px幅, BAR_Y=200, BAR_H=40）**:
```
|  LOOP  |  PREV  | PLAY/PAUSE |  NEXT  | SHUF  |
| 0-54   | 55-117 |  118-201   | 202-264| 265-319|
```

**表示**:
- LOOP: "OFF" / "ALL" / "ONE"（テキスト表示）
- SHUF: "SHUF"（ON時は通常色、OFF時は薄色）
- PREV/NEXT: キュー空時は薄色（既存仕様維持）
- 区切り線: 各ゾーン境界に1px の薄線

### FR-2: PlaylistDetailScreen SHUFFLE | ORDER 行

**入力**: タップ or 十字キー + A ボタン
**処理**:
- リストの先頭行（index 的に曲リストの上）に「SHUFFLE」「ORDER」の2ボタンを横並びで表示
- 行サイズ: BTM_ITEM_HEIGHT_2ROW (30px) — トラック行と同じ
- フォント: FONT_LG (0.65)
- スクロールで他のトラックと一緒に動く（固定ではない）
- 十字キーで選択可能。selected_index の扱い:
  - ボタン行を仮想 index として扱う（例: selected_index=0 がボタン行、実トラックは index=1 から）
  - または g_tracks の先頭に仮想エントリを挿入（SearchScreen の SEARCH_BTN 方式に準じる）
- SHUFFLE タップ/選択+A → shuffle_mode=true で再生開始（アクション: "start_shuffle_playback"）
- ORDER タップ/選択+A → shuffle_mode=false で順番再生開始（アクション: "start_order_playback"）

**表示**:
```
| SHUFFLE        | ORDER          |   ← 先頭行 (30px)
|---曲リスト----------------------------|
| タイトル1                              |
| 3:45 · 2.4万回 · 3年前                |
| タイトル2                              |
| ...                                   |
```
- 左半分: "SHUFFLE"、右半分: "ORDER"
- 選択時はアクセントカラーでハイライト

### FR-3: 再生モード状態管理

**RenderContext に追加するフィールド**:
```cpp
enum LoopMode { LOOP_OFF, LOOP_ALL, LOOP_ONE };
bool shuffle_mode = false;
LoopMode loop_mode = LOOP_OFF;
```

**main.cpp での処理変更**:

1. **next_track ハンドラ**:
   - LOOP_OFF: キュー末尾なら何もしない（既存動作）
   - LOOP_ALL: キュー末尾→先頭に戻る
   - LOOP_ONE: 同じ曲を再度 start_playback()

2. **prev_track ハンドラ**:
   - LOOP_OFF: キュー先頭なら何もしない（既存動作）
   - LOOP_ALL: キュー先頭→末尾に戻る
   - LOOP_ONE: 同じ曲を再度 start_playback()

3. **自動次曲（曲終了時）**:
   - 曲終了検知後、loop_mode に応じて next_track と同じロジックを適用

4. **toggle_shuffle ハンドラ**:
   - ON→OFF: play_queue を元の順番（0,1,2,...）に再構築。current_track_idx を再生中曲の元位置に更新
   - OFF→ON: play_queue を Fisher-Yates シャッフル。現在再生中の曲は先頭に配置。current_track_idx=0

5. **start_shuffle_playback / start_order_playback**:
   - shuffle_mode を設定してから既存の start_playback_from_playlist と同等の処理

- HomeScreen の PlayBar でも同様に切替可能（再生中のみ表示）
