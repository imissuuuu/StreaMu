# RDD - 2026-03-26-0100
**Project Name:** List UI Restyle

## 1. 機能一覧

### 機能要件
- **FR-1**: 選択項目にグラデーション+ベベルを適用（ホーム画面と同じスタイル）
- **FR-2**: 非選択項目に微妙な浮き出し背景+ミニベベルを適用
- **FR-3**: 再生中項目（`playing_bg`）にも浮き出し背景+ミニベベルを適用
- **FR-4**: 既存の区切り線（Settings の `text_dim` 1px線、PlayBar の縦区切り線、MODE_BTN の中央分割線）を削除

### 非機能要件
- **NFR-1**: 下画面のみ対象（上画面は変更しない）
- **NFR-2**: 3DSの描画パフォーマンスを維持（60fps目標）
- **NFR-3**: テーマシステム（ダーク/ライト、アクセントカラー）との整合性を維持

## 2. 詳細仕様

### FR-1: 選択項目のグラデーション+ベベル
- 入力: テーマの `accent` カラー
- 処理: アクセントカラーから20%暗色への垂直グラデーション + 3pxベベル（上/左=白25%、下/右=黒25%）
- 出力: ホーム画面タイルと同じ立体感のある選択バー
- 適用対象: 全リスト画面の選択項目（Search、Playlists、Playlist Detail、Playing、Settings、Wallpaper選択）

### FR-2: 非選択項目の浮き出し背景
- 入力: テーマの `bg_bottom` カラー
- 処理: `bg_bottom`より少し明るい背景色 + 微妙なベベル（上/左=白8%、下/右=黒30%）（ダークテーマ時。ライトテーマは上/左=白50%、下/右=黒10%）
- 出力: 各項目が背景からわずかに浮き出して見える
- 適用対象: 全リスト画面の非選択・非再生中項目

### FR-3: 再生中項目のスタイル
- 入力: テーマの `playing_bg` カラー
- 処理: FR-2と同じベベルスタイルだが、背景色を `playing_bg` にする
- 出力: 再生中であることが分かりつつ、他の非選択項目と統一感のあるスタイル

### FR-4: 区切り線の削除
- Settings画面: `ITEM_SEPARATOR` の1px `text_dim` 線 → 余白のみ（描画コード削除、余白は維持）
- PlayBar: ゾーン間の縦区切り線 → 削除
- MODE_BTN: 中央の分割線 → 削除

### 描画コストの考慮
- グラデーションは `GRAD_STEP=2` で描画（ホーム画面と同じ）
- 1項目あたり: グラデーション（高さ/2回）+ ベベル（4回）= 約20回のdrawcall
- 7項目表示で約140回 → ホーム画面の5タイル（約330回）より少なく、許容範囲
