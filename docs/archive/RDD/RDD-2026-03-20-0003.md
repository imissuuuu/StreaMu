# RDD - 2026-03-20-0003
**Project Name:** 起動時IP選択

## 1. 機能一覧
- **FR-1**: `AppConfig` に `server_ip` フィールドを追加し、`config.json` に保存/読み込みする
- **FR-2**: 起動時に `server_ip` が空なら、3DSソフトウェアキーボード（swkbd）でIP:Port入力を促す
- **FR-3**: 入力されたIPで接続を試行し、成功したら保存して続行
- **FR-4**: 接続タイムアウト時のメニューに「Change IP」選択肢を追加
- **FR-5**: YouTubeAPIのハードコードIPを `server_ip` 参照に置換
- **FR-6**: 設定画面にServer IP変更項目を追加
- **NFR-1**: ポート番号のデフォルトは8080。IP入力は `xxx.xxx.xxx.xxx:port` 形式

## 2. 詳細仕様

### FR-2: 起動時IP入力フロー
- 入力 → `config.server_ip` が空
- 処理 → swkbd表示（ヒントテキスト: "192.168.x.x:8080"）
- 出力 → 入力値を `config.server_ip` にセット、config保存

### FR-4: タイムアウト時メニュー
- 現状: Retry / Exit
- 変更後: Retry / Change IP / Exit
- 「Change IP」選択 → swkbd再表示 → 入力後リトライ

### FR-5: ハードコードIP置換
- `youtube_api.cpp` の3箇所の `http://192.168.10.102:8080` を `http://{server_ip}` に置換
- YouTubeAPIクラスに `server_ip` を渡す手段が必要

### FR-6: 設定画面
- 設定項目の末尾に「Server IP: xxx.xxx.xxx.xxx:8080」を追加
- 選択時にswkbdで編集可能

## 3. UI/UX考慮事項
```
起動時（IP未設定）:
┌─────────────────────────┐
│  [ソフトウェアキーボード]  │
│  Enter Server IP:Port    │
│  192.168.x.x:8080       │
└─────────────────────────┘

タイムアウト時:
  > Retry
    Change IP
    Exit
```

## 4. 追加設計情報
- `AppConfig` にフィールド追加 → `RenderContext` サイズ変更 → `make clean` 必須
- swkbdは `<3ds.h>` の `swkbdInit` / `swkbdInputText` で使用可能
- YouTubeAPIへのIP受け渡し: コンストラクタ引数 or setterメソッド
