# RDD - 2026-05-12-0001
**Project Name:** Server EXE化

## 1. 機能一覧

**機能要件:**
- **FR-1**: proxy.pyをPyInstallerで単一EXE（--onefile）にパッケージング
- **FR-2**: EXE起動時にffmpegが存在しなければ自動ダウンロード・展開
- **FR-3**: 既存のPython/venv方式（setup.py, start_server.bat）は維持

**非機能要件:**
- **NFR-1**: Windows 10/11対応（x86_64）
- **NFR-2**: ffmpegダウンロード中は進捗をコンソールに表示
- **NFR-3**: GitHub Releaseでexeを配布アセットとして添付

## 2. 詳細仕様

**FR-1 EXEビルド:**
- PyInstallerの`--onefile`で`StreaMu-Server.exe`を生成
- ビルドスクリプト（`.spec`ファイルまたはbatファイル）を`server/`に追加
- 隠しインポート: starlette, uvicorn, yt_dlp等を明示指定

**FR-2 ffmpeg自動ダウンロード:**
- 起動時にEXEと同じディレクトリでffmpeg.exeを検索
- 無ければ公開CDN（github.com/BtbN/FFmpeg-Builds等）からessentials版zipをDL
- zip展開 → ffmpeg.exeをEXEと同じディレクトリに配置
- DL失敗時はエラーメッセージ表示＋手動DL案内で終了（クラッシュしない）

**FR-3 既存方式維持:**
- setup.py, start_server.bat, requirements.txtはそのまま残す

## 3. UI/UX考慮事項

コンソール出力のみ（GUIなし）:
```

[INFO] ffmpeg not found. Downloading...
[INFO] Downloading ffmpeg (XX MB)... 45%
[INFO] ffmpeg ready.
[INFO] Server started on http://192.168.1.5:8080
```

## 4. 追加設計情報

- PyInstallerのonefile実行時、`sys.executable`は一時展開先を指す → yt-dlpのsubprocess呼び出しに影響する可能性あり（DESIGN段階で検証）
- ffmpegのDL先URLはハードコードせず、変更しやすい定数にする
- ウイルス対策ソフトの誤検出リスクあり（PyInstaller製EXEの既知問題、対処不可）
