# RDD - 2026-03-23-0002
**Project Name:** データフォルダリネーム + 初回起動IP案内

## 1. 機能一覧

### 機能要件
- **FR-1**: データフォルダのパスを `sdmc:/3ds/3ds-music-player/` → `sdmc:/3ds/StreaMu/` に変更する
- **FR-2**: 初回起動時（server_ipが空）にswkbdを表示する前に、上画面にIP入力の案内メッセージを英語で表示する

### 非機能要件
- **NFR-1**: 既存ユーザーが旧フォルダ `3ds-music-player/` を手動で `StreaMu/` にリネームすればデータを引き継げること

## 2. 詳細仕様

### FR-1: データフォルダリネーム
- **入力**: 現在のハードコードパス `sdmc:/3ds/3ds-music-player/`
- **処理**: 全ソースコード内のパス定義を `sdmc:/3ds/StreaMu/` に一括変更
- **出力**: config.json, playlists.json, wallpaper/ が全て `sdmc:/3ds/StreaMu/` 以下に配置される

### FR-2: 初回起動IP案内
- **入力**: `config.json` が存在しない、またはserver_ipが空文字列
- **処理**: swkbd表示前に上画面にIP入力案内メッセージを描画し、1フレーム以上表示する
- **出力**: 上画面に案内メッセージが表示された状態でswkbdが開く
- **メッセージ例**: "Enter the IP address of the PC running proxy.py (e.g. 192.168.1.10)"

## 3. UI/UX考慮事項

### FR-2 上画面表示
```
+------------------------------------------+
|                                          |
|                                          |
|   Enter the IP address of the PC        |
|   running proxy.py                       |
|   (e.g. 192.168.1.10)                   |
|                                          |
|                                          |
+------------------------------------------+
```
- 上画面中央に英語テキストを表示
- swkbdは下画面に出るので、案内は上画面に表示する
