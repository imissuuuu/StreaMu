# RDD - 2026-03-19-0002
**Project Name:** Phase 6-A: ホーム画面リスト化 + 再生バー共通化 + Quick Access

## 1. 機能一覧

### 機能要件
- **FR-1**: ホーム画面をボタンGrid式からスクロール可能なリスト式メニューに変更する
- **FR-2**: リスト項目: Search / Quick Access (見出し + 最大4スロット) / Playlists / Playing (再生中のみ) / Settings
- **FR-3**: Quick Access スロットにプレイリストを手動登録できる（最大4件）
- **FR-4**: Quick Access の空スロットは「+ Add Playlist」と表示し、タップでプレイリスト一覧画面へ遷移
- **FR-5**: Quick Access の登録済みスロットをタップするとプレイリスト内画面に遷移（再生はしない）
- **FR-6**: プレイリスト一覧画面のSELECTメニューに「Quick Accessに追加」「Quick Accessから削除」を追加
- **FR-7**: 再生バー（PREV / PLAY|PAUSE / NEXT）を共通コンポーネント化し、再生中はホーム画面にも常時表示する
- **FR-8**: 再生バー分の領域（y=200〜240）は再生停止時も常時確保する（レイアウト不変）
- **FR-9**: 既存FAV機能（fav_playlist_id）をQuick Accessに置き換え、FAVコードを廃止する

### 非機能要件
- **NFR-1**: リスト項目のフォントサイズは20px項目高さに収まる最大サイズを使用する
- **NFR-2**: Quick Access見出しは小さめフォント（項目ではなくセクションラベル）
- **NFR-3**: 再生バーは既存 PlayingScreen のバーデザインを流用、サイズ変更なし（40px）

## 2. 詳細仕様

### FR-1/FR-2: ホーム画面リスト式メニュー

```
┌─ Bottom Screen (320x240) ──────────┐
│ 8px padding                         │
│ Search                     ← 20px  │ タップ→検索画面
│ Quick Access               ← 15px  │ セクション見出し（選択不可）
│   [PL名 or + Add Playlist] ← 20px  │ スロット1
│   [PL名 or + Add Playlist] ← 20px  │ スロット2
│   (スロット3, 4 は登録時のみ表示)     │
│ Playlists                  ← 20px  │ タップ→PL一覧画面
│ Playing                    ← 20px  │ 再生中のみ表示 / タップ→PlayingScreen
│ Settings                   ← 20px  │ タップ→設定画面
│                                     │
│ ─── play bar (常時確保) ─── y=200  │
│ [PREV] [PLAY/PAUSE] [NEXT]  40px   │ 再生中のみ操作可能
└─────────────────────────────────────┘
```

- **入力**: タッチタップ / D-pad上下 + Aボタン
- **処理**: 選択項目に対応するアクション文字列を返す
- **出力**: 画面遷移

最大ケース（QA 4件 + Playing）: 8 + 20 + 15 + 4×20 + 20 + 20 + 20 = 183px < 192px（バー上端まで）→ スクロール不要

### FR-3/FR-4/FR-5: Quick Access スロット

- **登録**: プレイリスト一覧画面の SELECT メニューから「Quick Accessに追加」
- **解除**: 同メニューから「Quick Accessから削除」（登録済みPLの場合）
- **上限**: 4件。4件登録済みなら「Quick Accessに追加」をグレーアウトまたは非表示
- **空スロット**: 「+ Add Playlist」テキスト表示。タップでプレイリスト一覧画面へ遷移
- **登録済みスロット**: PL名を表示。タップでPL内画面へ遷移（再生しない）
- **AppConfig**: `quick_access_ids`（カンマ区切り文字列、最大4件）

### FR-6: SELECTメニュー拡張

既存 `STATE_POPUP_PLAYLIST_OPTIONS` のメニュー項目:
```
変更前: [タイトル編集] [★/☆ お気に入り登録/解除] [削除]
変更後: [タイトル編集] [Quick Accessに追加/から削除] [削除]
```

- 対象PLがQuick Accessに含まれている → 「Quick Accessから削除」
- 含まれていない & スロット空きあり → 「Quick Accessに追加」
- 含まれていない & スロット満杯 → 「Quick Access Full」（グレーアウト）

### FR-7/FR-8: 再生バー共通化

- PlayingScreen の再生バー描画コード（y=200〜240, PREV/PLAY/NEXT）を共通関数に抽出
- ホーム画面: 再生中なら共通バーを描画、停止中はバー領域を空のまま確保
- PlayingScreen: 共通関数を呼び出すように変更
- タッチ判定: バー領域のタッチ→PREV/PAUSE/NEXT のアクション（ホーム画面でも機能）

### FR-9: FAV→Quick Access置換

- `AppConfig::fav_playlist_id` → `AppConfig::quick_access_ids` に変更
- 既存FAV関連コード（home_screen.cpp の trigger_fav、main.cpp のハンドラ等）を削除
- ポップアップメニューの「お気に入り登録/解除」→「Quick Access追加/削除」に変更

## 3. UI/UX考慮事項

### ホーム画面リスト

- D-pad上下でカーソル移動（Quick Access見出しはスキップ）
- 選択中のアイテムはアクセントカラーで背景ハイライト
- Playing項目は再生中でなければ非表示（リストから消える）
- リスト全体がスクロール不要の場合、スクロール処理は不要

### Quick Access 空スロット数

- 未登録時: 1つの「+ Add Playlist」スロットのみ表示（空スロット4つ並べない）
- 登録件数 < 4: 登録済みスロット + 1つの「+ Add Playlist」を表示
- 登録件数 = 4: 「+ Add Playlist」は非表示

### 再生バー（ホーム画面）

- 再生停止中: バー領域(y=200〜240)は空のまま確保（背景色で塗る）
- 再生中: PREV/PLAY(PAUSE)/NEXT を表示（PlayingScreenと同じデザイン）
