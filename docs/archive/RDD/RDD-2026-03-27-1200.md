# RDD - 2026-03-27-1200
**Project Name:** Color Palette（カスタムS/Vスライダー追加）

## 1. 機能一覧

### 機能要件
- **FR-1**: 設定画面の ITEM_HUE の下に **ITEM_SATURATION**（彩度スライダー）を追加する（範囲: 0.00〜1.00）
- **FR-2**: ITEM_SATURATION の下に **ITEM_BRIGHTNESS**（明度スライダー）を追加する（範囲: 0.00〜1.00）
- **FR-3**: S/V いずれかのスライダーを操作したら自動的に `palette_index = -1`（カスタムモード）に切り替える
- **FR-4**: パレットからプリセット色を選択した場合、S/V はそのプリセット行の `PaletteSV` 値にリセットする
- **FR-5**: カスタム S/V 値を `config.json` に `accent_saturation` / `accent_brightness` として保存・読み込みする

### 非機能要件
- **NFR-1**: パレットグリッド（5×8、40色）は変更しない
- **NFR-2**: 既存の暗黙的切替方式（スライダー操作→カスタム、パレット選択→プリセット）を維持する
- **NFR-3**: スライダー操作中のリアルタイムプレビューを維持する

## 2. 詳細仕様

### FR-1 / FR-2: S/V スライダー追加
- **入力**: タッチドラッグ or D-pad 左右（±0.05 刻み）
- **処理**:
  - スライダー値を `editing_config_` の新フィールド `accent_saturation` / `accent_brightness` に反映
  - `apply_theme()` を呼び出してリアルタイムプレビュー
- **出力**: 画面上のテーマ色が即座に変化
- **デフォルト値**: S=0.75, V=0.78（現在の標準プリセットと同じ値）
- **操作方式**: 既存の色相スライダーと同一（ドラッグ + D-pad ±微調整 + A確定 + Bキャンセル）

### FR-3: 暗黙的カスタムモード切替
- **入力**: S/V スライダーの編集開始
- **処理**: `editing_config_.palette_index = -1` に設定
- **出力**: ITEM_COLOR の表示が "Custom" に変わる

### FR-4: パレット選択時のS/Vリセット
- **入力**: パレットグリッドから色を選択
- **処理**: 選択した行の `PaletteSV` から S/V を取得し、`accent_saturation` / `accent_brightness` に書き込む
- **出力**: S/V スライダーがプリセット値を反映

### FR-5: 設定の永続化
- **入力**: Save ボタン押下
- **処理**: `config.json` に `accent_saturation`(float) / `accent_brightness`(float) を追加保存
- **出力**: 次回起動時にカスタム S/V が復元される
- **バリデーション**: 0.0〜1.0 にクランプ。フィールド未存在時はデフォルト値（S=0.75, V=0.78）

## 3. UI/UX 考慮事項

### 設定画面レイアウト（下画面リスト）
```
 ITEM_MODE       | テーマ: Light / Dark
 ITEM_COLOR      | UIカラー: Palette / Custom
 ITEM_HUE        | 色素: [====|=========] 220    ← 虹色グラデーションバー
 ITEM_SATURATION | 彩度: [====|=========] 0.75   ← 現在の色相ベースのグラデーション（白→純色）
 ITEM_BRIGHTNESS | 明度: [====|=========] 0.78   ← 現在の色相ベースのグラデーション（黒→純色）
 ITEM_L_BUTTON   | Lボタン: ...
 ...
```

### スライダーバーの見た目
- **彩度バー**: 左端=白（S=0）→ 右端=現在の色相の純色（S=1）、明度は現在値で固定
- **明度バー**: 左端=黒（V=0）→ 右端=現在の色相の純色（V=1）、彩度は現在値で固定
- バー幅・位置は既存の色相スライダーと同一（180px, X=100）

### 操作フロー
1. ITEM_SATURATION or ITEM_BRIGHTNESS にカーソルを合わせて A で編集開始
2. タッチドラッグ or D-pad 左右で値を調整（リアルタイムプレビュー）
3. A で確定 / B でキャンセル（元の値に戻る）
