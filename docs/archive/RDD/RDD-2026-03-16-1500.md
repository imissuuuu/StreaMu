# RDD - 2026-03-16-1500
**Project Name:** Bottom-Screen List + Hamburger Nav

## 1. 機能一覧

**機能要件**
- FR-1: トラックリストを**下画面のみ**に表示（上画面のリスト描画を廃止）
- FR-2: 上画面はシステム情報・セクションタイトル・Now Playing の表示を現状維持
- FR-3: HomeScreen 以外の全画面の左下に「☰」ハンバーガーボタンを配置
- FR-4: ☰ タップで文脈依存のナビゲーションポップアップを表示
- FR-5: ポップアップ項目と状態（現在画面の項目はグレーアウト）

| 現在の画面 | ホーム | 検索 | プレイリスト | 設定 |
|-----------|--------|------|------------|------|
| SearchScreen | ✅ | ✅ | ✅ | ✅ |
| PlaylistsScreen | ✅ | ✅ | 🔘 グレー | ✅ |
| PlaylistDetailScreen | ✅ | ✅ | ✅ | ✅ |
| SettingsScreen | ✅ | ✅ | ✅ | 🔘 グレー |

- FR-6: SearchScreen の SEARCH_BTN（リスト先頭の検索ボタン）を削除
- FR-7: 「検索」はハンバーガーメニュー経由でキーボードを起動
- FR-8: 物理 B ボタンは引き続き「前の画面へ戻る」として機能（☰ は戻るを含まない）

**非機能要件**
- NFR-1: 下画面トラックリストは 7 件表示を維持
- NFR-2: タッチドラッグスクロールの滑らかさを維持（calc_scroll ベース）
- NFR-3: 既存のポップアップ（トラックオプション・プレイリスト追加等）は変更なし
- NFR-4: トラックリストは 2 行レイアウト（Row1: タイトル、Row2: duration・views・date）を維持

## 2. 詳細仕様

**FR-4 ナビゲーションポップアップ**
- 入力: ☰ タップ
- 処理: `STATE_POPUP_NAV` に遷移、`previous_state` を保存
- 出力: ポップアップ表示（既存ポップアップと同じスタイル）
- アクティブ項目タップ → 対象画面に遷移してポップアップを閉じる
- グレーアウト項目タップ → 何もしない
- 物理 B / ポップアップ外タップ → ポップアップを閉じる（前の画面へ戻らない）

**FR-1 リスト描画の変更**
- `btm_first = 0`（上画面オフセット廃止、全アイテムを下画面のみで表示）
- `draw_top_screen` からトラックリスト描画ブロックを削除

**FR-3 ハンバーガーボタン位置**
- デフォルト: 左下 (x=4, y=206, w=40, h=30)
- 将来: `AppConfig.menu_button_position` (LEFT/RIGHT) により右下にも配置可能
  - 右下: x=276, y=206, w=40, h=30
