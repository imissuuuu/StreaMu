# RDD - 2026-03-25-1200
**Project Name:** Phase 7-A ホーム画面UIリッチ化

## 1. 機能一覧

### 機能要件
- **FR-1**: 全タイルにテーマカラーベースの垂直グラデーション描画
- **FR-2**: タッチフィードバック（暗化オーバーレイ + ベベル反転 + インセットボーダー + テキスト座標シフト）
- **FR-3**: ベベル効果（上/左辺にハイライト、下/右辺にシャドウ）で立体感を表現

### 非機能要件
- **NFR-1**: 既存テーマシステム（ダーク/ライト、アクセントカラー変更）との整合性を維持
- **NFR-2**: 3DSの描画パフォーマンスを維持（60fps目標）

## 2. 詳細仕様

### FR-1: 垂直グラデーション
- 入力: テーマのアクセントカラー（`theme->accent`）
- 処理: タイル上部をベースカラー、下部に向かって明度を20%減衰させる線形補間
- 描画: 高さ1pxの水平矩形をY軸方向に連続描画
- 出力: 全タイル（Search, Playlists, Settings, Quick Access, Playing）にグラデーション背景
- 選択中（D-pad）のタイルにも適用

### FR-2: タッチフィードバック
タッチダウン中に以下4つを同時適用。離すと即座に元に戻る。

1. **暗化オーバーレイ**
   - 処理: タイル全体の上に黒色（#000000）矩形を不透明度20%で重ね描き
   - 出力: 環境光が遮られたような暗化表現

2. **ベベル反転**
   - 処理: FR-3のベベルの明暗を入れ替える（上/左が暗、下/右が明）
   - 出力: 浮き上がっていたタイルが押し込まれたような錯視

3. **インセットボーダー**
   - 処理: タイル内側に3pxの枠線を背景色（`theme->bg`）で描画
   - 出力: 背景がタイル内部に侵食したように見え、沈み込みを強調

4. **テキスト座標シフト**
   - 処理: タイル内テキストのX座標を+2px、Y座標を+2px
   - 出力: テキストが奥に押し込まれたような立体感

### FR-3: ベベル効果
- 通常状態（浮き上がり）:
  - 上辺・左辺: 白色25%透過の3px帯（ハイライト）
  - 下辺・右辺: 黒色25%透過の3px帯（シャドウ）
- タッチ時: FR-2により明暗が反転

### タッチ操作
- タッチダウン: 対象タイルにFR-2の4効果を即時適用
- タッチアップ: 全効果を即時解除、タップ判定でアクション実行
- D-pad選択: グラデーション＋ベベル表示（タッチフィードバックは適用しない）

## 4. 追加設計情報

### 描画制約
- citro2dの`C2D_DrawRectSolid`のみ使用（角丸・ぼかし不可）
- グラデーションは矩形重ね描きで実現するため、タイルの高さ分のdrawcallが発生
- パフォーマンス懸念がある場合、グラデーションのステップ数を減らす（1px刻み→2px刻み等）

### 既存コードへの影響
- `source/ui/screens/home_screen.cpp`: draw_bottom()のタイル描画ロジック変更
- `source/ui/screens/home_screen.h`: タッチ状態管理の追加（押下中タイルID）
- `source/ui/ui_constants.h`: ベベル・グラデーション・フィードバック関連の定数追加
