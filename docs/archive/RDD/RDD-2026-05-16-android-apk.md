# RDD - 2026-05-16
**Project Name:** StreaMu Android Proxy Server APK

## 1. 機能一覧
- FR-1: StreaMu 用プロキシサーバーを Android APK として提供する。
- FR-2: Android 端末は 3DS と同じ LAN 上で `0.0.0.0:8080` を待ち受ける。
- FR-3: 既存 3DS クライアントの通信仕様を維持し、`/search`, `/stream`, `/thumbnail`, `/api/logs`, `/` の互換エンドポイントを提供する。
- FR-4: 3DS 側アプリは今回変更しない。3DS には Android 端末の IP アドレスを入力して接続する。
- FR-5: APK 画面にはサーバー状態、Android 端末の IP アドレス、3DS に入力する接続先、直近ログを表示する。
- FR-6: サーバーはユーザー操作でのみ開始・停止する。
- FR-7: サーバー起動中はアプリ画面と Android 通知の両方で起動状態を明示する。
- FR-8: サーバー停止中はバックグラウンド処理、ネットワーク待受、YouTube 抽出、音声変換処理を行わない。
- FR-9: README に Android APK の使い方、制約、既存 PC サーバーとの使い分けを追記する。

## 2. 非機能要件
- NFR-1: メモリ使用量とバッテリー消費を最小限に抑える。
- NFR-2: 接続待機中は軽量な HTTP 待受に留め、検索・抽出・変換処理はリクエスト時だけ実行する。
- NFR-3: ユーザーが認識できない自動起動、常駐、端末再起動後の自動復帰は行わない。
- NFR-4: Android foreground service を使う場合は通知を必ず表示し、通知またはアプリ画面から停止できるようにする。
- NFR-5: 既存 Windows/Mac/Linux サーバーの挙動を壊さない。
- NFR-6: Play Store 公開ではなく、まず sideload 用 APK を生成できる状態をゴールにする。
- NFR-7: 外部公開、ポート開放、インターネット越し接続は範囲外とし、LAN 内利用を前提にする。

## 3. 詳細仕様
- 入力:
  - Android ユーザーが APK を起動し、Start ボタンでサーバーを開始する。
  - 3DS ユーザーが Android 画面に表示された IP アドレスを StreaMu に入力する。
- 処理:
  - APK は明示操作後に StreaMu 互換 HTTP サーバーを起動する。
  - 起動中は foreground service と通知で状態を示す。
  - `/search` は YouTube 検索結果を既存形式のタブ区切りテキストで返す。
  - `/thumbnail` は既存と同じ画像レスポンスを返す。
  - `/stream` は既存 3DS クライアントが再生可能な音声ストリームを返す。
  - Stop 操作時は待受、進行中プロセス、バックグラウンド処理を停止する。
- 出力:
  - 成功時は 3DS から Android 端末上のサーバーへ接続し、検索・再生できる。
  - 失敗時は Android 画面とログに原因を表示する。

## 4. UI/UX考慮事項
- 初期状態は停止中とし、勝手にサーバーを起動しない。
- 起動中か停止中かを一目で判断できるステータス表示にする。
- 3DS に入力する値は `http://<Android IP>:8080` の形で大きく表示する。
- Start/Stop は迷わず操作できる主要操作にする。
- 起動中通知には StreaMu サーバーが動作中であることを明記する。
- 通知またはアプリ画面から停止できる導線を用意する。

## 5. 追加設計情報
- 実装方式候補:
  - Kotlin/Android + Python 埋め込みで既存 `proxy.py` のロジックを最大限再利用する。
  - Kotlin ネイティブで YouTube 抽出と音声配信を再実装する。
  - Termux など外部アプリ前提の手順にする。
- 推奨方針:
  - 既存資産の再利用性を優先し、Android アプリ内にサーバー処理を組み込む方式を検討する。
  - Android 10 以降ではアプリの書き込み可能ディレクトリから後置き実行ファイルを起動できないため、Windows EXE 版の `ffmpeg.exe` / `yt-dlp.exe` 初回ダウンロード方式はそのまま採用しない。
- 範囲外:
  - 3DS 側通信仕様の変更。
  - Play Store 公開対応。
  - 外部ネットワーク公開。
  - 端末起動時の自動サーバー起動。
