# RDD - 2026-03-26-1200
**Project Name:** List UI Restyle v2 (Minimal Flat + Dashed)

## 1. 機能一覧

### 機能要件
- **FR-1**: 選択項目にアクセントカラーのソリッド塗り + 左端3pxバー（明るめアクセント）を適用
- **FR-2**: 再生中項目にアクセントカラーの薄いティント背景（約10-15%透過）を適用
- **FR-3**: 通常項目は背景塗りなし（現状維持）
- **FR-4**: 項目間の区切り線を実線（solid）から点線（dashed）に変更
- ~~**FR-5**~~: 削除（Settings画面・PlayBar・MODE_BTNは変更しない）

### 非機能要件
- **NFR-1**: 下画面のみ対象（上画面は変更しない）
- **NFR-2**: 描画パフォーマンスを維持（グラデーション・ベベル不使用なので負荷増は最小）
- **NFR-3**: テーマシステム（ダーク/ライト、アクセントカラー）との整合性を維持
- **NFR-4**: タッチ/D-pad操作への影響なし（視覚的変更のみ）

## 2. 詳細仕様

### FR-1: 選択項目のスタイル
- 入力: テーマの `accent` カラー
- 処理:
  - 背景: `accent` カラーでソリッド塗り（グラデーションなし）
  - 左バー: 幅3px、色は `accent` より明るめ（白を25%ブレンド程度）、項目の左端に上から下まで描画
- 出力: 現在の `accent` ベタ塗りに左端のハイライトバーが追加された選択表現
- 適用対象: 全リスト画面の選択項目（Search、Playlists、Playlist Detail、Playing、Settings、Wallpaper選択）

### FR-2: 再生中項目のスタイル
- 入力: テーマの `accent` カラー
- 処理: `accent` カラーを約10-15%の透過度で背景に適用（ダークテーマ: `rgba(accent, 0.10)`、ライトテーマ: `rgba(accent, 0.07)`）
- 出力: 通常項目よりわずかに色づいた背景で再生中であることを示す
- 適用対象: 全リスト画面の再生中（非選択）項目
- テキスト色: タイトルをアクセント系の色に変更（既存の `playing_text` 活用）

### FR-3: 通常項目
- 変更なし。背景塗りなし、テキスト色は `text_body` / `text_dim` のまま

### FR-4: 区切り線の点線化
- 入力: なし（描画パラメータの変更）
- 処理: 項目間のセパレータ線を `solid 1px` → `dashed 1px` に変更
  - ダークテーマ: 白8%程度の透過度
  - ライトテーマ: 黒8%程度の透過度
  - dashedパターン: 3DSのcitro2d描画能力に合わせて実装（ドット間隔2-4px程度）
- 出力: レトロ感のある点線セパレータ
- 適用対象: 全リスト画面の項目間

### ~~FR-5~~: 削除
Settings画面・PlayBar・MODE_BTNは変更しない（使いやすさ優先）。

### 描画コストの考慮
- ソリッド塗り + 3px矩形 + dashed線のみ → グラデーション/ベベル不使用
- 1項目あたり: 背景矩形(1回) + 左バー矩形(1回) + dashed線(数回) ≈ 5-8回のdrawcall
- 7項目で約50回 → 前回案(140回)の半分以下、パフォーマンス問題なし

### dashed線の実装について
- citro2dには `dashed` 描画の直接APIはない
- 短い矩形をループで等間隔に描画するか、既存のdraw系関数を拡張する必要がある
- 詳細はDESIGNで設計
