# RDD - 2026-03-22-0002
**Project Name:** 3DS Device Compatibility (New 3DS Speedup)

## 1. 機能一覧

### 機能要件 (FR)
- **FR-1**: New 3DS で起動時に高クロックモード（804MHz + L2キャッシュ）を有効化する

### 非機能要件 (NFR)
- **NFR-1**: 旧 3DS では何も変わらないこと（エラーにならない）
- **NFR-2**: 既存の動作に影響を与えないこと

## 2. 詳細仕様

### FR-1: New 3DS 高クロック有効化
- 入力: なし（起動時に自動実行）
- 処理: `osSetSpeedupEnable(true)` を呼ぶ。旧 3DS では自動的に無視される（libctru の仕様）
- 出力: New 3DS で CPU 268MHz → 804MHz、L2キャッシュ有効化

## 3. UI/UX考慮事項
- なし（UI変更なし）

## 4. 追加設計情報
- 変更対象: `source/main.cpp` の初期化セクションに1行追加
- `osSetSpeedupEnable` は旧 3DS で呼んでも安全（何も起きない）
- APT 初期化後に呼ぶ必要がある
