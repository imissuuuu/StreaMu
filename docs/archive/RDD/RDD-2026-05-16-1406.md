## 2. 詳細仕様
- 入力: ユーザーが Mac/Linux のターミナルで `server/start_server.sh` を実行する。
- 処理:
  - スクリプト自身の場所を基準に `server/` へ移動する。
  - 利用可能な Python コマンドを検出し、バージョンが 3.10 以上であることを確認する。
  - `venv` がなければ作成する。
  - venv 内の Python/pip を使って `requirements.txt` をインストールする。
  - `ffmpeg` がローカルまたは PATH に存在するか確認する。
  - `ffmpeg` が無い場合は OS 別の導入案内を表示して終了する。
  - 条件を満たした場合は venv 内 Python で `proxy.py` を起動する。
- 出力:
  - 成功時は従来通り `http://<PCのIP>:8080` でサーバーが起動する。
  - 失敗時は原因と次に実行すべきコマンド例をコンソールに表示する。
