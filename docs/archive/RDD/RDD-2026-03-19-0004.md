# RDD - 2026-03-19-0004
**Project Name:** Phase 5-E: PlayingScreen SELECT挙動統一

## 1. 機能一覧

### 機能要件
- **FR-1**: PlayingScreen で SELECT を押すと STATE_POPUP_TRACK_OPTIONS を開く（PlaylistDetailScreen と同じ挙動）
- **FR-2**: TRACK_OPTIONS から「削除」を選ぶと active_playlist_id のプレイリストから該当曲を削除する

### 非機能要件
- **NFR-1**: 既存の SearchScreen / PlaylistDetailScreen の SELECT 挙動に影響を与えない

## 2. 詳細仕様

### FR-1: PlayingScreen での SELECT

**入力**: PlayingScreen 表示中に SELECT ボタン押下
**処理**:
- playing_tracks が空でなく、selected_index が有効な場合:
  - `previous_state = STATE_PLAYING_UI`
  - `current_state = STATE_POPUP_TRACK_OPTIONS`
  - `selected_track_id = playing_tracks[selected_index].id`
- MODE_BTN 行は対象外（playing_tracks には MODE_BTN は含まれない）
**出力**: TRACK_OPTIONS ポップアップ表示

### FR-2: 削除処理

**入力**: TRACK_OPTIONS ポップアップで「削除」を選択（previous_state == STATE_PLAYING_UI）
**処理**:
1. `playlist_manager.remove_track(active_playlist_id, selected_track_id)` で PL から削除
2. `playlists` を再読み込み
3. `playing_tracks` からも該当曲を除去（再生中リストの同期）
4. `play_queue` を再構築（インデックスが変わるため）
5. 再生中の曲が削除された場合は次の曲へ遷移（or 停止）
**出力**: ポップアップ閉じ、リスト更新

## 3. UI/UX考慮事項

- ポップアップの項目数: 3項目（詳細/削除/追加） — PlaylistDetailScreen と同じ
- 削除後もPlayingScreenに留まる（画面遷移なし）
