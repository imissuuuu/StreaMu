# RDD - 2026-03-28-1200
**Project Name:** Thumbnail（本実装）

## 1. 機能一覧

### 機能要件
- **FR-1**: PlayingScreen の上画面左側にサムネイルを表示する
- **FR-2**: Settings 以外のすべての画面で、再生中であれば上画面左側にサムネイルを表示する
- **FR-3**: サムネイルは非同期でダウンロードし、取得完了次第表示に切り替える（フリーズなし）
- **FR-4**: サムネイル画像は中央クロップで正方形に切り出して表示する（4:3→1:1）
- **FR-5**: 再生曲が変わったら新しいサムネイルを非同期取得する
- **FR-6**: キャッシュは直近1枚（再生中の曲）のみ保持する

### 非機能要件
- **NFR-1**: サムネイル取得中も UI がフリーズしないこと
- **NFR-2**: サムネイル取得失敗時はサムネイルなしで継続（クラッシュしない）
- **NFR-3**: アプリ終了時に GPU テクスチャを正しく解放すること（既修正済み）

## 2. 詳細仕様

### FR-1 / FR-2: 表示位置・条件
- 上画面（400×240）の左側に 128×128 で表示（暫定 x=8, y=56）
- 表示条件: `thumbnail_tex.is_loaded()` かつ `current_state != STATE_SETTINGS`（および設定関連状態）
- Settings 除外対象: `STATE_SETTINGS`

### FR-3: 非同期ダウンロード
- 再生曲 ID が変わったとき（`playing_id != thumbnail_vid_id`）にスレッドを起動
- スレッド内で `YouTubeAPI::download_thumbnail()` を呼び出す
- 取得完了後に `thumbnail_tex.load_from_memory()` でテクスチャ化
- スレッド間同期は既存の `LightLock` を使用
- スレッドが動いている間に別曲に変わった場合: 完了後に ID 不一致を検出して破棄（再取得）

### FR-4: 中央クロップ（正方形切り出し）
- `stbi_load_from_memory` でデコード後、ピクセルデータをクロップしてから `load_from_pixels()` へ渡す
- クロップ方法: `short_side = min(w, h)`、中央から `short_side×short_side` を切り出す
- 切り出し後のサイズが 2 のべき乗でない場合はそのまま `C3D_TexInit`（128×128 が最近傍）

### FR-5: 曲変更検知
- `on_enter()` の同期取得を廃止し、メインループで `playing_id != thumbnail_vid_id && !thumbnail_loading` を検知してスレッド起動
- `thumbnail_vid_id` はスレッド起動時点で更新（二重起動防止）

### FR-6: キャッシュ
- `AppContext::thumbnail_tex`（Wallpaper 1枚）のみ保持
- 新曲取得時に `unload()` → 取得完了後に `load_from_pixels()` で上書き

## 3. UI/UX 考慮事項

### 上画面レイアウト（暫定）
```
+------------------------------------------+
| [Status Bar]                  12:00  WiFi |  y=0..20
|  [Thumb ]  Section Title                  |  y=56..184
|  128x128   "Now Playing"                  |
|            Track Title                    |
|            Meta info                      |
| [Now Playing Bar ========================]|  y=190..240
+------------------------------------------+
```
- サムネイル: x=8, y=56（ステータスバー下・再生バー上の中間）
- 右側の曲情報エリアは現状の描画位置を維持（テキスト x 開始位置を +140 程度にオフセット）

### 表示切り替え
- 取得中: サムネイルなし（何も表示しない）
- 取得完了: フェードなし、即時表示

### Settings 画面
- 上画面はそのまま（サムネイル非表示）

## 4. 追加設計情報

### 制約
- スレッド: `libctru` の `threadCreate` を使用（`std::thread` 禁止）
- `std::atomic` 禁止（coding-patterns.md #6）
- GPU テクスチャ操作はメインスレッドのみ（`load_from_pixels()` をスレッド内で呼ばない）
  → スレッドはバイト列取得のみ行い、完了フラグ+バイト列を共有、メインスレッドでテクスチャ化

### 既存コードへの影響
- `source/app_context.h`: スレッド管理用フィールド追加（フラグ、バイト列バッファ）
- `source/ui/wallpaper.cpp`: `load_from_pixels()` にクロップ処理追加
- `source/ui/ui_renderer.cpp`: サムネイル表示条件の変更、テキスト x オフセット調整
- `source/ui/screens/playing_screen.cpp`: `on_enter()` の同期取得を削除
- `source/main.cpp`: メインループにサムネイル取得トリガー追加、スレッド管理
