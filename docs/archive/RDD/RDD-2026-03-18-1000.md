# RDD - 2026-03-18-1000
**Project Name:** Playing UI Screen

## 1. 機能一覧

**機能要件**
- FR-01: playing UI 画面の新規追加（上画面 + 下画面の2画面構成）
- FR-02: 上画面：バナー（全画面共通）— 時刻・バッテリー情報を表示、色変更対応
- FR-03: 上画面：背景 — デフォルト白、設定で任意の画像を割り当て可能
- FR-04: 上画面：曲情報バー — 曲名 と 曲の長さ（例: `3:45`）を表示
- FR-05: 下画面：ホームボタン — タップでホーム画面へ遷移
- FR-06: 下画面：曲一覧 — 再生中プレイリストのトラックリストを表示
- FR-07: 下画面：再生タッチUI — 戻る / 再生切替（再生・一時停止）/ 進む の3ボタン
- FR-08: playing UI の表示トリガー
  - ホーム画面の「再生中（4番）」をタップしたとき
  - プレイリストの再生を開始したとき
- FR-09: 再生タッチUI（10）の色はUIブロック色と同期

**非機能要件**
- NFR-01: ライト/ダーク 2種のテーマに対応（背景色・文字色・選択アウトライン連動）
- NFR-02: バナーはすべての画面で固定表示
- NFR-03: 再生タッチUI は将来のアイコン（▶ 等）化を考慮した構造にする
- NFR-04: 検索結果から再生したときの挙動は今回スコープ外（後フェーズで定義）

## 2. 詳細仕様

**FR-08 画面遷移**
- 入力: ホーム画面の「4番」タップ、またはプレイリスト再生開始
- 処理: `STATE_PLAYING_UI` へ遷移
- 出力: playing UI を描画

**FR-05 ホームボタン**
- 入力: 下画面左側のホームボタンタップ
- 処理: `STATE_HOME` へ遷移
- 出力: ホーム画面を描画

**FR-04 曲情報バー**
- 入力: 再生中トラック情報（`ctx.g_tracks` 等）
- 処理: 再生中の曲名 + 曲の長さを取得
- 出力: 上画面の曲情報バーに `曲名  3:45` の形式で表示

**FR-07 再生タッチUI**
- 入力: 下画面の戻る / 再生切替 / 進む ボタンタップ
- 処理: 対応する再生操作を実行
- 出力: 再生状態を更新
- 色: UIブロック色と同期（テーマ変更で自動更新）

**FR-06 曲一覧**
- 再生中プレイリストのトラックリストを下画面に表示
- 既存の `calc_scroll` / `y_base` スクロール機構を流用

## 4. 追加設計情報

**実装上の制約**
- `std::atomic` 禁止。スレッド同期は `LightLock` のみ（→ HANDOFF 参照）
- `C2D_Text` はキャッシュせず毎フレーム `C2D_TextParse()` する
- テーマカラーは `RenderContext::theme` のポインタ経由で参照（値コピー禁止）
