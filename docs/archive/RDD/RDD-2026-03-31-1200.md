# RDD - 2026-03-31-1200
**Project Name:** BrowseComp Qwen Evaluator

## 1. 機能一覧

### 機能要件
- FR-1: BrowseComp問題CSVをAzure BlobからDLし、canaryキーで復号する
- FR-2: Qwen（llama-server、ポート1234）をOpenAI互換APIで呼び出す
- FR-3: Qwenに2つのツールを提供する
  - `web_search`: スニペットのみ取得（includeContent: false, limit: 10）
  - `browse_url`: 特定URLのフルページ取得（browser-use CLI）
- FR-4: エージェントループ（最大10回）でQwenが自律的に検索・取得・回答を判断する
- FR-5: Claude API（anthropic SDK）で回答を採点（正解/不正解）
- FR-6: 実行問題数をCLI引数で指定可能（デフォルト: 5問）
- FR-7: 結果をMarkdownファイルに保存（`C:/dev/qwen/browsecomp-results/`）

### 非機能要件
- NFR-1: Windows環境（bash）で動作
- NFR-2: llama-serverは起動済み前提（自動起動しない）
- NFR-3: Claude API keyは環境変数 `ANTHROPIC_API_KEY` から取得
- NFR-4: 進捗をリアルタイムでコンソール出力（問題番号・ループ回数・ツール呼び出し内容）

## 2. 詳細仕様

### FR-1: 問題取得・復号
- 入力: `https://openaipublic.blob.core.windows.net/simple-evals/browse_comp_test_set.csv`
- 処理: pandasでCSV読み込み → `decrypt(row["problem"], row["canary"])` で復号
- 出力: `{question: str, answer: str}` のリスト
- 復号アルゴリズム: SHA256からXORキー生成（browsecomp_eval.pyと同じ実装）

### FR-2/3/4: エージェントループ
```
入力: question（復号済み）
処理:
  1. Qwenにquestion + ツール定義を送信
  2. Qwenがtool_callを返したら実行（web_search or browse_url）
  3. ツール結果をmessagesに追加して再送信
  4. Qwenがtool_callなしで回答したらループ終了
  5. ループ上限10回で強制終了
出力: Qwenの最終回答テキスト
```

- `web_search`: web-search-mcp（stdio JSON-RPC）をサブプロセスで起動
- `browse_url`: `PYTHONIOENCODING=utf-8 browser-use open <URL> && browser-use eval "document.body.innerText"` をサブプロセスで実行

### FR-5: 採点
- 入力: question, correct_answer, qwen_response
- 処理: Claude API（claude-sonnet-4-6）にGRADER_TEMPLATEで送信
- 出力: `"yes"` or `"no"`

### FR-6: CLI
```
python3 browsecomp_qwen.py [--num N] [--port PORT]
  --num N    : 評価問題数（デフォルト: 5）
  --port PORT: llama-serverポート（デフォルト: 1234）
```

### FR-7: 結果保存
