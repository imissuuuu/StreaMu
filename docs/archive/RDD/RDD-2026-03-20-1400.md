# RDD - 2026-03-20-1400
**Project Name:** 設定画面スクロール対応

## 1. 機能一覧

### 機能要件
- **FR-1**: 設定画面のD-padスクロール — `selected_item_` の位置に応じて表示領域が自動追従し、Save ボタンが画面外に押し出されないようにする
- **FR-2**: 設定画面のタッチスワイプスクロール — スワイプ上下でリストをスクロールできる。既存の two-tap 操作と競合しない

### 非機能要件
- **NFR-1**: パレットモード・HUEスライダー・D-Pad Speedスライダー・壁紙選択モードの既存動作に影響を与えないこと

## 2. 詳細仕様

### FR-1: D-padスクロール
**入力**: D-pad UP/DOWN で `selected_item_` が変化
**処理**: `scroll_offset`（ピクセル単位）を計算し、選択中の項目が画面の可視領域内に収まるよう追従する
**出力**: 全項目（Save含む）が重ならず正しく表示される。フッターは固定位置（y=224）

### FR-2: タッチスワイプスクロール
**入力**: タッチスワイプ（上下方向のドラッグ）
**処理**: `touch_state` の移動量（dy）を `scroll_offset` に反映する。`was_tap` が true（移動量が閾値以下）の場合は従来の two-tap 処理を実行し、スクロールは行わない
**出力**: スワイプでリストがスクロールする。タップ操作は従来通り動作する

## 3. UI/UX考慮事項
- 3DS下画面は 320x240。フッター（y=224, 高さ16px）を除いた可視領域は y=0〜224
- 項目高さ 28px、セパレータ 20px。全項目の合計高さ = 7項目×28 + 20(sep) = 216px + Save 28px = 244px（画面に収まらない）
- スクロールバーは不要（項目数が少ないため位置感覚で十分）
- スライダー編集モード中（HUE, D-Pad Speed）のスクロールは無効化する（ドラッグ操作と競合するため）
