# RDD - 2026-03-20-1500
**Project Name:** ステータスバーアイコン描画

## 1. 機能一覧

### 機能要件
- FR-1: WiFiアイコンを `C2D_DrawRectSolid` による図形描画で表示する（5状態）
- FR-2: バッテリーアイコンを `C2D_DrawRectSolid` による図形描画で表示する（7状態）
- FR-3: 既存のテキスト表示（`Wi-Fi: 2/3  Bat: 4/5`）をアイコン表示に置換する
- FR-4: 時計表示（`HH:MM`）は現状維持

### 非機能要件
- NFR-1: PNG/romfs不要。図形描画のみで実装する
- NFR-2: 既存のステータスバー領域（Y=0〜20, 幅400px）内に収める

## 2. 詳細仕様

### FR-1: WiFiアイコン（5状態）

表現: 高さの異なる3本の縦バー（左から低→高）

| 状態 | 描画 |
|------|------|
| 切断 | ×マーク（白2本の斜線） |
| 0 (接続済み・信号なし) | 3本すべて灰色 |
| 1 | 1本目白、残り灰 |
| 2 | 1-2本目白、残り灰 |
| 3 | 全白 |

- バーの幅: 3px、間隔: 2px
- バーの高さ: 1本目=6px、2本目=10px、3本目=14px
- 底辺揃え（ステータスバー下端に合わせる）
- 入力: `osGetWifiStrength()` → 0〜3、切断は `ctx.is_server_connected` ではなく WiFi強度判定（要確認）

### FR-2: バッテリーアイコン（7状態）

表現: 横向き電池型の外枠 + 内部ゲージバー

| 状態 | 描画 |
|------|------|
| 0 | 外枠のみ（空） |
| 1 | ゲージ 1/5 |
| 2 | ゲージ 2/5 |
| 3 | ゲージ 3/5 |
| 4 | ゲージ 4/5 |
| 5 | ゲージ 5/5（満充電） |
| 充電中 | 現ゲージ量 + ⚡マーク（右横に描画） |

- 外枠サイズ: 幅18px × 高さ10px + 右端に突起（端子）2px×4px
- 内部ゲージ: 外枠内を5分割、レベルに応じて塗りつぶし
- 充電中検知: `PTMU_GetBatteryChargeState()` → u8
- ⚡マーク: 小さな稲妻型を2本の斜線で表現

### FR-3: レイアウト配置

```
[WiFiアイコン] [間隔] [Batアイコン][⚡] [間隔] [HH:MM]     [VERSION]
|<-- 左寄せ                                    右寄せ -->|
```

- WiFiアイコン開始X: 8px (TOP_MARGIN_X)
- 各要素間のスペース: 8px
- 時計・バージョンは既存位置を維持

## 3. UI/UX考慮事項
- アイコンはステータスバーの `accent` 背景色上に描画
- アクティブバーの色: `accent_text` カラー（白 or 黒、テーマ依存）
- 非アクティブバーの色: `accent_text` を半透明化（alpha 80程度）
- 充電⚡マークの色: `accent_text` と同色

## 4. 追加設計情報
