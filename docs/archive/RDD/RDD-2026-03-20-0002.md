# RDD - 2026-03-20-0002
**Project Name:** 全システムメッセージ英語化

## 1. 機能一覧
- **FR-1**: ユーザーに表示される全ての日本語テキストを英語に置換する
- **NFR-1**: 3DSのフォントで表示可能なASCII文字のみ使用する

## 2. 詳細仕様
- **対象ファイル**: `source/ui/ui_renderer.cpp` のみ
- **置換一覧**:

| 日本語 | 英語 |
|--------|------|
| `[ 新規作成 ]` | `[ Create New ]` |
| `タイトルを編集` | `Edit Title` |
| `Quick Accessから削除` | `Remove from Quick Access` |
| `Quick Accessに追加` | `Add to Quick Access` |
| `削除 (元に戻せません)` | `Delete (Cannot Undo)` |
| `詳細を表示` | `Show Details` |
| `このプレイリストから削除` | `Remove from Playlist` |
| `プレイリストに追加` | `Add to Playlist` |
| `[ 閉じる ]` | `[ Close ]` |
| `本当に終了しますか？` | `Exit App?` |
| `いいえ (戻る)` | `No (Back)` |
| `はい (HOMEへ)` | `Yes (Exit)` |
| `キャンセル` | `Cancel` |

## 3. UI/UX考慮事項
- ポップアップ幅に収まる短い英語を使用する
- 既に英語のテキスト（"Track Options", "Playlist Options"等）はそのまま

## 4. 追加設計情報
- 変更対象: `source/ui/ui_renderer.cpp` の `draw_popup_overlay()` 内のみ
- コメント（日本語）は変更しない（ユーザーには表示されない）
