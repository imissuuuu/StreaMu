# RDD - 2026-03-23-0001
**Project Name:** フレンドリスト旧タイトル/アイコン修正

## 1. 機能一覧

### 機能要件
- **FR-1**: フレンドリストに現在の正しいタイトル名「StreaMu」と現行アイコンが表示されること
- **FR-2**: 旧タイトル「3ds_music_player」関連の残存ファイル（`3ds_music_player.smdh`）を削除すること

### 非機能要件
- **NFR-1**: 修正後もCIA/3DSXビルドが正常に動作すること
- **NFR-2**: 既存のセーブデータ（config.json等）に影響しないこと

## 2. 詳細仕様

### FR-1: フレンドリスト表示の修正
- **入力**: 現在のCIAインストール状態（旧タイトル表示）
- **処理**:
  1. 旧SMDHファイル削除
  2. `make clean && make cia` で完全再ビルド
  3. 3DS本体で旧CIAをFBIで完全削除 → 新CIAをインストール
  4. 解消しない場合 → `app.rsf` の UniqueId を変更（例: `0xFF3D0` → `0xFF3D1`）して再ビルド・再インストール
  5. それでも解消しない場合 → フレンドリストキャッシュクリア手順を調査
- **出力**: フレンドリストに「StreaMu」と正しいアイコンが表示される

### FR-2: 旧ファイル削除
- **入力**: プロジェクトルートに残存する `3ds_music_player.smdh`
- **処理**: ファイルを削除、Makefileに旧名への参照がないことを確認
- **出力**: プロジェクトに旧名のファイルが存在しない状態

## 3. UI/UX考慮事項
- UI変更なし（本体システム側の表示問題）

## 4. 追加設計情報
- **制約**: フレンドリストのキャッシュは3DS本体のシステムモジュールが管理しており、アプリ側から直接制御不可
- **UniqueId変更時の注意**: IDを変更すると本体側では「別アプリ」として扱われるため、ホーム画面の配置がリセットされる可能性あり
- **既存コードへの影響**: `app.rsf`（UniqueId変更の場合のみ）、ビルド成果物の削除のみ
