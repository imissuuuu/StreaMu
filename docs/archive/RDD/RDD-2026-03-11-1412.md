# RDD - 2026-03-11-1412 (Rev.2)
**Project Name:** 3DS Music Player - Phase 2: 設定画面・テーマシステム

## 1. 機能一覧

### 機能A: Config Manager
- `sdmc:/3ds/3ds-music-player/config.json` にJSON保存/起動時ロード
- 存在しない/破損時はデフォルト値フォールバック

### 機能B: ダーク/ライトモード
- 背景・文字・ポップアップ・カーソルアウトラインが連動切替
- ライト: 現行ベース(白をややグレーに調整)
- ダーク: 黒系背景 + 明るい文字

### 機能C: テーマカラー（アクセントカラー）
- **カラーパレット（グリッド型）**: 8×4程度のプリセット色マスをD-padで選択
- **色相スライダー**: 微調整用。Hue(0-360)を左右キーで回転、彩度・明度は固定
- アクセントカラーから派生色を自動計算

### 機能D: L/Rボタン挙動設定
- L, R 独立設定（例：L=スキップ、R=再生切替のような組み合わせ可）
- 選択肢: 無効 / 曲スキップ / 再生停止トグル

### 機能E: Settings画面（デュアルスクリーン構成）
- **下画面**: 設定項目リスト（D-pad + Aで値変更）
- **上画面**: 選択中の項目の説明文 + テーマ変更のリアルタイムプレビュー

## 2. 詳細仕様

### 機能A: Config Manager

```json
{
  "theme_mode": "light",
  "accent_hue": 220,
  "accent_palette_index": -1,
  "lr_config": { "l_action": "skip", "r_action": "skip" }
}
```

- `accent_palette_index`: パレットから選択した場合はそのインデックス、色相スライダーで微調整した場合は `-1`
- `accent_hue`: 色相値(0-360)
- JSONパーサー: 手動パース（軽量実装、外部ライブラリ不要）

### 機能B: ダーク/ライトモード

| 色変数名 | ライト | ダーク |
|----------|--------|--------|
| 背景 | `(245, 245, 245)` | `(25, 25, 30)` |
| `COL_TEXT_BODY` | `(30, 30, 30)` | `(220, 220, 220)` |
| `COL_TEXT_DIM` | `(120, 120, 120)` | `(150, 150, 150)` |
| `COL_POPUP_BG` | `(240, 240, 245)` | `(40, 40, 50)` |
| `COL_POPUP_TEXT`| `(30, 30, 30)` | `(220, 220, 220)` |
| カーソルアウトライン | 黒 `(0,0,0)` | 白 `(255,255,255)` |

### 機能C: テーマカラー

- `COL_ACCENT` = HSV→RGB変換(hue, S=0.75, V=0.78) でユーザー指定色
- `COL_PLAYING_BG` = HSV(hue, S=0.69, V=0.51) 暗め版
- `COL_PLAYING_TX` = HSV(hue, S=0.29, V=0.86) 明るめ版
- `COL_TITLE` = `COL_ACCENT`と同色

### 機能D: L/R挙動

```cpp
enum LRAction { LR_DISABLED, LR_SKIP, LR_PLAY_PAUSE };
```
デフォルト: L=LR_SKIP, R=LR_SKIP

### 機能E: Settings画面

**下画面（項目選択）:**
```
  Mode:     [ Light  ]   ← A: トグル
  Color:    [ ■■■■ Grid ] ← A: パレット展開
  Hue:      [ ===220=== ] ← 左右: 色相スライダー
  L Button: [ Skip    ]   ← A: サイクル切替
  R Button: [ Skip    ]   ← A: サイクル切替
  [ Save & Back ]         ← A: 保存してHome復帰
```

**上画面（プレビュー + 説明）:**
- 上部: 選択中の項目の説明テキスト
- 下部: モックUI（ボタン矩形 + テキスト）でテーマ変更をリアルタイム反映

## 3. UI/UX 考慮事項
- Bボタンで戻る場合は保存しない（変更破棄）
- Save & Backのみ永続化
- カラーパレット展開時は下画面がパレットグリッドに切替

## 4. 追加設計情報
- 現在の `static const u32` 色定数をランタイム変更可能な構造体 `ThemeColors` に移行
- `TouchButton::set_colors()` で既にボタン色は動的変更可能
- `draw_top()` のプレビュー描画は `SettingsScreen` クラスで実装
