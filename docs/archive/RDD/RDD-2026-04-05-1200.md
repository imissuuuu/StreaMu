# RDD - 2026-04-05-1200
**Project Name:** Search/Playlist Track Separation

## 1. 機能一覧

### 機能要件
- **FR-1**: `RenderContext` に `search_tracks: std::vector<Track>` を追加（SearchScreen 専用フィールド）
- **FR-2**: 検索完了・開始時の `g_tracks` 操作を `search_tracks` に切り替え
- **FR-3**: SearchScreen 関連の `g_tracks` 参照を全て `search_tracks` に置き換え
- **FR-4**: SearchScreen の `draw_bottom` を PlayingScreen 構成に刷新（トラックリスト + PlayBar + ハンバーガーメニュー）
- **FR-5**: トラックリスト描画ロジックを共有ヘルパーに抽出し、PlayingScreen・SearchScreen 両方から呼ぶ

### 非機能要件
- **NFR-1**: `g_tracks` は PlaylistDetailScreen 専用として維持（既存動作を変えない）
- **NFR-2**: 既存の検索機能（再生・一時停止・TRACK_OPTIONS ポップアップ・プレイリスト追加・シーク）は全て継続動作する
- **NFR-3**: `RenderContext` にフィールドを追加するため、ビルドは `make clean && make` で行う

## 2. 詳細仕様

### FR-1 / FR-2: search_tracks フィールド
- 書き込み: 検索完了時（現在 `ctx.g_tracks = res` の箇所）→ `ctx.search_tracks = res`
- クリア: 新しい検索開始時（現在 `ctx.g_tracks.clear()` の箇所）→ `ctx.search_tracks.clear()`
- 読み取り: SearchScreen のみ

### FR-3: g_tracks 参照の置き換え対象
| ファイル | 箇所 | 変更内容 |
|----------|------|----------|
| `main.cpp` | 検索スレッド完了 | `g_tracks = res` → `search_tracks = res` |
| `main.cpp` | 検索開始 | `g_tracks.clear()` → `search_tracks.clear()` |
| `main.cpp` | STATE_SEARCH の KEY_X ポップアップ | `g_tracks[selected_index]` → `search_tracks[...]` |
| `main.cpp` | プレイリスト追加（STATE_SEARCH） | `g_tracks[selected_index]` → `search_tracks[...]` |
| `main.cpp` | シークフォールバック | `g_tracks` → `search_tracks` |
| `search_screen.cpp` | 全域 | `g_tracks` → `search_tracks` |
| `ui_renderer.cpp` | TRACK_DETAILS フォールバック検索 | `g_tracks` に加えて `search_tracks` も検索対象に追加 |

### FR-4: SearchScreen draw_bottom の新構成
```
[下画面 320x240]
┌────────────────────────────────┐
│ トラックリスト                  │ ← PlayingScreen と同スタイル
│ （ハイライト・再生中マーカー付き）│   LIST_START_Y ～ BAR_Y
├────────────────────────────────┤
│ PlayBar（シークバー）            │ BAR_Y ～ BAR_Y+SEEK_H

```
- HOMEボタンは表示しない（PlayingScreen との唯一の差異）
- ハンバーガーメニューは現状の位置・動作を維持

### FR-5: 共有ヘルパー
- `track_list_helpers.h/cpp` にリスト描画関数を追加
- `playing_tracks` / `search_tracks` を引数で受け取り、PlayingScreen スタイルで描画
- PlayingScreen・SearchScreen の `draw_bottom` 両方からこのヘルパーを呼ぶ

## 3. UI/UX 考慮事項

### 操作体系
- タップ: リストアイテムをタップ → 再生 or 一時停止（現状通り）
- タップ: シークバー → シーク（PlayingScreen と同じ `seek` アクション）
- タップ: ハンバーガーメニュー → `trigger_nav_menu`（現状通り）
- KEY_A: 選択アイテムを再生 or 一時停止
- D-pad: リスト上下移動（PlayingScreen と同じ自動スクロール付き）

### 検索トリガー
- Yボタン（`trigger_search_keyboard`）は現状通り SearchScreen の update() に残す
- 新しい描画構成には影響しない
