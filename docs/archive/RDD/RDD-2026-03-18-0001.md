# RDD - 2026-03-18-0001
**Project Name:** Phase 5-B: PlayingScreen 上画面曲情報を下部に移動 + 半透明ウィンドウ

## 1. 機能一覧

- **FR-1**: 上画面の曲情報ブロック（プレイリスト名・タイトル・メタ情報）を画面下部（y ≈ 148〜240）に再配置する
- **FR-2**: 曲情報表示時、固定サイズの半透明ウィンドウ（背景矩形）を描画し、その上にテキストを重ねる
- **FR-3**: 上部空きスペース（y ≈ 50〜148）は将来のサムネイル表示用として空けておく
- **NFR-1**: ウィンドウサイズは曲名の長さに依存せず固定とする
- **NFR-2**: 定数をハードコードせず `ui_constants.h` に追加する
- **NFR-3**: PlayingScreen 以外（HomeScreen, SearchScreen 等）の上画面表示は変更しない

## 2. 詳細仕様

### FR-1: 曲情報ブロックの移動

**対象コード**: `source/ui/ui_renderer.cpp` → `draw_top_screen()`

現状: `draw_y = TOP_STATUS_Y` (= 60.0f) から開始
変更後: `draw_y` の初期値を `TOP_NOW_PLAYING_WIN_Y + TOP_NOW_PLAYING_PAD` に変更

### FR-2: 半透明ウィンドウ

**入力 → 処理 → 出力**:
- 入力: `ctx.playing_title_lines` が非空のとき描画する
- 処理:
  1. 固定矩形を `C2D_DrawRectSolid` で半透明色（alpha ≈ 0xB0〜0xC0）で描画
  2. その後、既存のテキスト描画ロジックを実行（draw_y の開始点をウィンドウ内に設定）
- 出力: 半透明ウィンドウ + テキストが上画面下部に表示される

**ウィンドウ仕様**:

| パラメータ | 値 | 定数名 |
|-----------|-----|--------|
| X座標 | 8.0f | `TOP_MARGIN_X`（既存流用） |
| Y座標 | 148.0f | `TOP_NOW_PLAYING_WIN_Y` |
| 幅 | 384.0f | `TOP_NOW_PLAYING_WIN_W` |
| 高さ | 84.0f | `TOP_NOW_PLAYING_WIN_H` |
| 内側パディング(上) | 6.0f | `TOP_NOW_PLAYING_PAD` |
| 背景色 | `C2D_Color32(0, 0, 0, 0xB0)` または テーマ overlay 色 | （定数 or インライン） |

- 高さ 84px = 最大 4行 × 20px + 余白4px（プレイリスト名1行 + タイトル最大2行 + メタ1行）
- 幅 384px = 上画面幅400 - 左右マージン8×2
