# RDD - 2026-03-22-0001
**Project Name:** Public Release Packaging

## 1. 機能一覧

### 機能要件 (FR)
- **FR-1**: MIT ライセンスファイルを作成する
- **FR-2**: 使用ライブラリのサードパーティライセンス一覧を作成する

- **FR-4**: Python 製クロスプラットフォームセットアップスクリプトを作成する
- **FR-5**: 英語・日本語両対応の README.md を作成する
- **FR-6**: .gitignore を作成する（venv, ffmpeg, ビルド成果物等を除外）

### 非機能要件 (NFR)
- **NFR-1**: 個人情報（IPアドレス等）がどのファイルにも含まれないこと
- **NFR-2**: セットアップスクリプトは Windows / Mac / Linux で動作すること
- **NFR-3**: 公開先に依存しない汎用的な構成にすること

## 2. 詳細仕様

### FR-1: LICENSE
- MIT License テンプレートを使用
- 著作権者名はユーザーに確認（ハンドルネーム可）
- 年は 2026

### FR-2: THIRD_PARTY_LICENSES.md
- 使用ライブラリを調査し、名前・ライセンス種別・URLを一覧化
- 対象: libctru, citro2d, yt-dlp, ffmpeg, その他 proxy.py の依存

### FR-3: requirements.txt
- proxy.py の import 文から依存パッケージを抽出
- バージョン固定 or 最小バージョン指定

### FR-4: セットアップスクリプト（Python製）
- 入力: なし（対話式 or 自動）
- 処理: venv 作成 → pip install -r requirements.txt → ffmpeg 確認/案内
- 出力: セットアップ完了メッセージ
- 全 OS 対応（os/subprocess/pathlib 使用）

### FR-5: README.md
- 構成: プロジェクト概要 → スクリーンショット（任意） → 必要環境 → ビルド手順（3DS側） → セットアップ手順（proxy側） → 使い方 → ライセンス
- 英語セクション + 日本語セクション（または言語切替リンク）

### FR-6: .gitignore
- 除外対象: `build/`, `*.3dsx`, `*.elf`, `venv/`, `__pycache__/`, `ffmpeg`, `ffmpeg.exe`, `config.json`（個人IP含む）, `.claude/`（AI作業ファイル）
