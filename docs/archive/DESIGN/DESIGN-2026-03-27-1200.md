# システム設計書 - Color Palette（カスタムS/Vスライダー追加）
**RDD:** `RDD-2026-03-27-1200.md`
**作成日:** 2026-03-27

## 1. 全体方針

- `AppConfig` に `accent_saturation` / `accent_brightness` の2フィールドを追加し、カスタムモード時の S/V を保持する
- `apply_theme()` のカスタムモード分岐（`palette_index < 0`）で、固定値 0.75/0.78 の代わりにこれらの値を使用する
- 設定画面は既存の色相スライダーと同じパターンで S/V スライダーを追加する（コードの一貫性）
- `ConfigManager` に float パーサーを追加する（int パーサーの拡張）
- パレットグリッドは変更しない

**ビルド注意**: `AppConfig` のフィールド変更により `make clean` 必須（coding-patterns #11）

### 3.2 `source/config_manager.h`

#### parse_float() メソッド追加
```cpp
static float parse_float(const std::string& json, const char* key, float default_val) {
    std::string search = std::string("\"") + key + "\"";
    size_t pos = json.find(search);
    if (pos == std::string::npos) return default_val;
    pos = json.find(':', pos);
    if (pos == std::string::npos) return default_val;
    pos++;
    while (pos < json.size() && (json[pos] == ' ' || json[pos] == '\t')) pos++;

    // Extract number string and use strtof
    char num_buf[32];
    int ni = 0;
    bool negative = false;
    if (pos < json.size() && json[pos] == '-') { negative = true; pos++; }
    while (pos < json.size() && ni < 30 &&
           ((json[pos] >= '0' && json[pos] <= '9') || json[pos] == '.')) {
        num_buf[ni++] = json[pos++];
    }
    if (ni == 0) return default_val;
    num_buf[ni] = '\0';
    float val = 0.0f;
    // Manual float parse (avoid locale issues with strtof)
    // Parse integer part
    int i = 0;
    while (i < ni && num_buf[i] != '.') {
        val = val * 10.0f + (num_buf[i] - '0');
        i++;
    }
    if (i < ni && num_buf[i] == '.') {
        i++;
        float frac = 0.1f;
        while (i < ni) {
            val += (num_buf[i] - '0') * frac;
            frac *= 0.1f;
            i++;
        }
    }
    return negative ? -val : val;
}
```

## 4. 各機能の詳細設計

### FR-1/FR-2: S/V スライダー入力処理

色相スライダーと同じパターンで実装する。`update()` 内に追加：

```
HUE スライダー編集モード処理の直後に:

if (in_edit_mode_ && (selected_item_ == ITEM_SATURATION || selected_item_ == ITEM_BRIGHTNESS)) {
  // タッチ読み取り
  // 画面外タップ → 編集終了
  // ドラッグ → 0.0〜1.0 にマップ、palette_index = -1、apply_preview()
  // D-pad左右 → ±0.05、palette_index = -1、apply_preview()
  // A → 確定
  // B → editing_config_ を ctx.config に戻す、apply_preview()
}
```

共通ロジック:
- `float* target`: ITEM_SATURATION なら `&editing_config_.accent_saturation`、ITEM_BRIGHTNESS なら `&editing_config_.accent_brightness`
- ドラッグ: `*target = clamp(touch_ratio, 0.0f, 1.0f)`
- D-pad: `*target = clamp(*target ± 0.05f, 0.0f, 1.0f)`

### FR-3: 暗黙的カスタムモード切替

S/V スライダー操作時に `editing_config_.palette_index = -1` を設定する。
（色相スライダーと同じ動作）

### スライダー描画

S/V スライダーの描画は `draw_bottom()` 内の `ITEM_HUE` 描画の直後に追加：

```
彩度バー: 左端（白、S=0）→ 右端（現在の色相の純色、S=1）
  - 複数セグメントに分割し、各セグメントの色を
    hsv_to_color32(hue, seg_s, current_v) で計算

明度バー: 左端（黒、V=0）→ 右端（現在の色相の純色、V=1）
  - 各セグメントの色を hsv_to_color32(hue, current_s, seg_v) で計算

セグメント数: 8（十分な滑らかさ）
バー位置/サイズ: 色相スライダーと同一（bar_x=100, bar_w=180, 高さ8px）
カーソル: 4px幅、cursor_outline 色
```
