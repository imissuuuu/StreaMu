# システム設計書 - Server EXE化
**RDD:** `RDD-2026-05-12-0001.md`
**作成日:** 2026-05-12

## 1. 全体方針

- **ffmpeg管理を独立モジュール化**: `ffmpeg_bootstrap.py` を新設し、proxy.pyからは関数呼び出しのみ
- **PyInstaller対応のパス解決**: `sys._MEIPASS`（onefile展開先）と実際のEXE配置ディレクトリを区別する。ffmpegはEXE配置ディレクトリに置く
- **yt-dlpのsubprocess問題を回避**: PyInstaller onefile環境では`sys.executable`が一時展開先を指すため、yt-dlpをsubprocessではなくPython APIとして呼び出すよう変更

## 2. 新規ファイル

### `server/ffmpeg_bootstrap.py`

```python
"""ffmpeg auto-download for Windows."""
import os
import sys
import io
import zipfile
import urllib.request
from pathlib import Path

FFMPEG_URL = "https://github.com/BtbN/FFmpeg-Builds/releases/download/latest/ffmpeg-master-latest-win64-gpl.zip"

def get_app_dir() -> Path:
    """EXE配置ディレクトリ or スクリプトディレクトリを返す."""
    if getattr(sys, 'frozen', False):
        return Path(sys.executable).parent.resolve()
    return Path(__file__).parent.resolve()

def get_ffmpeg_path() -> str:
    """ffmpeg.exeのフルパスを返す."""
    return str(get_app_dir() / "ffmpeg.exe")

def ensure_ffmpeg() -> str:
    """ffmpeg.exeが存在しなければDL。パスを返す."""
    ffmpeg_path = get_ffmpeg_path()
    if os.path.isfile(ffmpeg_path):
        return ffmpeg_path

    print("[INFO] ffmpeg not found. Downloading...")
    _download_ffmpeg(get_app_dir())
    if not os.path.isfile(ffmpeg_path):
        print("[ERROR] ffmpeg download failed.")
        print("  Please download manually from https://ffmpeg.org/download.html")
        print(f"  and place ffmpeg.exe in: {get_app_dir()}")
        sys.exit(1)
    print("[INFO] ffmpeg ready.")
    return ffmpeg_path

def _download_ffmpeg(dest_dir: Path) -> None:
    """BtbN/FFmpeg-Buildsからzipをダウンロード、ffmpeg.exeを展開."""
    try:
        req = urllib.request.Request(FFMPEG_URL)
        with urllib.request.urlopen(req, timeout=60) as resp:
            total = int(resp.headers.get('Content-Length', 0))
            downloaded = 0
            chunks: list[bytes] = []
            while True:
                chunk = resp.read(1024 * 256)
                if not chunk:
                    break
                chunks.append(chunk)
                downloaded += len(chunk)
                if total > 0:
                    pct = downloaded * 100 // total
                    mb = downloaded // (1024 * 1024)
                    print(f"\r[INFO] Downloading ffmpeg ({mb} MB)... {pct}%", end="", flush=True)
            print()

        data = b"".join(chunks)
        with zipfile.ZipFile(io.BytesIO(data)) as zf:
            for name in zf.namelist():
                if name.endswith("/bin/ffmpeg.exe"):
                    with zf.open(name) as src, open(dest_dir / "ffmpeg.exe", "wb") as dst:
                        dst.write(src.read())
                    return
        print("[ERROR] ffmpeg.exe not found in downloaded archive.")
    except (urllib.error.URLError, OSError, zipfile.BadZipFile) as e:
        print(f"[ERROR] Download failed: {e}")
```

### `server/proxy.py`

**変更1: BASE_DIR / FFMPEG_PATH をffmpeg_bootstrapに委譲**

変更前:
```python
BASE_DIR: Path = Path(__file__).parent.resolve()
FFMPEG_PATH: str = str(BASE_DIR / ("ffmpeg.exe" if platform.system() == "Windows" else "ffmpeg"))
```

変更後:
```python

BASE_DIR: Path = get_app_dir()
FFMPEG_PATH: str = get_ffmpeg_path()
```

**変更2: yt-dlpのsubprocess呼び出しをPython API呼び出しに変更**

`_stream_normal`と`_stream_seek`で`sys.executable -m yt_dlp`をsubprocessとして呼び出している箇所を、`yt_dlp`のPython APIでダウンロードしてpipeに書き込む方式に変更する。

変更前（`_stream_normal` L243-246相当）:
```python
ydl_cmd = [
    sys.executable, "-m", "yt_dlp",
    "-f", "bestaudio/best",
    "--quiet", "--no-warnings",
    "-o", "-",
    url
]
```

変更後:
```python
def _yt_dlp_download_to_fd(url: str, w_fd: int, fmt: str = "bestaudio/best") -> None:
    """yt-dlpのPython APIでダウンロードし、fdに書き込む."""
    ydl_opts = {
        "format": fmt,
        "quiet": True,
        "no_warnings": True,
        "outtmpl": "-",
        "logtostderr": False,
        "socket_timeout": 10,
    }
    with os.fdopen(w_fd, "wb") as pipe_out:
        ydl_opts["outtmpl"] = "-"
        with yt_dlp.YoutubeDL({**ydl_opts, "outtmpl": "-"}) as ydl:
            info = ydl.extract_info(url, download=False)
            direct_url = info.get("url", "")
            headers = info.get("http_headers", {})
            req = urllib.request.Request(direct_url, headers=headers)
            with urllib.request.urlopen(req, timeout=300) as resp:
                while True:
                    chunk = resp.read(65536)
                    if not chunk:
                        break
                    pipe_out.write(chunk)
```

→ これにより`sys.executable`への依存を排除し、PyInstaller環境で動作可能にする。

## 4. 各機能の詳細設計

### FR-1: EXEビルド

起動フロー:
```
StreaMu-Server.exe 起動
  → PyInstallerがonefileを一時ディレクトリに展開
  → proxy.py __main__ 実行
  → get_app_dir() で sys.executable の親ディレクトリ取得（= EXE配置場所）
  → ensure_ffmpeg() でffmpegチェック → 無ければDL
  → uvicorn.run() でサーバー開始
```

PyInstaller onefile時のパス解決:
- `sys._MEIPASS`: 一時展開先（Pythonコード・ライブラリ）
- `sys.executable`: EXE本体のパス
- `Path(sys.executable).parent`: EXE配置ディレクトリ ← ffmpegはここに置く

### FR-2: ffmpeg自動ダウンロード

DL元: `github.com/BtbN/FFmpeg-Builds` の `ffmpeg-master-latest-win64-gpl.zip`
- zip内構造: `ffmpeg-master-latest-win64-gpl/bin/ffmpeg.exe`
- 必要なのは`ffmpeg.exe`のみ（ffprobe等は不要）
- zip全体は約100MB、ffmpeg.exe単体は約120MB展開後

エラーハンドリング:
- ネットワークエラー → メッセージ表示 + 手動DL案内 + `sys.exit(1)`
- zip破損 → 同上
- 書き込み権限なし → 同上
