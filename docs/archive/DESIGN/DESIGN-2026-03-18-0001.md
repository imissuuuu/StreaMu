## 1. 全体方針

- 変更対象は `ui_renderer.cpp` の `draw_top_screen()` と `ui_constants.h` の2ファイルのみ

    float draw_y = TOP_STATUS_Y;

```cpp
if (!ctx.playing_title_lines.empty()) {
    // 半透明ウィンドウ背景

    // テキスト描画（ウィンドウ内側から開始）

    // 以降の描画ロジックは現状維持

    for (const auto& line : ctx.playing_title_lines) { ... }
    if (!ctx.playing_meta.empty()) { ... }
}
```

## 4. 各機能の詳細設計

### FR-1 & FR-2: 半透明ウィンドウ + テキスト描画

```
playing_title_lines が非空のとき:
  1. C2D_DrawRectSolid(8, 148, 0, 384, 84, 0x000000B0)  // 半透明黒矩形
  2. draw_y = 148 + 6 = 154.0f
  3. active_playlist_name が非空なら:
       ">> Playing from: <name>" を draw_y に描画 → draw_y += 20
  4. playing_title_lines をループ:
       1行目: ">> <line>" or "|| <line>"、FONT_MD で描画 → draw_y += 20
       2行目以降: "   <line>"
  5. playing_meta が非空なら:
       meta を draw_y に FONT_SM で描画
```

**オーバーフロー考慮:**
- 最大 5行 × 20px = 100px。ウィンドウ高さ 84px に収まらない場合がある。
- 対策: プレイリスト名(1行) + タイトル(最大2行) + メタ(1行) = 4行 × 20px + pad6 = 86px → 微妙にはみ出す
- → ウィンドウ高さを **88.0f** に変更（`TOP_NOW_PLAYING_WIN_H = 88.0f`）
- タイトルが3行以上折り返す場合は画面外にはみ出す可能性があるが、現行の折り返し処理（`playing_title_lines` 生成側）が最大2行に収まるよう制御していれば問題なし（要確認）

### FR-3: サムネイル予約領域
