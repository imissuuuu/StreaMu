## 4. 各機能の詳細設計

### 色操作ヘルパー（home_screen.cpp ファイルスコープ）

```cpp
// u32色 (ABGR形式: citro2dのC2D_Color32はABGR) からR,G,Bを抽出
static inline u8 color_r(u32 c) { return c & 0xFF; }
static inline u8 color_g(u32 c) { return (c >> 8) & 0xFF; }
static inline u8 color_b(u32 c) { return (c >> 16) & 0xFF; }
static inline u8 color_a(u32 c) { return (c >> 24) & 0xFF; }

// 明度を factor (0.0〜1.0) 倍にした色を返す
static inline u32 darken_color(u32 c, float factor) {
    u8 r = (u8)(color_r(c) * factor);
    u8 g = (u8)(color_g(c) * factor);
    u8 b = (u8)(color_b(c) * factor);
    return C2D_Color32(r, g, b, color_a(c));
}
```

### FR-1: グラデーション描画

```
疑似コード:
  base_color = theme->accent
  dark_color = darken_color(base_color, 0.80)  // 20%暗く

  for y = 0 to tile_h, step GRAD_STEP:
    t = y / tile_h  // 0.0 〜 1.0
    r = lerp(base_r, dark_r, t)
    g = lerp(base_g, dark_g, t)
    b = lerp(base_b, dark_b, t)
    C2D_DrawRectSolid(tile_x, tile_y + y, 0,
                      tile_w, GRAD_STEP, C2D_Color32(r, g, b, 255))
```

GRAD_STEP=2 の場合、最大タイル高さ132px → 66回のdrawcall。5タイルで330回。許容範囲。

### FR-3: ベベル描画

```
疑似コード（通常状態）:
  highlight = C2D_Color32(255, 255, 255, 64)  // 白25%
  shadow    = C2D_Color32(0, 0, 0, 64)        // 黒25%

  // 上辺 (ハイライト)
  C2D_DrawRectSolid(x, y, 0, w, BEVEL_W, highlight)

  C2D_DrawRectSolid(x + w - BEVEL_W, y, 0, BEVEL_W, h, shadow)
```

### draw_tile ラムダの全体フロー

```
draw_tile(TileId id, const char* label):
  1. Rect取得
  2. is_pressed = (id == pressed_tile_)
  3. グラデーション描画 (FR-1)
  4. if (!is_pressed): ベベル描画（通常） (FR-3)
  5. if (is_pressed):
       ベベル反転描画 (FR-2.2)
       暗化オーバーレイ (FR-2.1)
       インセットボーダー (FR-2.3)
  6. テキスト描画 (is_pressedならtx+2, ty+2)
```

## 5. 実装順序

1. **色ヘルパー追加 + 定数追加** → ビルド確認
2. **グラデーション描画** (FR-1) → ビルド確認 + 実機テスト
3. **ベベル描画** (FR-3) → ビルド確認
4. **タッチフィードバック** (FR-2: pressed_tile_ + 描画) → ビルド確認 + 実機テスト
5. **パフォーマンス確認** → 必要に応じてGRAD_STEPを調整
