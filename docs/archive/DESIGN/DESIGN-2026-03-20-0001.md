# System Design - Startup Loading Improvement
**RDD:** `RDD-2026-03-20-0001.md`
**Date:** 2026-03-20

## 1. Overall Approach

- **No new files.** All changes are in `main.cpp` (lines 261-451).
- The existing startup code is a linear sequence in `main()`, not screen-managed. This stays as-is — wrapping it in a Screen class would be overengineering for a one-time boot sequence.
- A small helper function `draw_loading_screen()` is added at the top of `main.cpp` to avoid duplicating progress bar drawing logic.
- The current "Now Loading..." single-frame draw (lines 261-273) is removed and replaced by calling `draw_loading_screen()` at each stage boundary.
- Each step has a minimum display duration (Steps 1-2: 0.3s, Step 3: 0.5s) so the user can visually register each stage. Implemented via `svcSleepThread()` after drawing.
- The spinner loop (lines 324-451) is refactored to use the same progress bar (step 4/4) with a pulsing animation instead of the text spinner.
- Timeout menu input: remove any B/START shortcuts, use D-pad + A only. The exit confirmation dialog already uses D-pad + A, which is kept.

## 2. New Code

### Helper function (top of main.cpp, before `main()`)

```cpp
// Draw a loading progress bar on the top screen.
// step: current step (1-4), total: 4
// label: text shown below the bar (e.g., "Initializing system...")
// pulse_frame: if >= 0, animates the bar tip for indeterminate progress (step 4)
void draw_loading_screen(UIManager& ui_mgr, C2D_TextBuf buf,
                         const ThemeColors* theme,
                         int step, int total, const char* label,
                         int pulse_frame = -1) {
  ui_mgr.begin_top_screen(theme->bg_top);
  ui_mgr.begin_bottom_screen(theme->bg_bottom);
  C2D_TextBufClear(buf);

  // Bar dimensions
  const float bar_x = 60.0f;
  const float bar_y = 105.0f;
  const float bar_w = 280.0f;
  const float bar_h = 16.0f;

  // Background bar (dark gray)
  C2D_DrawRectSolid(bar_x, bar_y, 0, bar_w, bar_h, C2D_Color32(60, 60, 60, 255));

  // Filled portion
  float fill_ratio = static_cast<float>(step - 1) / total; // completed steps
  if (pulse_frame < 0) {
    // Determinate: show completed portion
    fill_ratio = static_cast<float>(step) / total;
  }
  float fill_w = bar_w * fill_ratio;

  if (fill_w > 0) {
    C2D_DrawRectSolid(bar_x, bar_y, 0, fill_w, bar_h,
                      C2D_Color32(50, 120, 200, 255));
  }

  // Pulse animation for step 4 (indeterminate)
  if (pulse_frame >= 0) {
    float base_fill = bar_w * static_cast<float>(step - 1) / total;
    float segment_w = bar_w / total;
    // Sine-based pulse: fills 0% to 100% of the current segment
    float t = 0.5f + 0.5f * sinf(pulse_frame * 0.05f);
    float pulse_w = segment_w * t;
    C2D_DrawRectSolid(bar_x + base_fill, bar_y, 0, pulse_w, bar_h,
                      C2D_Color32(80, 150, 230, 255));
  }

  // Bar border (light outline)
  // Top and bottom edges
  C2D_DrawRectSolid(bar_x, bar_y, 0, bar_w, 1, C2D_Color32(120, 120, 120, 255));
  C2D_DrawRectSolid(bar_x, bar_y + bar_h - 1, 0, bar_w, 1, C2D_Color32(120, 120, 120, 255));
  // Left and right edges
  C2D_DrawRectSolid(bar_x, bar_y, 0, 1, bar_h, C2D_Color32(120, 120, 120, 255));
  C2D_DrawRectSolid(bar_x + bar_w - 1, bar_y, 0, 1, bar_h, C2D_Color32(120, 120, 120, 255));

  // Step text below bar
  C2D_Text text;
  char step_text[64];
  snprintf(step_text, sizeof(step_text), "Step %d/%d: %s", step, total, label);
  C2D_TextParse(&text, buf, step_text);
  C2D_TextOptimize(&text);
  C2D_DrawText(&text, C2D_AtBaseline | C2D_WithColor,
               bar_x, bar_y + bar_h + 20, 0, 0.5f, 0.5f,
               C2D_Color32(180, 180, 180, 255));

  ui_mgr.end_frame();
}
```

## 4. Detailed Design per FR

### FR-1/FR-2: Progress bar at each stage

Flow:
```
main() start
  → UIManager init, config load, wallpaper load
  → draw_loading_screen(step=1, "Initializing system...")
  → romfs, ndsp, ndmu, player, soc init
  → draw_loading_screen(step=2, "Loading config...")
  → playlist_manager.init()
  → draw_loading_screen(step=3, "Loading playlists...")
  → ScreenManager setup, IP keyboard (if needed)
  → Enter connection loop with step=4 pulse
```

Note: Steps 1-3 are drawn as "completed" (full segment). Each `draw_loading_screen()` call renders one frame, then `svcSleepThread()` holds the display for the minimum duration (0.3-0.5s). This ensures each step label is readable even though the actual init work is near-instant. Total added delay: ~1.1s.

### FR-3: Spinner redesign

The text spinner `[/] [-] [\] [|]` is replaced by the pulsing bar animation in step 4. The pulse uses `sin(frame * 0.05)` for a smooth ~2-second cycle. The pulse segment fills the 4th quarter of the bar with varying width.

### FR-4/FR-5: Timeout handling

Timeout menu rendering stays mostly the same (drawn directly, not via `draw_loading_screen`). Changes:
- Remove B button from exit confirmation
- Update hint text
- Visual style uses same colors as progress bar for consistency

### Speed improvement: Connection check interval

Current: retry every 60 frames (1 second) → `timeout_counter % 60 == 0`
Changed to: retry every 30 frames (0.5 seconds) → `timeout_counter % 30 == 0`

This halves the worst-case wait between the 3DS Wi-Fi becoming ready and the first successful check. Animation interval stays at 20 frames.

Timeout threshold also adjusts: `timeout_counter >= 30 * 15` (still 15 seconds wall time, since checks are now every 0.5s the frame count halves but we keep the same real-time timeout = 60fps * 15s = 900 frames).
