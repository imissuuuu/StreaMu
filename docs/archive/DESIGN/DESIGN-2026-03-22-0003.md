# システム設計書 - CIA Build
**RDD:** `RDD-2026-03-22-0003.md`
**作成日:** 2026-03-22

## 1. 全体方針
- Makefile に `cia` ターゲットを追加。既存の `all`（.3dsx）はそのまま
- CIA ビルドパイプライン: bannertool → makerom
- RSF ファイルで CIA メタデータを定義
- ツールは `/opt/devkitpro/tools/bin/` に配置済み（フルパスで参照）

## 2. 新規ファイル

### app.rsf
makerom 用メタデータ定義。主要フィールド:
```
App:
  Title: "3DS Music Player"
  ProductCode: "CTR-H-MUSP"
  UniqueId: 0xFF3D0 (homebrew range)
SystemControlInfo:
  StackSize: 0x10000
  RemasterVersion: 0
AccessControlInfo:
  UseOnSD: true
  FileSystemAccess: [CtrNandRo, CtrNandRw, CategorySystemApplication]
  IoAccessControl: [FsMountSdmc, FsMountContent]
  Services: [ac:u, boss:U, cam:u, cfg:u, fs:USER, gsp::Gpu, hid:USER, httpc:u, ir:USER, mic:u, ndm:u, news:u, nwm::UDS, ptm:u, soc:U, y2r:u]
```

### assets/audio_silent.wav
bannertool が banner.bnr 生成時に音声ファイルを要求する。無音の短い WAV を生成して使用。

## 3. 既存ファイルの変更

### Makefile
追加するターゲット:
```makefile
# CIA build tools
BANNERTOOL := $(DEVKITPRO)/tools/bin/bannertool
MAKEROM    := $(DEVKITPRO)/tools/bin/makerom

# CIA build target
cia: $(TARGET).cia

$(TARGET).cia: $(TARGET).elf $(TARGET).smdh banner.bnr
	$(MAKEROM) -f cia -o $@ -elf $< -rsf app.rsf -icon $(TARGET).smdh -banner banner.bnr
	@echo "Built: $@"

$(TARGET).smdh:
	$(BANNERTOOL) makesmdh -s "3DS Music Player" -l "YouTube music streamer for 3DS" -p "Contributors" -i assets/icon_48.png -o $@

banner.bnr:
	$(BANNERTOOL) makebanner -i assets/banner_256.png -a assets/audio_silent.wav -o $@
```

clean ターゲットに `.cia`, `.smdh`, `banner.bnr` を追加。

## 4. 各機能の詳細設計
- `bannertool makesmdh`: icon_48.png → .smdh（ホーム画面アイコン+メタデータ）
- `bannertool makebanner`: banner_256.png + audio_silent.wav → banner.bnr（起動バナー）
- `makerom -f cia`: elf + smdh + bnr + rsf → .cia

## 5. 実装順序
1. 無音 WAV を生成
2. app.rsf を作成
3. Makefile にターゲット追加
4. `make cia` でビルド確認
