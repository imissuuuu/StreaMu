`start_streaming()` 内、`CURLOPT_USERAGENT` 設定の後に以下を追加:

```cpp
curl_easy_setopt(curl, CURLOPT_LOW_SPEED_LIMIT, 1L);    // 1 byte/s 未満で
curl_easy_setopt(curl, CURLOPT_LOW_SPEED_TIME, 15L);     // 15秒続いたら中断
```

## 4. 各機能の詳細設計

### FR-1: ストリーミングタイムアウト

CURLの `LOW_SPEED` 系オプションの動作:
- `LOW_SPEED_LIMIT`: 速度閾値（bytes/sec）
- `LOW_SPEED_TIME`: 閾値以下が続く許容秒数
- 条件を満たすと `curl_easy_perform()` が `CURLE_OPERATION_TIMEDOUT` を返す
- `start_streaming()` は `res != CURLE_OK` → `success = false` → 既存リトライフローへ

タイムアウト発火条件: **15秒間、受信速度が1byte/s以下**
- 正常ストリーミング中（数百KB/s）: 発火しない
- サーバー停止/ネットワーク断: 15秒後に中断
