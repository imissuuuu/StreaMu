## 設計方針

**最小リスク原則**: 移行量を最小化し、既存の動作を壊さない。

| 層 | 方針 |
|---|---|
| **上画面描画** | UIRenderer に残す (全画面共通のヘッダー+トラックリストが既に動作中。変更しない) |
| **下画面描画** | Screen クラスに移行 (UIRenderer::draw_bottom_screen から該当部分を移植) |
| **入力処理** | Screen クラスに移行 (main.cpp の if/else チェーンから該当部分を移植) |
| **複雑な処理** | main.cpp に残す (`start_playback`, キーボード呼び出し等)。Screen はアクション文字列を返す |

### 1. SearchScreen

```cpp
// search_screen.h
#pragma once
#include "../screen.h"
#include <string>

class SearchScreen : public Screen {
public:
    void on_enter(AppContext& ctx) override;
    std::string update(AppContext& ctx, u32 kDown, u32 kRepeat) override;
    void draw_top(const RenderContext& ctx, UIManager& ui_mgr) override;    // 空
    void draw_bottom(const RenderContext& ctx, UIManager& ui_mgr) override; // UIRendererから移植
};
```

**on_enter():**
- `ctx.current_state = STATE_SEARCH;`
- ※ selected_index, g_tracksは呼び出し元(main.cpp)が事前にセット済み

**update() の処理内容 (main.cpp:637-729 から移植):**
1. SEARCH_BTN挿入ロジック (先頭に「[ 検索 ]」を追加。ただしダウンロード中でない場合のみ)
2. KEY_A処理:
   - selected_id == "SEARCH_BTN" → return `"trigger_search_keyboard"`
   - selected_id == playing_id → return `"toggle_pause"`
   - それ以外 → return `"start_playback"` (main.cppがctx.selected_indexを見て再生開始)
3. DPad UP/DOWN: selected_index移動 (wrap around)
4. DPad RIGHT/LEFT: scroll_x操作 (テキスト幅制限チェック付き)
   - ※ テキスト幅チェックに `ui_mgr.get_text_buf()` が必要 → update()にui_mgrを渡せないので、AppContext経由でtext_bufポインタを渡すか、スクロール上限を固定値にする
   - **推奨案:** scroll_xの上限チェックはdraw時に行い、update時は単純に±50する。描画時にクランプ。

**draw_bottom() の処理内容 (ui_renderer.cpp:272-355 STATE_SEARCH部分):**
- 2行レイアウト: タイトル行 + メタデータ行
- スクロール対応 (selected_index行のdraw_xをscroll_x分ずらす)
- ハイライト: 選択行=accent色、再生中行=playing_bg色
- トラックリストが空のときは表示なし

変更後:
```cpp
// Screen管理対象の状態
if (ctx.current_state == STATE_HOME ||
    ctx.current_state == STATE_SEARCH ||
    ctx.current_state == STATE_PLAYLISTS ||
    ctx.current_state == STATE_PLAYLIST_DETAIL ||
    ctx.current_state == STATE_SETTINGS) {

    std::string action = screen_mgr.update(ctx, kDown, kRepeat);

    // === HomeScreen actions (既存) ===
    if (action == "trigger_search") {
        kDown |= KEY_Y;
    } else if (action == "trigger_playlists") {
        screen_mgr.change_screen(ctx, "PlaylistsScreen");
        kDown &= ~KEY_A;
    } else if (action == "trigger_settings") {
        screen_mgr.change_screen(ctx, "SettingsScreen");
        kDown &= ~KEY_A;
    }
    // === SettingsScreen actions (既存) ===
    else if (action == "trigger_home") {
        screen_mgr.change_screen(ctx, "HomeScreen");
    }
    // === SearchScreen actions (NEW) ===
    else if (action == "trigger_search_keyboard") {
        kDown |= KEY_Y;  // 既存のKEY_Yハンドラに任せる
    }
    else if (action == "start_playback") {
        start_playback(ctx.g_tracks[ctx.selected_index]);
        LightLock_Lock(&ctx.lock);
        ctx.active_playlist_id = "";
        ctx.active_playlist_name = "";
        ctx.play_queue.clear();
        ctx.current_track_idx = -1;
        LightLock_Unlock(&ctx.lock);
    }
    else if (action == "toggle_pause") {
        if (ctx.playing_id != "") {
            ctx.is_paused = !ctx.is_paused;
            ndspChnSetPaused(0, ctx.is_paused);
            ctx.g_status_msg = ctx.is_paused ? "Paused..." : "Now Playing...";
        }
    }
    // === PlaylistsScreen actions (NEW) ===
    else if (action == "open_playlist_detail") {
        screen_mgr.change_screen(ctx, "PlaylistDetailScreen");
        kDown &= ~KEY_A;
    }
    // === PlaylistDetailScreen actions (NEW) ===
    else if (action == "start_playback_from_playlist") {
        start_playback(ctx.g_tracks[ctx.selected_index]);
        LightLock_Lock(&ctx.lock);
        ctx.active_playlist_id = ctx.selected_playlist_id;
        for (const auto& pl : ctx.playlists) {
            if (pl.id == ctx.selected_playlist_id) {
                ctx.active_playlist_name = pl.name;
                break;
            }
        }
        // シャッフルキュー生成
        ctx.play_queue.clear();
        for (size_t i = 0; i < ctx.g_tracks.size(); ++i)
            ctx.play_queue.push_back(i);
        for (size_t i = ctx.play_queue.size() - 1; i > 0; --i) {
            size_t j = rand() % (i + 1);
            std::swap(ctx.play_queue[i], ctx.play_queue[j]);
        }
        for (size_t i = 0; i < ctx.play_queue.size(); ++i) {
            if (ctx.play_queue[i] == ctx.selected_index) {
                ctx.current_track_idx = i;
                break;
            }
        }
        LightLock_Unlock(&ctx.lock);
    }
}
```

## DPadスクロールの scroll_x 上限チェック問題

**問題:** 現在のmain.cpp (L932-947) はKEY_DRIGHTでscroll_xを増やすとき、`C2D_TextGetDimensions()`でテキスト幅を測定して上限を計算している。しかしScreen::update()にはUIManagerの参照がない。

**解決策:**
- Screen::update()ではscroll_xの増減のみ行う(上限チェックなし)
- scroll_xの上限クランプはdraw_bottom()内で行う (描画時にテキスト幅が分かるため)
- もしくは固定の上限値 (例: 500px) を仮設定し、描画時に実際のテキスト幅でクランプ

**推奨:** draw_bottom()内でクランプ。update()では単純に `scroll_x += 50; if (scroll_x < 0) scroll_x = 0;` のみ。
