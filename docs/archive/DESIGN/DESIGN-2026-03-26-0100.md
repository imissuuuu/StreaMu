# システム設計書 - List UI Restyle
**RDD:** `RDD-2026-03-26-0100.md`
**作成日:** 2026-03-26

## 1. 全体方針

- `home_screen.cpp` にあるグラデーション/ベベル描画関数を `track_list_helpers.cpp` に移動し、全画面から使えるようにする
- 非選択項目用の「浮き出し背景」描画関数を新設
- 各画面の `draw_bottom()` 内の `C2D_DrawRectSolid` ベタ塗りを、共通描画関数の呼び出しに置き換える
- ThemeColors に `item_bg`（非選択項目の浮き出し背景色）を追加

なし

## 3. 既存ファイルの変更

## 4. 各機能の詳細設計

### 共通描画関数の実装

```cpp
// --- Color helpers ---
static inline u8 col_r(u32 c) { return c & 0xFF; }
static inline u8 col_g(u32 c) { return (c >> 8) & 0xFF; }
static inline u8 col_b(u32 c) { return (c >> 16) & 0xFF; }

static inline u32 darken_color(u32 c, float factor) {
    return C2D_Color32((u8)(col_r(c) * factor),
                       (u8)(col_g(c) * factor),
                       (u8)(col_b(c) * factor), 255);
}

// --- Gradient ---
void draw_gradient(float x, float y, float w, float h, u32 top_col, u32 bot_col);
// (既存コードそのまま移動)

// --- Bevel ---
void draw_bevel(float x, float y, float w, float h, bool pressed);
// (既存コードそのまま移動)

// --- Press overlay ---
void draw_press_overlay(float x, float y, float w, float h, u32 inset_col);
// (既存コードそのまま移動)

// --- Selected item (gradient + bevel) ---
void draw_selected_item_bg(float x, float y, float w, float h, u32 accent) {
    u32 accent_dark = darken_color(accent, 0.80f);
    draw_gradient(x, y, w, h, accent, accent_dark);
    draw_bevel(x, y, w, h, false);
}

// --- Raised item (subtle bg + mini bevel) ---
void draw_raised_item_bg(float x, float y, float w, float h, u32 bg_color, bool is_dark) {
    C2D_DrawRectSolid(x, y, 0, w, h, bg_color);
    // Mini bevel (subtler than selected)
    u32 hi = is_dark ? C2D_Color32(255, 255, 255, 20)  // 白8%
                     : C2D_Color32(255, 255, 255, 128); // 白50%
    u32 lo = is_dark ? C2D_Color32(0, 0, 0, 77)        // 黒30%
                     : C2D_Color32(0, 0, 0, 26);        // 黒10%
    float bw = 2.0f; // thinner than BEVEL_W(3px) for subtlety
    C2D_DrawRectSolid(x, y, 0, w, bw, hi);              // top
    C2D_DrawRectSolid(x, y, 0, bw, h, hi);              // left
    C2D_DrawRectSolid(x, y + h - bw, 0, w, bw, lo);     // bottom
    C2D_DrawRectSolid(x + w - bw, y, 0, bw, h, lo);     // right
}
```

### is_dark の渡し方

`RenderContext::config.mode` で判定可能。各呼び出し箇所で `ctx.config.mode == THEME_DARK` を渡す。

### item_bg の算出 (apply_theme 内)

```cpp
// ダークテーマ
colors.item_bg = C2D_Color32(42, 42, 42, 255);  // bg_bottom(30,30,30) + 12

// ライトテーマ
colors.item_bg = C2D_Color32(235, 235, 235, 255); // bg_bottom(245,245,245) - 10
```
