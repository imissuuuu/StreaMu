## 3. 既存ファイルの変更

### source/main.cpp
System Init セクション（~line 346）に追加:

```cpp
// 変更前:
aptSetSleepAllowed(false);
romfsInit();

// 変更後:
aptSetSleepAllowed(false);
osSetSpeedupEnable(true); // Enable New 3DS 804MHz CPU + L2 cache (no-op on Old 3DS)
romfsInit();
```

`osSetSpeedupEnable` は APT が初期化済みであれば呼べる。`aptInit` は `gfxInitDefault` 内で暗黙的に呼ばれるため、この位置で安全。

## 4. 各機能の詳細設計
- `osSetSpeedupEnable(true)`: libctru API。New 3DS では CPU を 804MHz に切替え、L2キャッシュを有効化。旧 3DS では何も起きない（内部で機種判定済み）
- 戻り値なし（void）、エラーハンドリング不要
