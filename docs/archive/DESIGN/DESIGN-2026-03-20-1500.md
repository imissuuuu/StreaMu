## 4. 各機能の詳細設計

### FR-1: WiFiアイコン描画

WiFi切断の判定: `osGetWifiStrength() == 0` かつ WiFi自体が無効な場合。
ただし libctru では WiFi有効/無効を直接取得する簡単なAPIがないため、
`osGetWifiStrength() == 0` を「切断 or 信号なし」として統合し、4状態に簡略化する案もあり。
→ 実装では5状態を維持。切断判定には `ACU_GetWifiStatus` を使う（要 `acInit()`）。
  もし `acInit` が既に呼ばれていなければ、`osGetWifiStrength() == 0` で代用する。

```cpp
// WiFi icon: 3 ascending bars, bottom-aligned at Y=18
// Bar dimensions: width=3px, gap=1px, heights=6/10/14px
// Active color: accent_text, Inactive: accent_text with alpha 80

float wx = TOP_MARGIN_X;  // 8.0f
float wy_base = 18.0f;    // bottom of status bar
int bar_h[] = {6, 10, 14};

// 切断チェック
bool wifi_off = (wifi == 0);  // 簡易判定

if (wifi_off) {
    // × マーク: 2本の斜線（左上→右下、右上→左下）
    // 細い四角形を斜めに配置（近似）
    // サイズ: 10x10px 領域
} else {
    for (int i = 0; i < 3; i++) {
        u32 color = (i < wifi) ? accent_text : accent_text_dim;
        float bx = wx + i * (3 + 1);  // 3px幅 + 1px間隔
        float by = wy_base - bar_h[i];
        C2D_DrawRectSolid(bx, by, 0, 3, bar_h[i], color);
    }
}
```

**×マークの描画:**
`C2D_DrawRectSolid` は軸平行の矩形のみなので、斜線は描けない。
代替案: 小さな正方形を対角線上に並べてドット斜線にする。
またはテキストで `"x"` を描画（最もシンプル）。
→ テキスト `"x"` をアイコン領域中央に小フォントで描画する。

### FR-2: バッテリーアイコン描画

```cpp
// Battery icon: 外枠 + 端子 + ゲージ
// 外枠: 18x10px, 端子: 2x4px (右端)
// 内部ゲージ: 5セグメント、各 3x8px (1pxパディング)

float bx = wx + 22.0f;   // WiFiアイコンの右 + 余白
float by = 5.0f;          // ステータスバー内で上下中央

u8 charging = 0;
PTMU_GetBatteryChargeState(&charging);

// 外枠（白線）
u32 col = accent_text;
C2D_DrawRectSolid(bx, by, 0, 18, 10, col);            // 外枠
C2D_DrawRectSolid(bx+1, by+1, 0, 16, 8, accent_bg);   // 内側くり抜き
C2D_DrawRectSolid(bx+18, by+3, 0, 2, 4, col);          // 端子

// ゲージ（レベルに応じて塗りつぶし）
for (int i = 0; i < 5; i++) {
    if (i < battery) {
        float gx = bx + 1 + i * 3;  // 各セグメント3px幅 (1px gap含む)
        C2D_DrawRectSolid(gx, by+1, 0, 3, 8, col);
    }
}

// 充電マーク: ⚡ → テキスト描画（図形で稲妻は複雑すぎるため）
if (charging) {
    C2D_TextParse(&text, m_ui.get_text_buf(), "+");
    C2D_DrawText(&text, C2D_WithColor, bx+22, TOP_SYS_Y, 0, FONT_SM, FONT_SM, col);
}
```

**充電⚡について:**
`C2D_DrawRectSolid` で稲妻の形を作るのは非現実的（斜線が描けない）。
テキストで `"+"` または `"*"` を電池の右に描画するのが最もシンプル。

### FR-3: 時計テキスト

```cpp
// 時計（アイコン群の右に配置）
float clock_x = bx + 28.0f;  // バッテリー + 充電マーク分の右
char time_str[8];
if (tm) snprintf(time_str, sizeof(time_str), "%02d:%02d", tm->tm_hour, tm->tm_min);
else    snprintf(time_str, sizeof(time_str), "--:--");
C2D_TextParse(&text, m_ui.get_text_buf(), time_str);
C2D_DrawText(&text, C2D_WithColor, clock_x, TOP_SYS_Y, 0, FONT_SM, FONT_SM, accent_text);
```

### 色の定義

```cpp
u32 accent_text = m_colors.accent_text;
// 半透明版: alpha 80 (非アクティブバー用)
u32 accent_text_dim = C2D_Color32(
    (accent_text >> 24) & 0xFF,
    (accent_text >> 16) & 0xFF,
    (accent_text >> 8) & 0xFF,
    80);
```

注意: `m_colors.accent_text` の RGBA 構成を確認してから実装すること。
