# システム設計書 - Bottom-Screen List + Hamburger Nav
**RDD:** `RDD-2026-03-16-1500.md`
**作成日:** 2026-03-16

## 1. 全体方針

- **リスト描画の責務を下画面に集約する**。`btm_first` のオフセット計算（上画面アイテム数のスキップ）を廃止し、全トラックを index 0 から下画面で描画する。
- **ハンバーガーボタンを共有ヘルパーとして実装する**。位置計算（`get_menu_btn_rect`）と描画（`draw_menu_button`）を `track_list_helpers` に追加し、各 Screen が個別に持たない。
- **将来のボタン位置切替を `AppConfig` フィールドで吸収する**。今回は左固定だが、関数を経由することで将来の変更を1箇所に集中させる。
- **`STATE_POPUP_NAV` を既存のポップアップチェーンに組み込む**。main.cpp の is_popup_state 判定・描画・タッチ処理を既存パターンに統一して複雑さを増やさない。
- **負方向スクロール（上画面引き込み）ロジックを全削除**。`scroll_offset_y` の min clamp を 0 に変更する。

```cpp
// === ハンバーガーメニューボタン位置 ===
enum MenuButtonSide { MENU_BTN_LEFT = 0, MENU_BTN_RIGHT = 1 };

struct AppConfig {
  ThemeMode  mode          = THEME_LIGHT;
  int        accent_hue    = 220;
  int        palette_index = 0;
  LRAction   l_action      = LR_SKIP;
  LRAction   r_action      = LR_SKIP;
  MenuButtonSide menu_btn_side = MENU_BTN_LEFT; // 将来の設定対応用（今回は未実装）
};
```

### `ui_constants.h` — ハンバーガーボタン定数追加

```cpp
// ハンバーガーメニューボタン
constexpr int MENU_BTN_Y  = 206;
constexpr int MENU_BTN_W  = 40;
constexpr int MENU_BTN_H  = 30;
constexpr int MENU_BTN_LX = 4;         // 左配置 x
constexpr int MENU_BTN_RX = 276;       // 右配置 x (320 - 40 - 4)
```

### `track_list_helpers.h/.cpp` — ボタンヘルパー追加

```cpp
// ボタン矩形を設定に応じて返す（将来の右配置切替対応）
struct MenuBtnRect { int x, y, w, h; };
inline MenuBtnRect get_menu_btn_rect(const AppConfig& cfg) {
    int bx = (cfg.menu_btn_side == MENU_BTN_RIGHT) ? MENU_BTN_RX : MENU_BTN_LX;
    return { bx, MENU_BTN_Y, MENU_BTN_W, MENU_BTN_H };
}

// ☰ ボタンを描画する（全非 Home 画面で共通呼び出し）
void draw_menu_button(const RenderContext& ctx, UIManager& ui_mgr);
```

`draw_menu_button` 実装方針：
- `get_menu_btn_rect(ctx.config)` で位置取得
- `C2D_DrawRectSolid` で半透明背景 + `C2D_DrawText` で `"="` 3本線文字（または `"\xe2\x98\xb0"` ≡ ☰）

## 4. 各機能の詳細設計

### FR-1 リスト描画（下画面のみ）

`draw_track_list_bottom` は `btm_first = 0` で動作。上画面オフセット計算ブロック（約15行）を完全削除。`calc_scroll` ベースの `y_base` 計算はそのまま維持。

### FR-3/4 ハンバーガーメニュー

```
update() flow:
  タッチ end (was_tap == true):
    MenuBtnRect btn = get_menu_btn_rect(ctx.config)
    if (tap in btn) → return "trigger_nav_menu"
    else            → リスト項目判定（既存）

main.cpp:
  action == "trigger_nav_menu":
    previous_state = current_state
    current_state  = STATE_POPUP_NAV
```

### FR-5 グレーアウト判定

```cpp
bool is_grayed(int item_idx, AppState prev_state) {
    if (item_idx == 2) return (prev_state == STATE_PLAYLISTS);
    if (item_idx == 3) return (prev_state == STATE_SETTINGS);
    return false;
}
```

`draw_popup_overlay` 内: grayed な項目のテキスト色を `m_colors.text_dim` に変更。KEY_A 処理側でも grayed なら何もしない。
