# システム設計書 - Phase 6-B: PlayBar シャッフル/ループ切替 + PL再生モード選択
**RDD:** `RDD-2026-03-19-0003.md`
**作成日:** 2026-03-19

## 1. 全体方針

- **LoopMode enum と shuffle_mode を RenderContext に追加**。AppConfig には保存しない（揮発性）
- **PlayBar を5ゾーンに拡張**。既存の3ゾーン定数を5ゾーンに変更し、draw/handle_touch を更新
- **PlaylistDetailScreen にボタン行追加**。SearchScreen の SEARCH_BTN 方式に準じ、g_tracks の先頭に仮想エントリを挿入する方式を採用（既存の track_list_helpers がそのまま使える）
- **自動次曲ロジックを loop_mode 対応に変更**。現在はハードコードでループしているが、LOOP_OFF 時は停止、LOOP_ALL 時は先頭に戻る、LOOP_ONE 時は同じ曲を再度再生
- RenderContext 変更のため `make clean` 必須

なし。既存ファイルの変更のみ。

### 3-3. `source/ui/screens/playlist_detail_screen.cpp`

ボタン行の実装方針: **仮想 Track エントリ方式**

PlaylistDetailScreen::on_enter() で、g_tracks の先頭に `id="MODE_BTN"` の仮想 Track を挿入する。
これにより draw_track_list_bottom() の描画・navigate_track_list() のナビゲーションがそのまま使える。

```cpp
void PlaylistDetailScreen::on_enter(AppContext& ctx) {
    ctx.current_state   = STATE_PLAYLIST_DETAIL;
    ctx.selected_index  = 0;  // ボタン行が index 0
    ctx.scroll_x        = 0;
    ctx.scroll_offset_y = 0.0f;
    ctx.touch_state.reset();

    // 先頭にモードボタン仮想エントリを挿入
    LightLock_Lock(&ctx.lock);
    Track mode_btn;
    mode_btn.id    = "MODE_BTN";
    mode_btn.title = "";  // draw_track_list_bottom で特別描画
    ctx.g_tracks.insert(ctx.g_tracks.begin(), mode_btn);
    LightLock_Unlock(&ctx.lock);
}
```

update() の変更:
- タップ判定: MODE_BTN 行のタップ時、左半分(x<160) → "start_shuffle_playback"、右半分(x>=160) → "start_order_playback"
- A ボタン: selected_index==0 の時、左右キー or デフォルトで "start_order_playback"。
  → 簡略化: A ボタンで MODE_BTN 行を選択中 → "start_order_playback" をデフォルトに。
  ただしここは RDD の仕様に合わせ、SHUFFLE/ORDER を左右で選べるようにする方が良い。
  → **方針**: MODE_BTN 行ではフォーカスが左右に分かれる。新しいメンバー `mode_btn_focus_` (0=SHUFFLE, 1=ORDER) を追加。十字キー左右で切替。A で実行。

draw_track_list_bottom() の変更:
- `g_tracks[i].id == "MODE_BTN"` の場合、通常のタイトル/メタデータ描画の代わりに SHUFFLE | ORDER ボタンを描画
- 左半分に "SHUFFLE"、右半分に "ORDER" をフォント FONT_LG で描画
- selected 時のハイライトは、mode_btn_focus_ に応じて左半分 or 右半分のみハイライト

### 3-6. `source/main.cpp`

新しいアクションハンドラ:
```cpp
} else if (action == "start_shuffle_playback") {
    ctx.shuffle_mode = true;

    // g_tracks[0] は MODE_BTN → 除外してから playing_tracks にコピー

    ctx.shuffle_mode = false;
    // 同上だが順番キュー生成
}
```

toggle_loop ハンドラ:
```cpp
} else if (action == "toggle_loop") {
    if (ctx.loop_mode == LOOP_OFF) ctx.loop_mode = LOOP_ALL;
    else if (ctx.loop_mode == LOOP_ALL) ctx.loop_mode = LOOP_ONE;
    else ctx.loop_mode = LOOP_OFF;
}
```

toggle_shuffle ハンドラ:
```cpp
} else if (action == "toggle_shuffle") {
    ctx.shuffle_mode = !ctx.shuffle_mode;
    LightLock_Lock(&ctx.lock);
    if (ctx.shuffle_mode) {
        // 現在再生中の曲を先頭に置いてシャッフル
        ctx.play_queue.clear();
        for (size_t i = 0; i < ctx.playing_tracks.size(); ++i)
            ctx.play_queue.push_back(i);
        // Fisher-Yates shuffle
        for (size_t i = ctx.play_queue.size() - 1; i > 0; --i) {
            size_t j = rand() % (i + 1);
            std::swap(ctx.play_queue[i], ctx.play_queue[j]);
        }
        // 現在の曲を先頭に移動
        int cur_track = ...; // playing_id から特定
        // cur_track を queue の先頭に swap
        ctx.current_track_idx = 0;
    } else {
        // 順番に戻す
        ctx.play_queue.clear();
        for (size_t i = 0; i < ctx.playing_tracks.size(); ++i)
            ctx.play_queue.push_back(i);
        // 現在の曲の位置を探す
        for (size_t i = 0; i < ctx.play_queue.size(); ++i) {
            if (ctx.playing_tracks[ctx.play_queue[i]].id == ctx.playing_id) {
                ctx.current_track_idx = (int)i;
                break;
            }
        }
    }
    LightLock_Unlock(&ctx.lock);
}
```

自動次曲ロジック (should_auto_next 部分) の変更:
```
変更前: ctx.current_track_idx++; if >= size → 0 (常にループ)
変更後:
  if (loop_mode == LOOP_ONE) → 同じ曲を再度 start_playback
  else {
    ctx.current_track_idx++;
    if >= size {
      if (loop_mode == LOOP_ALL) → 0 に戻す
      else (LOOP_OFF) → 再生停止
    }
  }
```

既存の start_playback_from_playlist ハンドラ:
- 現在は常にシャッフル → **shuffle_mode に応じて分岐**
- shuffle_mode == true: Fisher-Yates シャッフル（既存動作）
- shuffle_mode == false: 順番キュー (0,1,2,...)

prev_track / next_track ハンドラ:
- LOOP_ONE: 同じ曲を再度 start_playback
- LOOP_ALL: 既存のラップアラウンド動作（変更なし）
- LOOP_OFF: 末尾/先頭で何もしない
```
変更前 (prev_track): ctx.current_track_idx--; if < 0 → size-1
変更後:
  if (LOOP_ONE) → start_playback(同じ曲)
  else { ctx.current_track_idx--;
    if < 0 {
      if (LOOP_ALL) → size-1
      else (LOOP_OFF) → 0 に戻して何もしない (return)
    }
  }
```

### 3-7. PlaylistDetailScreen 離脱時の MODE_BTN 除去

PlaylistDetailScreen から別画面に遷移する際、g_tracks の先頭の MODE_BTN を除去する必要がある。
→ main.cpp 側で start_shuffle_playback / start_order_playback ハンドラ内、および open_playlist_detail → PlayingScreen 遷移時に除去。

**除去方法**: `if (!ctx.g_tracks.empty() && ctx.g_tracks[0].id == "MODE_BTN") ctx.g_tracks.erase(ctx.g_tracks.begin());`

遷移パスの整理:
1. PlaylistDetailScreen → start_shuffle/order_playback → MODE_BTN 除去 → playing_tracks コピー → PlayingScreen
2. PlaylistDetailScreen → start_playback_from_playlist（曲タップ）→ MODE_BTN 除去 → playing_tracks コピー → PlayingScreen
3. PlaylistDetailScreen → B ボタン（戻る）→ MODE_BTN 除去（on_enter の逆操作が必要）
4. PlaylistDetailScreen → nav_menu → 別画面 → MODE_BTN 除去

→ **簡略化**: main.cpp のアクションハンドラ内で g_tracks を使う前に常に MODE_BTN を除去するのではなく、**PlaylistDetailScreen が画面を離れるとき（on_exit 的なタイミング）に除去する**のが最善。
→ ScreenManager::change_screen() が呼ばれるとき、旧 Screen の仮想関数 on_exit() を呼ぶ仕組みがあるか確認が必要。

→ **最も安全な方法**: start_playback_from_playlist / start_shuffle_playback / start_order_playback ハンドラの冒頭で MODE_BTN を除去。B ボタンでの戻りは ScreenManager の change_screen が on_enter を呼ぶので、次の画面の on_enter で g_tracks が上書きされるか確認。

→ PlaylistsScreen に戻る場合は g_tracks は使われないので問題ない。HomeScreen も同様。別の PL を開くと on_enter で g_tracks が再設定される。
→ **結論**: 再生開始ハンドラでのみ除去すれば十分。B で戻った場合の残留 MODE_BTN は、次の PL 開始時に g_tracks が再設定されるため問題なし。

## 4. 各機能の詳細設計

### FR-1: PlayBar 5ゾーン

ゾーン定数:
```
ZONE_1 = 55   (LOOP | PREV 境界)
ZONE_2 = 118  (PREV | PLAY 境界)
ZONE_3 = 202  (PLAY | NEXT 境界)
ZONE_4 = 265  (NEXT | SHUF 境界)
```

テキスト配置（中央寄せ計算）:
- LOOP (0-55): テキスト中央 = 27.5
- PREV (55-118): テキスト中央 = 86.5
- PLAY (118-202): テキスト中央 = 160
- NEXT (202-265): テキスト中央 = 233.5
- SHUF (265-320): テキスト中央 = 292.5

### FR-2: SHUFFLE | ORDER ボタン行

描画フロー:
```
draw_track_list_bottom() {
  for each visible track {
    if (track.id == "MODE_BTN" && state == STATE_PLAYLIST_DETAIL) {
      // 中央に縦線 (x=160)
      // 左側: "SHUFFLE" (FONT_LG, 中央寄せ)
      // 右側: "ORDER" (FONT_LG, 中央寄せ)
      // selected 時: mode_btn_focus==0 なら左半分ハイライト、1なら右半分
      continue;
    }
    // 通常描画
  }
}
```

操作フロー:
```
selected_index == 0 (MODE_BTN) の時:
  KEY_DLEFT  → mode_btn_focus = 0 (SHUFFLE)
  KEY_DRIGHT → mode_btn_focus = 1 (ORDER)
  KEY_A      → mode_btn_focus==0 ? "start_shuffle_playback" : "start_order_playback"
  タップ     → x<160 ? "start_shuffle_playback" : "start_order_playback"
```

### FR-3: 再生モード状態管理

自動次曲フロー:
```
曲終了検知 → should_auto_next = true
if (LOOP_ONE):
  同じ曲を再度 start_playback
else:
  current_track_idx++
  if (>= queue_size):
    if (LOOP_ALL): current_track_idx = 0
    if (LOOP_OFF): 再生停止 (playing_id="", is_playing=false)
  start_playback(playing_tracks[play_queue[current_track_idx]])
```
