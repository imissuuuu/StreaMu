# システム設計書 - Phase 6-A: ホーム画面リスト化 + 再生バー共通化 + Quick Access
**RDD:** `RDD-2026-03-19-0002.md`
**作成日:** 2026-03-19

---

## 1. 全体方針

- **HomeScreen を全面書き換え**: TouchButton Grid → スクロール可能リスト式メニュー
- **再生バーを共通ヘルパー関数に抽出**: PlayingScreen から `draw_play_bar()` / `handle_play_bar_touch()` を抽出し、HomeScreen でも呼べるようにする
- **FAV → Quick Access 置換**: `fav_playlist_id` (単一) → `quick_access_ids` (カンマ区切り、最大4件)
- **既存画面への影響を最小化**: PlayingScreen は共通関数呼び出しに変更するだけ。他画面は変更なし

    // 再生バーを描画する（再生中のみ内容を表示、停止中は背景のみ）

    // 再生バー領域のタッチを判定しアクション文字列を返す
    // ty >= BAR_Y のタップに対して呼ぶ。該当なしは ""

}

### 3-4. `source/ui/screens/home_screen.h` — 全面書き換え

```cpp
#pragma once
#include "../screen.h"
#include "../../app_context.h"
#include <vector>
#include <string>

class HomeScreen : public Screen {
public:
    void on_enter(AppContext& ctx) override;
    std::string update(AppContext& ctx, u32 kDown, u32 kHeld, u32 kRepeat) override;
    void draw_top(const RenderContext& ctx, UIManager& ui_mgr) override;
    void draw_bottom(const RenderContext& ctx, UIManager& ui_mgr) override;

private:
    // メニュー項目の種別
    enum ItemType {
        ITEM_SEARCH,
        ITEM_QA_HEADER,    // セクション見出し（選択不可）
        ITEM_QA_SLOT,      // Quick Access スロット（PL名 or "+ Add Playlist"）
        ITEM_PLAYLISTS,
        ITEM_PLAYING,
        ITEM_SETTINGS
    };

    struct MenuItem {
        ItemType type;
        std::string label;
        std::string playlist_id; // QA_SLOT のみ使用（空=未登録スロット）
        bool selectable;         // カーソルで選択できるか
    };

    std::vector<MenuItem> items_;
    int selected_idx_ = 0;

    void rebuild_items(const AppContext& ctx);
    std::string get_action(const AppContext& ctx, int index);

    // Quick Access ID ヘルパー
    static std::vector<std::string> parse_qa_ids(const std::string& csv);
    static std::string join_qa_ids(const std::vector<std::string>& ids);
};
```

### 3-5. `source/ui/screens/home_screen.cpp` — 全面書き換え

**rebuild_items**: AppContext から動的にメニュー項目リストを構築

```
items_ = [
  {ITEM_SEARCH,    "Search",          "", true},
  {ITEM_QA_HEADER, "Quick Access",    "", false},
  {ITEM_QA_SLOT,   "PL名",       "id1", true},   // 登録済み
  {ITEM_QA_SLOT,   "+ Add Playlist",  "", true},   // 空スロット（登録数<4のとき1つ）
  {ITEM_PLAYLISTS, "Playlists",       "", true},
  {ITEM_PLAYING,   "Playing",         "", true},   // ctx.playing_id 非空のときのみ追加
  {ITEM_SETTINGS,  "Settings",        "", true},
]
```

**draw_bottom**:

```
for each item in items_:
  if (item == QA_HEADER):
    draw with HOME_HEADER_FONT, HOME_HEADER_H
  else:
    draw with HOME_FONT, HOME_ITEM_H
    if selected: accent background

PlayBar::draw(ctx, ui_mgr); // 再生バー（常時）
```

**update**:

```
D-pad上下: selected_idx_ を移動（selectableがfalseの項目はスキップ）
タッチ: リスト領域(y < 200)のタップ → 項目判定 → get_action()
タッチ: バー領域(y >= 200) → PlayBar::handle_touch()
Aボタン: get_action(selected_idx_)
```

**get_action**:

| ItemType | アクション文字列 |
|----------|-----------------|
| ITEM_SEARCH | `"trigger_search"` |
| ITEM_QA_SLOT (登録済み) | `"open_qa_playlist"` — ctx に PL ID をセット |
| ITEM_QA_SLOT (空) | `"trigger_playlists"` |
| ITEM_PLAYLISTS | `"trigger_playlists"` |
| ITEM_PLAYING | `"trigger_playing"` |
| ITEM_SETTINGS | `"trigger_settings"` |

**parse_qa_ids / join_qa_ids**: カンマ区切り文字列 ↔ vector<string> 変換ヘルパー

## 4. 各機能の詳細設計

### FR-1/FR-2: ホームリストメニュー

```
on_enter(ctx):
  rebuild_items(ctx)
  selected_idx_ = 0 (Searchにカーソル)

update(ctx):
  playing状態変化時 → rebuild_items(ctx)

  D-pad DOWN → selected_idx_++; skip non-selectable
  D-pad UP   → selected_idx_--; skip non-selectable
  A / タップ  → get_action(selected_idx_)

  バー領域タッチ → PlayBar::handle_touch() → "prev_track"/"toggle_pause"/"next_track"

draw_bottom():
  float y = HOME_LIST_START_Y
  for each item:
    if QA_HEADER: y += HOME_HEADER_H
    else: y += HOME_ITEM_H
  PlayBar::draw()
```

### FR-3〜FR-6: Quick Access

```
parse_qa_ids("id1,id2,id3") → ["id1", "id2", "id3"]
join_qa_ids(["id1", "id2"]) → "id1,id2"

登録: ids = parse_qa_ids(config.quick_access_ids)
      ids.push_back(selected_playlist_id)
      config.quick_access_ids = join_qa_ids(ids)
      ConfigManager::save(config)

削除: ids = parse_qa_ids(config.quick_access_ids)
      remove selected_playlist_id from ids
      config.quick_access_ids = join_qa_ids(ids)
      ConfigManager::save(config)
```

### FR-7/FR-8: 再生バー共通化

```
PlayBar::draw(ctx, ui_mgr):
  bar_bg = dark ? (55,55,55) : (230,230,230)
  C2D_DrawRectSolid(0, BAR_Y, 0, 320, BAR_H, bar_bg)  // 常時描画
  if (ctx.playing_id.empty()) return;  // 停止中はここで終了
  // PREV / PLAY|PAUSE / NEXT を描画（既存コードと同一）

PlayBar::handle_touch(tx, ty, ctx):
  if (ty < BAR_Y || ctx.playing_id.empty()) return ""
  if (tx < ZONE_1) return "prev_track"
  if (tx < ZONE_2) return "toggle_pause"
  return "next_track"
```
