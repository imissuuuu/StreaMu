### FR-4: setup.py
```python
#!/usr/bin/env python3
"""Cross-platform setup script for 3DS Music Player proxy server."""
```
処理フロー:
1. Python バージョン確認（3.10+）
2. venv 作成（`./venv`）
3. venv 内 pip で `requirements.txt` をインストール
4. ffmpeg の存在確認 → なければダウンロード案内を表示
5. 完了メッセージ（起動コマンドを表示）

OS判定は `platform.system()` で Windows/Linux/Darwin を分岐。
venv 内の python/pip パスは OS に応じて `venv/Scripts/` or `venv/bin/` を使い分け。
