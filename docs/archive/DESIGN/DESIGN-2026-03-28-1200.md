# システム設計書 - Thumbnail（本実装）
**RDD:** `RDD-2026-03-28-1200.md`
**作成日:** 2026-03-28

## 1. 全体方針

- **スレッドモデル**: サムネイルDLスレッドは独立に1本。メインスレッドが起動トリガーを判定し、スレッドは HTTP 取得 + stb_image デコード + クロップまで行う。GPU テクスチャ化（`load_from_pixels()`）はメインスレッドで実行する（GPU API はメインスレッドのみ安全）。
- **同期方式**: `LightLock` + フラグ（`std::atomic` 禁止、coding-patterns #6）。
- **クロップ**: `load_from_memory()` の中でデコード後にピクセルデータを中央正方形にクロップしてから `load_from_pixels()` へ渡す。
- **表示条件変更**: `STATE_PLAYING_UI` 限定 → Settings 以外の全画面で `thumbnail_tex.is_loaded()` なら表示。
- **位置変更**: 中央 (x=136) → 左側 (x=8, y=56)。

### 3-3. `source/ui/wallpaper.cpp`
`load_from_memory()` にクロップ処理を追加:

```cpp
bool Wallpaper::load_from_memory(const uint8_t* data, size_t size) {
    unload();

    int w = 0, h = 0, channels = 0;
    u8* rgba = stbi_load_from_memory(data, (int)size, &w, &h, &channels, 4);
    if (!rgba) return false;
    if (w <= 0 || h <= 0 || w > 1024 || h > 1024) {
        stbi_image_free(rgba);
        return false;
    }

    // Center-crop to square
    int crop = w < h ? w : h;
    int ox = (w - crop) / 2;
    int oy = (h - crop) / 2;
    u8* cropped = static_cast<u8*>(malloc(crop * crop * 4));
    if (!cropped) { stbi_image_free(rgba); return false; }
    for (int row = 0; row < crop; row++) {
        memcpy(cropped + row * crop * 4,
               rgba + ((oy + row) * w + ox) * 4,
               crop * 4);
    }
    stbi_image_free(rgba);

    bool ok = load_from_pixels(cropped, crop, crop);
    free(cropped);
    return ok;
}
```

`draw_at()` は変更不要（クロップ後は正方形なので letterbox == fill）。

### 3-6. `source/main.cpp`
メインループにサムネイル取得トリガーとテクスチャ化処理を追加。

#### サムネイルDLスレッド関数（download_thread の近くに定義）:
```cpp
static void thumbnail_dl_thread(void* arg) {
    AppContext* ctx = static_cast<AppContext*>(arg);

    // Copy video ID under lock
    LightLock_Lock(&ctx->lock);
    std::string vid_id = ctx->thumbnail_vid_id;
    YouTubeAPI* api = ctx->api;
    LightLock_Unlock(&ctx->lock);

    if (!api || vid_id.empty()) {
        LightLock_Lock(&ctx->lock);
        ctx->thumbnail_loading = false;
        LightLock_Unlock(&ctx->lock);
        return;
    }

    // Download (no lock needed — http_get has its own)
    std::vector<uint8_t> raw;
    bool ok = api->download_thumbnail(vid_id, raw);

    if (ok && !raw.empty()) {
        // Decode + crop on this thread (CPU only, no GPU calls)
        int w = 0, h = 0, ch = 0;
        u8* rgba = stbi_load_from_memory(raw.data(), (int)raw.size(), &w, &h, &ch, 4);
        if (rgba && w > 0 && h > 0) {
            int crop = w < h ? w : h;
            int ox = (w - crop) / 2;
            int oy = (h - crop) / 2;
            std::vector<uint8_t> pixels(crop * crop * 4);
            for (int row = 0; row < crop; row++) {
                memcpy(pixels.data() + row * crop * 4,
                       rgba + ((oy + row) * w + ox) * 4,
                       crop * 4);
            }
            stbi_image_free(rgba);

            LightLock_Lock(&ctx->lock);
            ctx->thumbnail_pixels = std::move(pixels);
            ctx->thumbnail_crop_size = crop;
            ctx->thumbnail_ready = true;
            ctx->thumbnail_loading = false;
            LightLock_Unlock(&ctx->lock);
            return;
        }
        if (rgba) stbi_image_free(rgba);
    }

    // Failure
    LightLock_Lock(&ctx->lock);
    ctx->thumbnail_loading = false;
    LightLock_Unlock(&ctx->lock);
}
```

**注意**: `stbi_load_from_memory` をスレッドで呼ぶには、`stb_image.h` の宣言が必要。`wallpaper.cpp` で `STB_IMAGE_IMPLEMENTATION` を定義済みなので、`main.cpp` では `#include "stb_image.h"` のみ（実装なし宣言のみ）を追加する。

#### メインループ内（player.update() の前あたり）:
```cpp
// --- Thumbnail async trigger ---
{
    LightLock_Lock(&ctx.lock);
    bool need_fetch = !ctx.playing_id.empty()
                   && ctx.playing_id != ctx.thumbnail_vid_id
                   && !ctx.thumbnail_loading;
    if (need_fetch) {
        ctx.thumbnail_tex.unload();
        ctx.thumbnail_vid_id = ctx.playing_id;
        ctx.thumbnail_loading = true;
        ctx.thumbnail_ready = false;
    }
    LightLock_Unlock(&ctx.lock);

    if (need_fetch) {
        // Detached thread — fire-and-forget, sets thumbnail_ready when done
        threadCreate(thumbnail_dl_thread, &ctx, 0x4000, 0x3F, -2, true);
    }
}

// --- Thumbnail GPU upload (main thread only) ---
{
    LightLock_Lock(&ctx.lock);
    bool ready = ctx.thumbnail_ready;
    LightLock_Unlock(&ctx.lock);

    if (ready) {
        LightLock_Lock(&ctx.lock);
        std::vector<uint8_t> pixels = std::move(ctx.thumbnail_pixels);
        int crop_size = ctx.thumbnail_crop_size;
        ctx.thumbnail_ready = false;
        LightLock_Unlock(&ctx.lock);

        ctx.thumbnail_tex.unload();
        ctx.thumbnail_tex.load_from_pixels(pixels.data(), crop_size, crop_size);
    }
}
```

#### クリーンアップ:
現状の `ctx.thumbnail_tex.unload()` は `g_ctx_ptr.reset()` 前に既に移動済み（今セッション修正済み）。
追加で、サムネイルスレッドは detached なので join 不要。ただし `thumbnail_loading` 中に `ctx` が破棄される可能性を考慮し、終了前に loading 完了を待つ:

```cpp
// Wait for thumbnail thread to finish (if running)
{
    bool still_loading;
    do {
        LightLock_Lock(&ctx.lock);
        still_loading = ctx.thumbnail_loading;
        LightLock_Unlock(&ctx.lock);
        if (still_loading) svcSleepThread(10 * 1000 * 1000);
    } while (still_loading);
}
ctx.thumbnail_tex.unload();
g_ctx_ptr.reset();
```

## 4. 各機能の詳細設計

### FR-3: 非同期DL フロー

```
メインループ (毎フレーム)
  ├─ playing_id != thumbnail_vid_id && !thumbnail_loading ?
  │   ├─ YES → thumbnail_vid_id = playing_id
  │   │        thumbnail_loading = true
  │   │        threadCreate(thumbnail_dl_thread, detached)
  │   └─ NO  → skip
  │
  ├─ thumbnail_ready ?
  │   ├─ YES → pixels を取り出し
  │   │        thumbnail_tex.load_from_pixels() [GPU upload]
  │   │        thumbnail_ready = false
  │   └─ NO  → skip
  │
  └─ 描画: thumbnail_tex.is_loaded() → draw_at()
```

### FR-4: クロップ

```
原画像 (120×90):              クロップ後 (90×90):
+------------------+          +------------+
|  ox  |  crop  |  |          |            |
|<-15->|<--90-->|  |    →     |   90×90    |
|      |        |  |          |            |
+------------------+          +------------+
ox = (120-90)/2 = 15
oy = (90-90)/2 = 0
```

### FR-5: 曲変更検知の競合制御

曲が連続で変わった場合（スキップ連打）:
1. フレーム N: playing_id = "aaa" → スレッド起動
2. フレーム N+1: playing_id = "bbb" → `thumbnail_loading = true` なので起動しない
3. スレッド完了: `thumbnail_ready = true`, `thumbnail_loading = false`
4. フレーム N+K: `thumbnail_ready = true` → pixels を取り出して GPU upload
5. フレーム N+K: `playing_id ("bbb") != thumbnail_vid_id ("aaa")` → 新スレッド起動
6. 最終的に "bbb" のサムネイルが表示される

→ 中間の取得は無駄だが、メモリリーク/クラッシュなし。スキップ連打でも安全。
