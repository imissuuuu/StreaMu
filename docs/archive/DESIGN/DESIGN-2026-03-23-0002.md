## 4. 各機能の詳細設計

### FR-1: パス変更
全4ファイルのリテラル文字列を `3ds-music-player` → `StreaMu` に置換するだけ。ロジック変更なし。

### FR-2: IP案内表示
```
フロー:
1. ctx.config.server_ip が空
2. begin_top_screen() で上画面描画開始
3. 案内テキスト描画（中央配置）
4. end_frame() でフレーム確定（上画面に案内が表示される）
5. show_ip_keyboard() 呼び出し（swkbdが下画面に出る）
6. 上画面の案内テキストはswkbd操作中も見える
```
