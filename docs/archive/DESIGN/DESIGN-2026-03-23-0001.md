# システム設計書 - フレンドリスト旧タイトル/アイコン修正
**RDD:** `RDD-2026-03-23-0001.md`
**作成日:** 2026-03-23

## 1. 全体方針
- コード変更なし。ビルド成果物と設定ファイルの修正のみ。
- 旧名残存ファイル削除 → クリーンビルド → 再インストールを段階的に試行。
- 解消しない場合は `app.rsf` の UniqueId を変更し、本体側に新規タイトルとして認識させる。

## 2. 新規ファイル
なし

## 3. 既存ファイルの変更

### `3ds_music_player.smdh`（削除）
- 旧名のSMDHファイル。ビルドで使用されていないが、混乱防止のため削除。

### `app.rsf`（条件付き変更）
- **変更条件**: 段階1（クリーンビルド+再インストール）で解消しない場合のみ
- **変更前**: `UniqueId: 0xFF3D0`
- **変更後**: `UniqueId: 0xFF3D1`
- 理由: フレンドリストのキャッシュは UniqueId に紐づくため、IDを変更すれば新規タイトルとして扱われる

## 4. 各機能の詳細設計

### FR-1: フレンドリスト修正（段階的アプローチ）

**段階1: クリーンビルド**
```
1. 旧SMDH削除: rm 3ds_music_player.smdh
2. make clean && make cia
3. 3DS本体: FBIで旧CIAを完全アンインストール
4. 新CIAをインストール → フレンドリスト確認
```

**段階2: UniqueId変更**（段階1で未解消の場合）
```
1. app.rsf の UniqueId を 0xFF3D0 → 0xFF3D1 に変更
2. make clean && make cia
3. 3DS本体: FBIで旧CIAを完全アンインストール
4. 新CIAをインストール → フレンドリスト確認
```

### FR-2: 旧ファイル削除
- `3ds_music_player.smdh` を削除するのみ

## 5. 実装順序
1. `3ds_music_player.smdh` 削除
2. `make clean && make cia` でビルド確認
3. ユーザーが3DS本体で再インストール・動作確認
4. （必要に応じて）UniqueId変更 → 再ビルド
