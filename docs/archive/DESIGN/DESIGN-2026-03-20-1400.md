# システム設計書 - 設定画面スクロール対応
**RDD:** `RDD-2026-03-20-1400.md`
**作成日:** 2026-03-20

## 1. 全体方針

- `SettingsScreen` に `float scroll_offset_ = 0.0f` を追加し、通常モードの設定リスト描画・タッチ判定に適用する
- D-pad: `selected_item_` 変更後に選択項目が可視領域内に収まるよう `scroll_offset_` を自動調整
- タッチスワイプ: `ctx.touch_state.update()` の `delta_y` を `scroll_offset_` に加算（SearchScreen と同パターン）
- タップ判定: `scroll_offset_` を考慮した座標で項目を判定（既存 two-tap ロジックはそのまま）
- パレットモード・スライダー編集モード・壁紙選択モードには影響しない（これらは独自の描画パスを持つ）

#### update(): タッチスワイプ処理（通常モード）

現在のタッチ処理ブロック（line 368-436）を拡張。
`ctx.touch_state.begin()` 後に `update()` を毎フレーム呼び、ドラッグ時は `scroll_offset_` を更新:

```cpp
// 変更前（line 374あたり）:
if (!(kHeld & KEY_TOUCH) && ctx.touch_state.is_touching) {

// 変更後:
// タッチ継続中 → スクロール処理
if ((kHeld & KEY_TOUCH) && ctx.touch_state.is_touching) {
    touchPosition touch;
    hidTouchRead(&touch);
    int delta_y = ctx.touch_state.update(touch.px, touch.py);
    if (ctx.touch_state.is_dragging) {
        scroll_offset_ += delta_y;
        // クランプ
        float max_scroll = 36.0f; // content(252) - visible(216) ≈ 36
        if (scroll_offset_ < 0.0f) scroll_offset_ = 0.0f;
        if (scroll_offset_ > max_scroll) scroll_offset_ = max_scroll;
    }
}
if (!(kHeld & KEY_TOUCH) && ctx.touch_state.is_touching) {
```

#### update(): タッチタップの座標補正

タップ判定の y 座標に `scroll_offset_` を加算して、スクロール後の正しい項目を特定:

```cpp
// 変更前:
float y = 8;

// 変更後:
float y = 8 - scroll_offset_;
```

#### update(): D-pad ナビゲーション後のスクロール追従

D-pad UP/DOWN の処理後にスクロール追従ロジックを追加:

```cpp
// D-pad処理の後に追加:
{
    // 選択項目のY位置を計算
    float item_y = 8.0f;
    for (int i = 0; i < selected_item_; i++) {
        item_y += (i == ITEM_SEPARATOR) ? 20.0f : 28.0f;
    }
    float visible_top = scroll_offset_;
    float visible_bottom = scroll_offset_ + 216.0f; // 可視領域高さ
    if (item_y < visible_top) {
        scroll_offset_ = item_y;
    } else if (item_y + 28.0f > visible_bottom) {
        scroll_offset_ = item_y + 28.0f - 216.0f;
    }
    if (scroll_offset_ < 0.0f) scroll_offset_ = 0.0f;
}
```

#### update(): スライダー編集モードの座標補正

HUE スライダー・D-Pad Speed スライダーの `item_y` 計算に `scroll_offset_` を反映:

```cpp
// 変更前:
float item_y = 8.0f + ITEM_HUE * 28.0f;

// 変更後（HUEの場合）:
float item_y = 8.0f + ITEM_HUE * 28.0f - scroll_offset_;
```

D-Pad Speed も同様:
```cpp
float item_y = 8.0f + ITEM_DPAD_SPEED * 28.0f - scroll_offset_;
```

**注意**: ITEM_HUE は index 2、ITEM_DPAD_SPEED は index 5。index 5 以前にセパレータはないので `index * 28.0f` で正しい。

#### draw_bottom(): 通常設定リストの描画にスクロール適用

```cpp
// 変更前:
float y = 8;

// 変更後:
float y = 8 - scroll_offset_;
```

描画時、画面外の項目はスキップ（クリッピング）:
```cpp
// 各項目描画前に追加:
if (y + item_h < 0 || y > 220) { y += item_h; continue; }
// セパレータの場合:
if (y + 20 < 0 || y > 220) { y += 20; continue; }
```
