# システム設計書 - Phase 5-E: PlayingScreen SELECT挙動統一
**RDD:** `RDD-2026-03-19-0004.md`
**作成日:** 2026-03-19

## 1. 全体方針

- 変更箇所は main.cpp と ui_renderer.cpp のみ。小規模な変更。
- `from_playlist` 判定を `from_playlist || from_playing` に拡張する方針。
- PlayingScreen は `playing_tracks` を使うが、TRACK_OPTIONS ポップアップの描画は `g_tracks` を参照する。→ 削除時に `playing_tracks` と `g_tracks` 両方の同期が必要。
- TRACK_DETAILS ポップアップも `g_tracks` を参照する。PlayingScreen から開く場合は `playing_tracks` を参照するよう変更が必要。

**TRACK_OPTIONS 削除処理の変更 (index 1):**
```
変更前: PlaylistDetailScreen からのみ。selected_playlist_id で PL から削除、g_tracks を更新。
変更後: PlayingScreen からの場合は active_playlist_id で PL から削除、playing_tracks からも除去、play_queue を再構築。
```

PlayingScreen 削除処理の詳細:
```cpp
if (ctx.previous_state == STATE_PLAYING_UI) {
    playlist_manager.remove_track(ctx.active_playlist_id, ctx.selected_track_id);
    ctx.playlists = playlist_manager.get_playlists();
    // playing_tracks から削除
    for (auto it = ctx.playing_tracks.begin(); it != ctx.playing_tracks.end(); ++it) {
        if (it->id == ctx.selected_track_id) {
            ctx.playing_tracks.erase(it);
            break;
        }
    }
    // play_queue 再構築
    int cur_playing_idx = -1; // 現在再生中の曲の新 playing_tracks index
    for (int i = 0; i < (int)ctx.playing_tracks.size(); ++i) {
        if (ctx.playing_tracks[i].id == ctx.playing_id) {
            cur_playing_idx = i;
            break;
        }
    }
    ctx.play_queue.clear();
    for (size_t i = 0; i < ctx.playing_tracks.size(); ++i)
        ctx.play_queue.push_back(i);
    if (ctx.shuffle_mode) {
        // Fisher-Yates シャッフル、再生中の曲を先頭に
        for (size_t i = ctx.play_queue.size() - 1; i > 0; --i) {
            size_t j = rand() % (i + 1);
            std::swap(ctx.play_queue[i], ctx.play_queue[j]);
        }
        if (cur_playing_idx >= 0) {
            for (size_t i = 0; i < ctx.play_queue.size(); ++i) {
                if (ctx.play_queue[i] == cur_playing_idx) {
                    std::swap(ctx.play_queue[0], ctx.play_queue[i]);
                    break;
                }
            }
            ctx.current_track_idx = 0;
        }
    } else {
        ctx.current_track_idx = cur_playing_idx >= 0 ? cur_playing_idx : 0;
    }
    // selected_index 調整
    if (ctx.selected_index >= (int)ctx.playing_tracks.size())
        ctx.selected_index = (int)ctx.playing_tracks.size() - 1;
    if (ctx.selected_index < 0) ctx.selected_index = 0;
    // 再生中の曲が削除された場合
    if (ctx.playing_id == ctx.selected_track_id) {
        // 次の曲があれば再生、なければ停止
        // → ここでは停止のみ。ユーザーが手動で次を選べる
        ctx.playing_id = "";
        MP3Player::is_playing = false;
    }
}
```

## 4. 各機能の詳細設計

### FR-1: SELECT ハンドラ追加

処理フロー:
```
KEY_SELECT pressed
  if STATE_PLAYING_UI:
    Lock → playing_tracks[selected_index].id → selected_track_id → Unlock
    previous_state = STATE_PLAYING_UI
    current_state = STATE_POPUP_TRACK_OPTIONS
```

### FR-2: 削除処理

PlayingScreen からの削除フロー:
```
1. playlist_manager.remove_track(active_playlist_id, selected_track_id)
2. playlists 再読み込み
3. playing_tracks から該当曲を erase
4. play_queue 再構築（shuffle_mode 考慮）
5. selected_index 範囲調整
6. 再生中曲が削除された → 停止
7. current_state = STATE_PLAYING_UI に戻る
```
