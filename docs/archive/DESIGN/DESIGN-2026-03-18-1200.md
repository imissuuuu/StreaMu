// 追加するヘルパー関数
void apply_dpad_speed(int speed) {
    static const u8 delays[]    = {30, 24, 15, 10, 6};
    static const u8 intervals[] = {10,  7,  4,  3, 2};
    int idx = std::max(0, std::min(4, speed - 1));
    hidSetRepeatParameters(delays[idx], intervals[idx]);
}

// 呼び出し箇所1: config load 直後（初期化フロー内）

## 4. 各機能の詳細設計

### FR-3: D-Pad Speed スライダーUI

**スライダーレイアウト（Hueと同じ座標系）:**
```
bar_x=100, bar_w=180, item_h=28
ステップ位置: bar_x + (step-1) / 4.0 * bar_w  (step=1..5)
カーソル位置: bar_x + (speed-1) / 4.0 * bar_w - 2
```

**描画（draw_bottom 内 ITEM_DPAD_SPEED ブランチ）:**
1. ラベル "D-Pad Speed" を x=8 に描画
2. バー背景（グレー）を bar_x, y+10, w=180, h=8 に描画
3. 5つのティックマーク（縦線）を各ステップ位置に描画
4. カーソル（縦棒）を現在値の位置に描画
5. 値テキスト（"1"〜"5"）を bar_x+bar_w+5 に描画

**編集モード（in_edit_mode_ && selected_item_ == ITEM_DPAD_SPEED）:**
```
タッチ処理:
  tap_x → step = round((tap_x - bar_x) / bar_w * 4) + 1
  step = clamp(step, 1, 5)
  editing_config_.dpad_speed = step

D-pad左: dpad_speed = max(1, dpad_speed - 1)
D-pad右: dpad_speed = min(5, dpad_speed + 1)
A/B: in_edit_mode_ = false
```

**編集モード外からの遷移:**
- Aボタン: `in_edit_mode_ = true`（Hueと同じ）
- 2回タップ: `in_edit_mode_ = true`

### FR-2: hidSetRepeatParameters の呼び出しフロー

```
アプリ起動
  └─ ConfigManager::load(ctx.config)
  └─ apply_dpad_speed(ctx.config.dpad_speed)   ← デフォルト3（標準）

設定画面で Save
  └─ ctx.config = editing_config_
  └─ ConfigManager::save(editing_config_)
  └─ apply_theme(ctx.config, m_colors)
  └─ return "trigger_home"
      └─ main.cpp: apply_dpad_speed(ctx.config.dpad_speed)  ← 反映
```
