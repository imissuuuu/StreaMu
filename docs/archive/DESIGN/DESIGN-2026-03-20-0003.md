### 3-5. `source/main.cpp` — 起動時IP入力 + タイムアウトメニュー変更

**swkbd ヘルパー関数:**
```cpp
static std::string show_ip_keyboard(const std::string& hint) {
    SwkbdState swkbd;
    char buf[64] = {0};
    swkbdInit(&swkbd, SWKBD_TYPE_NORMAL, 1, 63);
    swkbdSetHintText(&swkbd, hint.c_str());
    swkbdSetInitialText(&swkbd, hint.c_str());
    SwkbdButton button = swkbdInputText(&swkbd, buf, sizeof(buf));
    if (button == SWKBD_BUTTON_CONFIRM && strlen(buf) > 0)
        return std::string(buf);
    return "";
}
```

**接続ループ前に挿入:**
```cpp
// server_ip が空なら swkbd で入力
if (ctx.config.server_ip.empty()) {
    std::string ip = show_ip_keyboard("192.168.x.x:8080");
    if (!ip.empty()) {
        ctx.config.server_ip = ip;
        ConfigManager::save(ctx.config);
    }
}
api.set_server_ip(ctx.config.server_ip);
```

**タイムアウトメニュー:**
- 現状: index 0=Retry, 1=Exit (2択)
- 変更: index 0=Retry, 1=Change IP, 2=Exit (3択)
- 「Change IP」選択時: swkbd表示 → IP更新 → save → リトライ

## 4. 各機能の詳細設計

### swkbd 使用パターン
libctru の swkbd は同期的（呼ぶとキーボードが表示され、入力完了まで戻ってこない）。
描画ループ中に呼ぶと1フレーム止まるが、IP入力は頻繁でないため問題なし。
