# システム設計書 - Playing UI Screen
**RDD:** `RDD-2026-03-18-1000.md`
**作成日:** 2026-03-18

## 1. 全体方針

- `PlayingScreen` を既存の `ScreenManager` に登録する（HOME/SEARCH/PLAYLISTS 等と同格）
- `STATE_PLAYING_UI` を `AppState` に追加し、全ての分岐処理を既存パターンに従って追記
- `playing_duration` フィールドを `AppContext`/`RenderContext` に追加し、`start_playback` で設定
- `PlayingScreen::draw_top()` がバナー描画を自前で行い（`UIRenderer::draw_top_screen` は使わない）、
  曲情報バー（item 9）を上画面下部に追加描画する
- 下画面のトラックリストは `draw_track_list_bottom()` の流用ではなく PlayingScreen 内でインライン実装
  （理由: ヘッダ行30px + プレイバーbar40px の制約区間に合わせる必要があるため）

## 2. 新規ファイル

### `source/ui/screens/playing_screen.h`

```cpp
#pragma once
#include "../screen.h"
#include "../ui_manager.h"

class PlayingScreen : public Screen {
public:
    void on_enter(AppContext& ctx) override;
    std::string update(AppContext& ctx, u32 kDown, u32 kHeld, u32 kRepeat) override;
    void draw_top(const RenderContext& ctx, UIManager& ui_mgr) override;
    void draw_bottom(const RenderContext& ctx, UIManager& ui_mgr) override;

private:
    // 下画面レイアウト定数
    static constexpr float HDR_H  = 30.0f;  // ホームボタン行の高さ
    static constexpr float BAR_Y  = 200.0f; // プレイバーのY開始位置
    static constexpr float BAR_H  = 40.0f;  // プレイバーの高さ
    static constexpr float LIST_START_Y = HDR_H;  // トラックリスト開始Y
    static constexpr float LIST_END_Y   = BAR_Y;  // トラックリスト終了Y
    static constexpr float ITEM_H = 30.0f;  // 2行アイテム高さ (BTM_ITEM_HEIGHT_2ROW と同値)

    // ドラッグスクロール用 (既存パターン流用)
    bool m_drag_started = false;
};
```

### `source/ui/screens/playing_screen.cpp` — 主要メソッド設計

**`on_enter`**
```
ctx.current_state = STATE_PLAYING_UI
ctx.scroll_offset_y = 0.0f  // スクロールリセット
```

**`draw_top`** （上画面 400×240）
```
[y=0..20]   バナー: C2D_DrawRectSolid(0,0,0,400,20, accent)
            sys_info 文字列（時刻・バッテリー・WiFi）→ 既存 draw_top_screen と同じ内容を複製
[y=20..210] 背景: bg_top カラー（何も描かない = begin_top_screen で塗りつぶし済み）
[y=210..240] 曲情報バー:
            C2D_DrawRectSolid(0,210,0,400,30, button_bg)
            左: playing_title（先頭行のみ、幅280px で clamp）
            右: playing_duration ("3:45") → C2D_DrawText right-align (x=392-text_width)
```

**`draw_bottom`** （下画面 320×240）
```
[y=0..30]   ホームボタン:
            C2D_DrawRectSolid(4,4,0,70,22, button_bg)
            文字 "HOME" を中央に描画
[y=30..200] トラックリスト (インライン実装):
            calc_scroll(scroll_offset_y, ITEM_H, scroll_items, y_shift)
            y_base = LIST_START_Y - y_shift
            int first = scroll_items
            描画ループ: first ~ first+6 の g_tracks を y_base から描画
            現在再生中 (playing_id == track.id) の行はアクセントカラーでハイライト
            各アイテム: Row1=title (FONT_MD), Row2=duration (FONT_SM, text_dim)
[y=200..240] プレイバーバー:
            C2D_DrawRectSolid(0,200,0,320,40, accent)
            3等分 (各 ~106px):
              [0..106]   "PREV" テキスト（将来アイコン化想定、関数に切り出す）
              [107..213] "PLAY"/"PAUSE" (is_paused ? "PLAY" : "PAUSE")
              [214..319] "NEXT"
```

**`update`** — タッチ・入力処理
```
// ホームボタンタップ (x:4-74, y:4-26)
if kDown & KEY_TOUCH && tap in home_rect → return "trigger_home"

// プレイバーバータップ (y:200-240)
if kDown & KEY_TOUCH && tap.y >= 200:
    if tap.x < 107  → return "prev_track"
    if tap.x < 214  → return "toggle_pause"
    else            → return "next_track"

// トラックリストのドラッグスクロール (y:30-200)
// 既存パターン (touch_state.begin/update/end) を流用

// D-pad でのナビゲーション: navigate_track_list(ctx, kRepeat) 流用可
```

**④ アクションハンドリングに追加**
```cpp
} else if (action == "trigger_playing") {
    screen_mgr.change_screen(ctx, "PlayingScreen");
    kDown &= ~KEY_A;
} else if (action == "prev_track") {
    // main.cpp の KEY_L / LR_SKIP と同じロジック
    LightLock_Lock(&ctx.lock);
    if (!ctx.play_queue.empty()) {
        ctx.current_track_idx--;
        if (ctx.current_track_idx < 0)
            ctx.current_track_idx = (int)ctx.play_queue.size() - 1;
        int prev_idx = ctx.play_queue[ctx.current_track_idx];
        Track prev_track = ctx.g_tracks[prev_idx];
        LightLock_Unlock(&ctx.lock);
        start_playback(prev_track);
    } else { LightLock_Unlock(&ctx.lock); }
} else if (action == "next_track") {
    // main.cpp の KEY_R / LR_SKIP と同じロジック
    LightLock_Lock(&ctx.lock);
    if (!ctx.play_queue.empty()) {
        ctx.current_track_idx++;
        if (ctx.current_track_idx >= (int)ctx.play_queue.size())
            ctx.current_track_idx = 0;
        int next_idx = ctx.play_queue[ctx.current_track_idx];
        Track next_track = ctx.g_tracks[next_idx];
        LightLock_Unlock(&ctx.lock);
        start_playback(next_track);
    } else { LightLock_Unlock(&ctx.lock); }
}
```

**⑤ start_playback_from_playlist アクション後に遷移を追加**
```cpp
} else if (action == "start_playback_from_playlist") {
    // ... 既存のシャッフルロジック ...
```

**⑥ KEY_B ハンドリングに STATE_PLAYING_UI を追加**
```cpp
if (!was_popup) {
    if (ctx.current_state == STATE_SEARCH || ctx.current_state == STATE_PLAYLISTS) {
        screen_mgr.change_screen(ctx, "HomeScreen");
    } else if (ctx.current_state == STATE_PLAYLIST_DETAIL) {
        screen_mgr.change_screen(ctx, "PlaylistsScreen");

```

**⑦ 描画処理 — bg_state 条件を拡張**

```cpp
// Top screen

    screen_mgr.draw_top(render_ctx, ui_mgr);

    renderer.draw_top_screen(render_ctx);

    screen_mgr.draw_bottom(render_ctx, ui_mgr);
}
```

## 4. 各機能の詳細設計

### FR-08 画面遷移トリガー

| トリガー | 発火箇所 | アクション |
|---------|---------|-----------|
| ホーム "Now Playing" タップ | `home_screen.cpp` | `"trigger_playing"` |
| プレイリスト再生開始 | `main.cpp` `start_playback_from_playlist` 後 | `change_screen("PlayingScreen")` |
| B ボタン（playing UI から） | `main.cpp` KEY_B ハンドラ | `change_screen("HomeScreen")` |
| HOME ボタン（下画面左上） | `playing_screen.cpp` update | `"trigger_home"` |

### FR-04 曲情報バー（上画面 y=210-240）

```
入力: ctx.playing_title_lines[0], ctx.playing_duration
処理: タイトルは幅 280px を超えないよう表示（超える場合は末尾省略）
      再生時間は x=392-text_width で右寄せ
出力: グレーバー上に "曲名    3:45" の形式で表示
```

### FR-07 再生タッチUI（下画面 y=200-240）

```
入力: タッチ座標 (tap_x, tap_y)  where tap_y >= 200
処理: x < 107  → "prev_track"
      x < 214  → "toggle_pause"
      else     → "next_track"
出力: アクション文字列 → main.cpp の既存ハンドラに委譲
色:  accent (= UI ブロック色) → テーマ変更で自動同期
```

## 5. 実装順序

1. `AppState` に `STATE_PLAYING_UI` 追加 + `playing_duration` フィールド追加
   → ビルド確認（コンパイルエラーがないことを確認）

2. `playing_screen.h/.cpp` 骨格作成（on_enter + draw_top/draw_bottom の空実装）
   → `main.cpp` に `#include` + `screen_mgr.add_screen` + 描画条件追加
   → ビルド確認

3. `home_screen.cpp` の "Now Playing" アクション実装 + `main.cpp` の `trigger_playing` ハンドリング
   → 実機/エミュで PlayingScreen への遷移確認

4. `playing_screen.cpp` の draw_top 実装（バナー + 背景 + 曲情報バー）
   → ビルド確認・外観確認

5. `playing_screen.cpp` の draw_bottom 実装（HOME ボタン + トラックリスト + プレイバーバー）
   → ビルド確認・外観確認

6. `playing_screen.cpp` の update 実装（タッチ: HOME・プレイバー・スクロール）
   → `main.cpp` にアクションハンドリング追加 (prev_track / next_track)

7. `start_playback_from_playlist` 後の自動遷移追加 + `playing_duration` 設定追加
   → 全機能統合テスト
