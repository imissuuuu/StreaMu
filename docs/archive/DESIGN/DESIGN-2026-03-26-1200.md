## 1. 全体方針

- **引き算デザイン**: グラデーション・ベベルは一切使わない。色と線だけで状態を伝える
- **共通ヘルパー関数**: dashed線描画と左バー描画を共通関数として `track_list_helpers` に追加し、全画面で再利用
- **既存描画の最小変更**: 選択/再生中の背景描画は既存のC2D_DrawRectSolid呼び出しに追加・変更するだけ
- **citro2dにはdashed線APIがない**: 短い矩形をループで等間隔に描画するヘルパーを自作

## 4. 各機能の詳細設計

### FR-1: 選択項目 — アクセント塗り + 左3pxバー

既存の `C2D_DrawRectSolid(0, y, 0, 320, h, accent)` はそのまま維持。その上に左バーを重ねて描画。

```cpp
// track_list_helpers.h に追加
inline void draw_selection_left_bar(float y, float h, u32 accent) {
    // accent を明るくする: 白を25%ブレンド
    u8 r = (accent >> 24) & 0xFF;
    u8 g = (accent >> 16) & 0xFF;
    u8 b = (accent >> 8)  & 0xFF;
    u8 a = accent & 0xFF;
    r = r + (255 - r) / 4;
    g = g + (255 - g) / 4;
    b = b + (255 - b) / 4;
    u32 bright = (r << 24) | (g << 16) | (b << 8) | a;
    C2D_DrawRectSolid(0, y, 0, 3, h, bright);
}
```

適用箇所（全画面共通パターン）:
```cpp
// 変更前:
if (i == ctx.selected_index) {
    C2D_DrawRectSolid(0, y_pos - 2, 0, 320, BTM_ITEM_HEIGHT_2ROW, ctx.theme->accent);
}

// 変更後:
if (i == ctx.selected_index) {
    C2D_DrawRectSolid(0, y_pos - 2, 0, 320, BTM_ITEM_HEIGHT_2ROW, ctx.theme->accent);
    draw_selection_left_bar(y_pos - 2, BTM_ITEM_HEIGHT_2ROW, ctx.theme->accent);
}
```

### FR-2: 再生中項目 — アクセントティント背景

既存の `playing_bg` による塗りを、より透明なアクセントティントに変更。

```cpp
// 変更前:
} else if (is_playing) {
    C2D_DrawRectSolid(0, y_pos - 2, 0, 320, BTM_ITEM_HEIGHT_2ROW, ctx.theme->playing_bg);
}

// 変更後:
} else if (is_playing) {
    // accent に低透過度を適用（~25/255 ≈ 10%）
    u32 tint = (ctx.theme->accent & 0xFFFFFF00) | 0x19;
    C2D_DrawRectSolid(0, y_pos - 2, 0, 320, BTM_ITEM_HEIGHT_2ROW, tint);
}
```

**Note**: citro2dのカラーフォーマットは `RGBA8` → `(R<<24)|(G<<16)|(B<<8)|A`。
アルファ値 `0x19` = 25/255 ≈ 10%。ライト/ダークテーマ両方でこの値で十分視認できるか実機テストで確認。

再生中タイトルの色は既存の `playing_text` をそのまま使用（変更不要）。ただし現在 `playing_text` は `text_body` と同じ色で使われているので、アクセント系にするかは実機テスト後に判断。

### FR-4: 点線セパレータ（dashed line）

citro2dにdashed線APIはないため、短い矩形を等間隔で描画するヘルパーを作成。

```cpp
// track_list_helpers.h に追加
inline void draw_dashed_line_h(float x, float y, float width, u32 color,
                                float dash_len = 3.0f, float gap_len = 3.0f) {
    for (float dx = 0; dx < width; dx += dash_len + gap_len) {
        float seg = dash_len;
        if (dx + seg > width) seg = width - dx;
        C2D_DrawRectSolid(x + dx, y, 0, seg, 1, color);
    }
}
```

- `dash_len=3, gap_len=3`: 3pxの線 + 3pxの隙間 → レトロ感のある点線
- 320px幅で約54回のdrawcall（1項目あたり。7項目で約370回だがグラデーション描画よりは軽い）
- **最適化**: 実機パフォーマンスが問題なら `dash_len=4, gap_len=4` に変更して回数を減らす

各リスト項目の描画後に呼び出し:
```cpp
// 通常項目（非選択・非再生中）の下端にdashed線
// 選択項目の直下にはdashed線を描かない（アクセント塗りが区切り代わり）
if (i != ctx.selected_index) {
    u32 sep_color = ctx.theme->text_dim & 0x14FFFFFF;  // 8% opacity
    draw_dashed_line_h(0, y_pos - 2 + BTM_ITEM_HEIGHT_2ROW - 1, 320, sep_color);
}
```
