# システム設計書 - 上画面壁紙機能
**RDD:** `RDD-2026-03-19-0005.md`
**作成日:** 2026-03-19

## 1. 全体方針

- PNG デコードは `stb_image.h`（ヘッダーオンリーライブラリ）を使用。3DS homebrew で実績あり。
- デコードした RGBA ピクセルを 3DS GPU のタイルフォーマット（Morton order, 8x8タイル）に変換して `C3D_Tex` にアップロード。
- 壁紙の管理は専用クラス `Wallpaper`（`source/ui/wallpaper.h/.cpp`）に分離。ロード/アンロード/描画を担当。
- 壁紙テクスチャは GPU_RGBA8 フォーマット。サイズは 2 のべき乗にパディング（400x240 → 512x256）。
- 壁紙フォルダは `sdmc:/3ds/3ds-music-player/wallpaper/`（config dir と同じ親ディレクトリ）。
- 設定画面に ITEM_WALLPAPER を追加。SettingsScreen 内で壁紙選択モード（ファイル一覧表示）を実装。

## 2. 新規ファイル

### 2-1. `include/stb_image.h`
- stb_image v2.28+ のヘッダーオンリーライブラリ。STBI_NO_THREAD_LOCALS を定義して使用。
- 実装は `wallpaper.cpp` 内で `#define STB_IMAGE_IMPLEMENTATION` して展開。

### 2-2. `source/ui/wallpaper.h`
```cpp
#pragma once
#include <3ds.h>
#include <citro2d.h>
#include <string>

class Wallpaper {
public:
    ~Wallpaper();
    bool load(const std::string& path);
    void unload();
    bool is_loaded() const { return m_loaded; }
    void draw_fullscreen();  // 上画面全面 (400x240) に描画
private:
    C3D_Tex m_tex{};
    C2D_Image m_img{};
    bool m_loaded = false;
    int m_orig_w = 0;
    int m_orig_h = 0;
};
```

### 2-3. `source/ui/wallpaper.cpp`
処理フロー:
1. `stbi_load()` で PNG を RGBA8 にデコード
2. テクスチャサイズを次の 2 のべき乗に切り上げ（512x256）
3. `C3D_TexInit()` で GPU テクスチャを確保
4. RGBA ピクセルを 3DS Morton-order タイル配置に変換（Y反転 + ABGR バイト順）
5. `C3D_TexUpload()` でアップロード
6. `C2D_Image` を構築（subtex で実際の画像領域を指定）
7. `stbi_image_free()` でデコードバッファ解放

Morton order 変換:
```cpp
static u32 morton_interleave(u32 x, u32 y) {
    static const u32 xlut[] = {0x00,0x01,0x04,0x05,0x10,0x11,0x14,0x15};
    static const u32 ylut[] = {0x00,0x02,0x08,0x0a,0x20,0x22,0x28,0x2a};
    return xlut[x] | ylut[y];
}
```

`draw_fullscreen()`:
```cpp
void Wallpaper::draw_fullscreen() {
    if (!m_loaded) return;
    C2D_DrawImageAt(m_img, 0, 0, 0, nullptr, 400.0f / m_orig_w, 240.0f / m_orig_h);
}
```

壁紙選択モード:
```
1. ITEM_WALLPAPER で A 押下 → wallpaper フォルダを走査 → in_wallpaper_mode_ = true
2. 下画面にファイル一覧表示（先頭は「なし」）
3. D-pad で選択、A で確定 → editing_config_.wallpaper_file に設定
4. B でキャンセル
```

フォルダ走査:
```cpp
#include <dirent.h>
std::vector<std::string> list_wallpapers() {
    std::vector<std::string> files;
    DIR* dir = opendir("sdmc:/3ds/3ds-music-player/wallpaper");
    if (!dir) return files;
    struct dirent* ent;
    while ((ent = readdir(dir)) != nullptr) {
        std::string name = ent->d_name;
        if (name.size() > 4 && name.substr(name.size() - 4) == ".png") {
            files.push_back(name);
        }
    }
    closedir(dir);
    return files;
}
```

## 4. 各機能の詳細設計

### FR-1: 壁紙表示
```
起動時:
  config.wallpaper_file が非空 → load(wallpaper_dir + wallpaper_file)
毎フレーム:
  begin_top_screen(bg_color)  // 単色クリア
  if wallpaper loaded → draw_fullscreen()  // 上書き
  draw UI elements  // その上にUI
```

### FR-2: 壁紙選択UI
```
SettingsScreen update:
  if in_wallpaper_mode_:
    D-pad / Touch で一覧をナビゲート
    A: 選択確定 → editing_config_.wallpaper_file = 選択ファイル名 or ""
    B: キャンセル

SettingsScreen draw_bottom (wallpaper mode):
  タイトル "Wallpaper (A: Select, B: Cancel)"
  [  なし  ]          ← index 0
  [  file1.png  ]     ← index 1
  [  file2.png  ]     ← index 2
  ...
```

### FR-3: 壁紙無効化
```
「なし」選択 → editing_config_.wallpaper_file = ""
Save時 → wallpaper.unload() が呼ばれ、単色背景に戻る
```
